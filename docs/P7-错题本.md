# P7 验收记录 · 错题本插件

> 日期：2026-10-21 ｜ 版本：`2.1.0` ｜ 状态：错题本从 `planned` 变为 `ready`
> 本轮只做错题本；「资料」插件留到下一轮。

## 一、数据口径：只有一份错题本

新增 `wrong_items`（`learnsys/core/db.py::SCHEMA`）：

| 字段 | 用途 |
| --- | --- |
| `source` / `source_id` | 来源与去重键：`ask:<id>` / `quiz:<会话>:<指纹>` / `manual:<指纹>` |
| `question` / `answer` / `my_answer` | 题目、正确答案、当时答错的原话 |
| `tags` / `note` | 知识点、解析补充 |
| `auto` | 1 = 测验判错自动收（不计学习点） |
| `review_stage` / `last_review` | 复习进度；下次复习日按 1/3/7 天现算，不落库 |
| `mastered` | 已掌握 |

- **唯一来源**：问答收藏、测验错题、手动收录都进这张表。
- `asks.starred` 只保留为 v1 历史快照。首次打开统一库时迁移一次（`meta.wrongbook_imported_at` 门闩），
  迁移后代码不再读写它；删掉的题不会被下次启动复活。
- 去重：`(source, source_id)` 部分唯一索引；题目指纹只清中文标点和空白，**保留 `+ - * / =`**，
  并剥掉「【第1题】」题号前缀，避免自动收和手动补收因前缀不同重成两条。

## 二、复习节奏

- 收录后第 1 / 3 / 7 天各复习一次；第 3 次「记住了」自动标记掌握。
- 「没记住」打回明天重来（`review_stage=0`）。
- **启动提醒只统计、不再自动推进度**。以前提醒完就 bump，用户还没看就被记成复习过；
  现在进度只由错题本页面的「记住了 / 没记住」推进。

## 三、测验错题回流

**自动**
- `learnsys/agent/tools.py` 新增 `save_wrongbook` 写工具，`schemas_for("quiz")` 才暴露。
- `AgentRequest` 带 `conversation_id`；工具用「会话 + 题目指纹」去重，同一轮内另有内存去重。
- 提示词两处：`prompts.py` 的测验模式 + `study.build_quiz_question` 的字段要求。
- 测验改成**一次只出一题**，题目以「【第N题】」开头、批改以「【批改】」开头，
  既方便前端取题，也避免把下一题混进错题答案。

**手动补收**
- 每条批改下方有「收进错题本」按钮；自动收成功时按钮显示「已自动收进错题本」并禁用。
- 前端从标记里取上一题和本次作答，**不拿整段回复兜底**，防止把下一题写进答案。
- `tool_start` 不再清空正在流式输出的批改正文，只更新状态行。

## 四、页面与接口

- 入口 `#/wrongbook`：待复习 / 全部 / 已掌握三个页签，来源筛选，卡片展开看答案与我的作答。
- 操作：记住了、没记住、标记掌握 / 取消、删除（二次确认）。
- 导出 Anki CSV：`GET /api/wrongbook/export`（utf-8-sig，中文文件名按 RFC 5987 编码），
  前端带令牌 fetch 成 blob 下载；列：正面 / 背面 / 我的作答 / 来源 / 知识点 / 收录时间。
- 接口：`GET/POST /api/wrongbook`、`POST /{id}/review`、`POST /{id}/master`、
  `DELETE /{id}`、旧 `POST /api/wrongbook/{ask_id}/toggle` 保留兼容。
- 托盘「导出错题本」与启动复习提醒都改读统一错题本；快捷栏「收藏」= 收进 / 移出错题本。
- 托盘点「测验」后保持 quiz 模式直到新会话 / 清空 / 换模式，作答轮也能自动收题。

## 五、学习点

| 行为 | 学习点 |
| --- | --- |
| 手动收题 / 收藏问答 | +3 |

成就 `star_10` 改名「错题十道」，统计显式收录的错题。

## 八、已知缺口

1. 错题本没有搜索与单条详情路由，条目多了以后要加过滤。
2. 导出的是 Anki 可导入的 CSV，不是 `.apkg`；需要牌组样式时再补。
3. 六级断点还没有自动进错题本（`source` 已预留 `cet6`）。
4. 自动收题依赖模型主动调工具；漏调时用手动补收，去重仍可能因题目改写而漏判。
5. Qt 快捷栏的测验自动收题只做了代码路径与单测，**没有跑真机 GUI 录屏**。
