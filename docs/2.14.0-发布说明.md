## 1. 这次做了什么

| # | 内容 | 落地 |
|---|---|---|
| 1 | 固定 8 个知识点类目 | 词汇 / 语音 / 语法 / 听力细节 / 听力主旨 / 听力推断 / 阅读 / 其他；种子幂等写库 |
| 2 | 每道题 1–3 个类目 | 提示词契约：题干后输出「【知识点】A、B」；系统提示、用户提示、工具 tags、rewrite 四处统一 |
| 3 | 答对也落库 | 新增 `quiz_attempts` / `attempt_points`；前端在批改 `done` 后 POST `/api/quiz/attempt` |
| 4 | 对错结构化 | 批改首行固定「【批改】正确/错误」；部分正确算错误；解析器容忍加粗/换行/否定词 |
| 5 | 幂等 | `origin_key = quiz:{会话}:{题面指纹}:{答案指纹}`；重复提交 `created=false` |
| 6 | BKT-ready 单点口径 | `source='quiz' AND correct IS NOT NULL AND points_source='model' AND parse_ok=1` |
| 7 | 知识点页 | `#/knowledge`：8 类目次数/正确率/可入 BKT/最近练习，点开看最近答题 |
| 8 | 旧错题回填 | 只导升级前 quiz 错题；cutoff + live_skipped + 一次性闸门；标记「回填·仅展示」，不计入 BKT |

## 2. 明确仍然没做

- **BKT 概率**：本轮只备数据，不做掌握概率/排程；P18.2 再做。
- **按知识点自动出题**：知识点页只展示，不改测验选题。
- **多标签冲突、分页控件**：接口支持 offset，页面只显示最近 20 条。
- **「其他」是否计入 BKT**：当前模型显式标注「其他」会计入；P18.2 可再收紧。

## 4. 升级说明

- 老库自动建 `knowledge_points` / `quiz_attempts` / `attempt_points`，并种 8 个类目；
  另写 `meta.knowledge_attempts_since` 作为回填 cutoff。
- 生产库当前 `wrong_items=0`，回填不会产生数据；页面从新测验开始积累。
- 测验页前端有改动（逐题上报、解析模块）；需要重打 exe 并替换生产后生效。
- 题目指纹是题面文本哈希；模型改写题面会产生新指纹，不跨会话合并。
- 「【批改】正确/错误」和「【知识点】」是新的模型输出契约；若模型偶发不遵守，
  前端会落 `correct=null` / 「其他」，不会猜。
