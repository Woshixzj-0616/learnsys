# 学习工作台 2.37.0 发布说明

> 2026-10-27 · P26.1 Agent 中枢（只读派活）

## 新增

工作台侧栏多了 **Agent 中枢**（`#/agents`）：

- 写一个任务，选 **Claude Code** 或 **Codex CLI**；
- 在允许的目录里**只读**执行，过程流式可见（工具调用、结论、错误）；
- 结果自动存到 `学习档案/agents/<任务号>-<agent>.md`；
- 任务列表、停止、失败原因都在同一页。

首批能力：

| 任务 | 说明 |
|---|---|
| 读代码 / 审查 | 让 agent 读仓库或指定文件，解释架构、找问题 |
| 读资料 / 写文档 | 可挂资料库中的一份资料一起交给 agent |
| 代码类任务 | 只读阶段只给方案和 patch 建议，不改文件 |
| 操作文件 | 只读阶段只读，不改文件 |

## 安全边界

- Claude：`--restricted --permission-mode plan`，禁 MCP；
- Codex：`--sandbox read-only`；
- 目录白名单：`设置.json` → `agents.allowed_roots`（默认只允许数据目录）；
- 不接管登录/密钥/沙箱；不使用任何绕过审批的开关；
- 同一 agent 同时只跑一个任务，超时/停止走进程树。

## 当前限制

- **Codex 需要本机中转口**（`127.0.0.1:57321`）在运行；没开时页面直接提示「先打开 Codex」。
- 写文件、跑命令、diff、审批在 P26.2，不在本版。
- 自动拆任务 / 多 agent 协作在 P26.4，等前三阶段真实数据。
