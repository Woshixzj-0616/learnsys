# 学习工作台 2.38.7 发布说明

> 2026-10-28 · 置顶状态不再被旧值压住 + Qt 今日页补「学习 / 工作」场景

## 改了什么

### 1. 置顶状态只有一个落点

- `界面设置.json` 里旧版残留的 `always_on_top: false` 不再永久压住 `config.ASK_BAR_ALWAYS_ON_TOP`；
- 新增 `always_on_top_set` 标记：只有用户在横栏点过「置顶 / 已置顶」，重启后才认文件里的值；
- 判定集中在 `quickbar/common.resolve_on_top`，字符串 `"false"` 仍按 `_as_bool` 的规则读；
- 点开关立即 `_save_state()` 落盘，不再等退出。

### 2. Qt 今日页补「学习 / 工作」场景

- 头部新增「学习 / 工作」两个切换按钮，对齐 Web 今日页的 `only-study` / `only-work`；
- 工作场景：
  - Hero 副标题切换为工作口径；
  - 行动卡换成固定的三条（运行记录 / 浏览器 / 资料）；
  - 右侧快捷入口换成 Agent 中枢 / 运行记录 / 资料；
  - 六级断点面板隐藏；
  - 「所有工具」把 `agents` / `browser` / `agentruns` / `materials` 排到最前。
- 场景不持久化：每次打开默认「学习」。
