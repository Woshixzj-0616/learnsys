# 学习工作台 2.51.1 发布说明

## 新增：一句一译历史

- 六级训练 → 翻译 → **历史**，顶部新增「**整篇翻译 / 一句一译**」两个分段。
- 一句一译的每一句提交本来就落库，这次补上回看入口：
  - 列表显示中文原句、技能标签、提交时间、你当时写的译文、批改结论
    （准确 / 基本准确 / 有偏差 / 误译）和必改条数；
  - 点开是完整复盘：信息点覆盖与漏译、必改、建议、参考译文、可接受变体、
    最小改动版、更地道版，全部来自当时那次批改，不会用今天的题库重算；
  - 「再译这一句」回到原题，并把上次译文预填进输入框，直接改一版再提交。
- 单句没有档位（改写的是「结论」），所以历史行不显示分数；
  「整篇翻译」分段行为与之前完全一致，单句记录不会混进来。

## 数据与接口

- 无 schema 变更（仍为 20），不改表、不回填、不迁移。
- `GET /api/cet6/train/submissions` 新增 `mode` 参数：
  - 缺省 / `mode=` 空：只列整篇（与旧版一致，排除单句）；
  - `mode=sentence`：只列一句一译，带 `conclusion / skill / card_count / preview`；
  - 其他值返回 400。
- `GET /api/cet6/train/submissions/{id}` 对单句记录额外返回
  `sentence{id, zh, skill, source_title}`，供详情页显示中文原句。

## 验证

- 1507 个后端测试、44 个前端测试通过；体量门禁 0 个超线。
- 8766 隔离实例（生产库副本）真机：
  - 历史「一句一译」列出 2 条 10-31 的提交，结论均为「基本准确」；
  - 点开详情，原句、当时译文、3 条必改、2 条建议、四个版本译文全部还原；
  - 「再译这一句」回到原句并预填上次译文；
  - 「整篇翻译」分段仍为空、不会混入单句；控制台 0 报错。
- 顺手修了 `test_briefing` 写死 `2026-10-28` 造成的跨天误报（改用当天日期）。

## 已知边界

- 历史只回看，不提供删除单次提交的入口（与整篇历史一致）。
- 单句历史按提交时间倒序，最多取最近 50 条；更早的在库里但本页暂不分页。
- 题目内容更新后，详情里的参考译文仍以当时批改结果为准，不随题库变化。
