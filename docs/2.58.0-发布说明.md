# 学习工作台 2.58.0 发布说明

## 生词本只收词条，翻译错题改成整句卡

### 问题

2.56.1 起，一句一译和整篇翻译把每条必改项的 `fix`（“怎么改”）
直接当生词词头写库。`fix` 天然可以是整句片段，于是生词本混进
`Schools should`、`The government has invested`、`only in recent years`
这类条目；同一个错误还被拆成两半——错题本存 `改译：片段`、
生词本存 `fix`，复习时两边都看不到整句。

### 1. 生词本准入（唯一落点）

新增 `learnsys/train/lexical.py`：

- **拼写**：只收单个单词；
- **搭配 / 术语 / 用词 / 词汇**：收 1–4 词固定搭配；
- **语法 / 标点 / 结构 / 漏译 / 误译 / 改变原意 / 中式英语**：一律不收；
- 含句内标点或超过 4 词也不收。

翻译、一句一译、旧回填写工具都走这一处判定，不再各写一套。
历史条目用形态判定（1–4 词 + 主谓片段护栏），挡住
`Schools should`、`The research demonstrates`、`The government has invested`。

### 2. 翻译错题改成整句卡

- **一句一译**：中文原句一张卡，正面重译，背面=参考译文 + 全部必改点
  + 最小改动版；
- **整篇翻译**：由 `sentence_around()` 把错误片段确定性地扩成完整学生句子，
  一句一张卡，背面列该句全部错误点；
- 同一句重复批改只刷新内容，保留复习进度，不新增卡；
