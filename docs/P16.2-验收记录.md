## 2. 安全边界（必须看清）

这是**给 AI 生成的学习示例代码用的资源沙箱**，不是对抗恶意代码的内核级隔离。

已经做到的：

- 超时 / 内存 / 子进程数 / 输出上限，超限杀进程树；
- 工作目录是临时目录，结束即删；不读写数据目录以外的路径；
- 默认拒绝网络 API / 网址 / 网络头文件；
- 运行环境没有密钥、没有代理、没有用户 PATH；被运行的代码看不到 `LEARNSYS_TOKEN` 等变量。

**做不到的**（Windows 用户态、无管理员权限）：

- 无法在内核层切断网络。代码若绕过静态检查（例如动态加载 `ws2_32.dll` 后取函数地址），仍可能联网；
- 没有文件系统级隔离，理论上能读取当前用户可读的文件；
- 不是虚拟机 / 容器，不能运行不可信第三方代码。

曾尝试但本机不可用：

| 方案 | 结果 |
|---|---|
| Windows AppContainer（内核级无网络能力） | 系统程序（`cmd.exe`）可运行；MinGW 编译出的 PE 报错 623（DLL 重定位），C/C++ 示例无法运行；放弃 |
| WSL `unshare -n` | 当前用户没有用户命名空间权限，`Operation not permitted` |
| Docker / Windows Sandbox | 本机未安装 |
| 防火墙规则 | 需要管理员提权，不自动弹 UAC |

结论：P16.2 的「禁网」是**默认策略拒绝**，不是安全边界。需要更强隔离时再评估安装容器或提权方案。

## 5. 已知粗糙点

1. **不是安全沙箱**：见第 2 节；只能跑自己/模型生成的学习代码。
2. **确认每次都弹**：没有「本次会话都允许」；运行代码也会弹一次。
3. **运行代码不落盘**：临时目录结束即删，产物不保留；要保存代码请让 Agent 用 `write_study_file` 或 `save_material_note`。
4. **参数写死**：超时 10 秒、内存 512MB、输出 64KB，暂未进设置页。
5. **编译器只认 PATH 里的 `g++/gcc`**：本机 8.1.0 可用；换机器没编译器会返回中文「本机没有找到 g++」。
6. **输出编码**：先 UTF-8，再 GBK / `mbcs`；极少数程序的自定义编码可能乱码。
7. **写文件只允许 `学习档案/`**：资料库原文仍走导入接口，不开放任意写。
