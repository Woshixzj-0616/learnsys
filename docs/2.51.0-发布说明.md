# 学习工作台 2.51.0 发布说明

## 新增「每日积累」

- 入口：侧栏「学习」→ **每日积累**（`#/daily`）；今日页同时有一张进度小卡。
- 每天一份，三条线：
  - **写作好句 2 组**：从 24 篇写作题库的 `upgrades` 里轮换，每组含好句、弱版、
    中文点评和适用场景；点「看弱版」对照。
  - **翻译重点词 8 个**：从 24 篇翻译题库的术语表里按天轮换，中文 → 英文 + 备注；
    每个词可一键「加入生词本」。
  - **每日纠音 5 条**：从你自己在精听里写下的笔记解析，不是通用题库。
- 当天第一次打开时生成，生成后当天冻结；第二天换一批。
- 右上角「全部已读」一次过完当天 15 条（纠音只记已读，不算已掌握）。
- 连续天数按「当天 15 条全部过完」计算。

## 纠音怎么来

解析规则是确定性的，不调模型：

- 识别 `没听出 / 没听清 / 没听明白 / 没反应过来 / 不知道意思 / 听成 / 连读`；
- `听成 X` 里的 X 记为你听到的（例如 `combat 听成 come back`）；
- 目标词到原句里做模糊匹配，顺手修正拼写偏差（`realisti → realistic`）；
- 用 `transcript.json` 的词级时间轴，页面可以只播目标词所在片段，也能播整句；
- 分类标签：辨音 / 连读 / 生词 / 反应 / 没听出。

现有 68 条笔记中，规则能解析出 57 条（约 84%），共 83 个纠音点；
纯结构/理解型笔记不硬造，页面会提示去精听补一条笔记。

## 数据与接口

- schema **20**：
  - `cet6_pron_items`：纠音池（目标词、听成什么、类型、状态、最近使用）；
  - `cet6_accum_items`：当天条目与已读/已掌握状态。
- 新接口：`/api/daily`、`/api/daily/item/{id}/status`、`/api/daily/read-all`、
  `/api/daily/term/{id}/vocab`、`/api/daily/history`。
- `/api/today` 增加 `daily` 摘要，供今日页小卡使用。
- 题干、原句、时间轴仍不复制进库；翻译词加入生词本走现有 `vocab_items`。

## 已知边界

- 纠音解析是启发式：一条笔记里的长句引用、纯结构描述会跳过；
  同一个词在不同句子出现会分开记。
- 没有 `transcript.json` 的试卷，纠音只显示文字，不显示词级音频。
- 每日条目生成后不再变化；当天新写的精听笔记从第二天开始进入每日卡。
- 翻译词「加入生词本」按词去重，已在生词本时不会再建一条。
