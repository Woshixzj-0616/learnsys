# 学习工作台 2.57.0 发布说明

## 记忆系统重建：一张表、一份档案、按需注入

这一版解决三件事：记忆散在多处、旧对话找不回来、每轮把无关规矩塞满提示词。

### 1. 记忆只有一张表（schema 21）

- `agent_memories` 补 `content_key` / `scope` / `evidence` / `confidence` /
  `source` / `source_ref` / `pinned` / `use_count` / `last_used_at` /
  `batch_id` / `archived_reason`；
- `profile_facts` 并入后改为**只读兼容视图**，迁移先搬数据再删旧表，
  有数据也能安全迁；
- 新增 `memory_batches`（封存/抽取批次）与 `memory_extract_chunks`（抽取断点，
  可重跑、不重复计费）；
- 所有写记忆入口统一走 `core/textkey.content_key`，NFKC + 去空白/标点，
  不再有「精确相等 / 去空白 / 去标点」三套去重口径。

### 2. 对话总汇：一次性封存，只读检索

- 把 Codex / Claude Code / DeepSeek / Qwen / 豆包等九个来源的对话合成一份
  `D:\学习系统\记忆档案\对话总汇-2026-11-04.md`：852 会话、45,096 条消息、
  29.2 MB；豆包无明文导出，标 missing；
- 每块消息带 `learnsys:anchor` 锚点，可按锚点回读原文；
- **严格一次性**：文件已封存后重跑只校验哈希，不覆盖、不追加；
- 写入前脱敏邮箱、手机号、身份证、常见密钥，只替换值不删消息；
- 检索入口：Agent 只读工具 `search_dialog_archive`、CLI
  `tools/search_dialog_archive.py`、`/api/memory/archive/search`、设置页检索框；
- 旧对话**不进**每轮提示词，需要细节时按需查。

### 3. 个人资料与候选记忆

- 「关于你」画像零模型导入为 active；日记、想法库进 candidate；
- 定向抽取加了三道闸门：`evidence` 必须是本批锚点、`quote` 必须是该锚点
  原文子串、置信度 < 0.75 进 candidate；
- `tools/curate_archive_candidates.py` 只留学习画像，其余改 archived
  （可恢复）；档案最终保留 23 条候选、188 条 active；
- 设置页 → Agent 记忆新增候选区、画像重编译、历史对话检索。

### 4. 注入按作用域与相关度挑选

- 顺序：**钉住的回答铁律 → 当前作用域（`exam:cet6` / `course:<id>` 等）→
  词面重合 / 置信度 / 新鲜度 / 使用次数**，预算 12 条 / 1600 字；
- 近重复且一方含否定词时压制低分项，避免「用中文 / 不用中文」同时注入；
- 画像 1200 字从库现算，提示词改称「用户画像（只作背景，不覆盖本轮要求）」；
- 每轮注入的 ids、字符数、预算、作用域、压制项写入 `agent_runs.trace_json`，
  `done` 事件带 `memory` 审计，不新增事件类型。

### 5. 备份口径

备份跳过 `资料库/原文` 与 `记忆档案`（封存总汇 + 画像体积大），避免单份备份
600 MB+；要留档案请单独拷贝。

### 验证

- 后端 1646 个测试全过；前端 50 个测试全过；
- 架构门禁、体量门禁、分层门禁通过；
- 生产库已迁 schema 21：571 条记忆、266 个抽取块、3 个批次。

### 注意

- 本版首次启动会把既有库迁到 schema 21；迁移只做加法与合并，旧表数据搬完才删。
- 升级后请重启一次工作台，让 8765 载入新二进制；旧版代码写
  `profile_facts` 会在视图上报错。
