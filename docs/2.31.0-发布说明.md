## 新功能

复习卡从「看答案」改成**主动回忆**：

- 未揭晓时有一个输入框「先自己写一遍（可留空）」，自动聚焦；
- 揭晓后依次显示：参考 → 你这次的答案 → 你当时写的 → 错误说明；
- 键盘操作：
  - 输入框里 **Ctrl / Cmd + Enter** 显示答案；
  - 揭晓后按 **1–4** 直接评「忘了 / 模糊 / 记得 / 简单」，按钮上标了数字；
- 每题切换时输入框清空并重新聚焦，不会把上一题的答案带下去。

纯前端改动：没有新接口、没有新表、没有 schema 变更；FSRS 排期仍由
`POST /api/review/wrong/{id}` 决定。
