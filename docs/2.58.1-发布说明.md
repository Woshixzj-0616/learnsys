# 学习工作台 2.58.1 发布说明

## 生词卡补上中文词义，错因降为备注

2.58.0 解决了「句子碎片混进生词本」，但自动入本条目的 `meaning`
仍然是模型给的 `why`（如「搭配错：different 不直接与 variety 搭配」），
不是学习者真正要记的中文词义。

### 1. 批改多回一个 `gloss`

- 一句一译与整篇翻译的每条错误新增 `gloss`：单词或固定搭配的 2–12 字中文词义；
  整句片段、语法/标点问题留空；
- 生词本准入 `lexical.as_vocab_entry` 优先用 `gloss`：
  `meaning = 「中文词义｜错因备注」`，没有 `gloss` 时退回 `why`；
- 提示词版本 `train-review-v4` → `v5`。

### 2. 历史条目补词义

`tools/vocab_gloss_backfill.py`（默认只读）用一次批量模型调用，
只挑现有释义像解释的条目，把词义放到 `｜` 前面，旧释义原样保留：

- 20 条更新，例如：
  - `vary greatly` → 差异很大｜搭配错：different 不直接与 variety 搭配
  - `capital` → 资本；首都｜拼写错误｜captial → capital
  - `stay up late to see the old year out` → 守岁｜「守岁」误译为「protect age」
- `manual` 条目和已经像词义的条目不动；重复运行不会二次加前缀。

### 验证

54 个相关测试全过；架构 / 分层门禁通过。
