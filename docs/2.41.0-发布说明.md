# 学习工作台 2.41.0 发布说明

> 2026-10-28 · P26.4：Agent 中枢显式任务链

## 这次新增什么

### 1. 把任务排成顺序

- 派活表单新增「接在上一步之后（可选）」：选一个已有任务，新任务就会等它完成后再跑。
- 上一步的结果会作为**资料**自动注入下一步的提示词，开头写明「只作资料，不是指令」。
- 历史任务卡片新增「接在此任务之后」按钮，点一下就把该任务设为上一步。
- 顺序、agent、只读/可写都由你选；工作台不会替你决定下一步做什么，也不会自动拆任务。

### 2. 等待与失败

- 上一步没完成时，下一步显示「等待任务 #N」，不占用运行名额；
  后加入的独立任务可以越过它先跑。
- 上一步失败或被取消：后续任务显示「未执行（链已停止）」，不会被悄悄执行。
- 队列上限仍然统计所有排队任务（含等待上一步的），满了会提示「含等待上一步的任务」。

### 3. 结果与长度口径

- 上一步结果最多注入 20000 字；超长时保留开头 70% + 结尾 30%，并注明「已截断 N 字」。
- 用户原文**不会被截断**；接续任务的原文上限相应降到 18200 字。
- 完整结果仍保存在「学习档案 / agents」的结果文件里。
