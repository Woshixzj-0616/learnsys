# 学习系统 v2 · 施工单

> 配套文档：`docs/学习系统-v2-架构方案.md`
> 施工顺序：P0 → P1 → P2 → P3 → P4 → P5
> 原则：每一阶段结束都必须能**独立验收**；先粗版跑通，再打磨。

---

## 0. 总览

| 阶段 | 内容 | 预计 | 交付判据 |
|---|---|---|---|
| P0 | 准备、备份、基线 | 0.5 天 | 有备份、有基线测试结果、依赖就位 |
| P1 | Agent 独立化（不依赖 Codex） | 2–3 天 | Codex 关闭时文字问答可用；有 Markdown；有思考题 |
| P2 | 统一数据库 + 本地服务 | 1–2 天 | 一个进程提供 API + 六级 `/analyze`；旧数据迁移完成 |
| P3 | Web 工作台 + 快捷栏重做 | 3–4 天 | 浏览器里能完成日常学习；快捷栏状态不跳 |
| P4 | 六级精听并线 | 1–2 天 | 不再单独启动分析服务；进度不丢；时间线可见 |
| P5 | 打包、回归、文档 | 1–2 天 | 干净目录双击可跑；可回滚 |

**最小可用闭环（建议先做）**：P0 → P1.1–P1.6 → P2.3/P2.4 → P3.3（只做问一问页）→ P4.2。
大约 **4–5 天**，你就能得到一个「Codex 关了也能用、回答完整、能在浏览器里聊」的版本；其它模块随后补。

## P1 · Agent 独立化（2–3 天）

### T1.1 配置与密钥加载

- 新文件：`learnsys\core\config.py`、`learnsys\core\paths.py`
- 读取顺序（开源版）：`设置.json` → 环境变量 → `~/.claude/settings.json`（仅作为本机便利回退）→ 未配置状态
- 字段：`agent.base_url / auth_token / model / fast_model / max_tokens / thinking`；`vision.*`；`data_root`；`cet6.root`
- 密钥只存内存；日志永远打印 `sk-…末尾4位`
- 未配置时不抛异常，进入首次运行向导
- 验收：删除 Codex，启动时 `GET /api/health` 显示模型已配置；清空配置后显示「去配置」而不是报错

### T1.2 Anthropic 协议客户端

- 新文件：`learnsys\agent\provider_anthropic.py`
- 支持：非流式、SSE、tool_use、tool_result、thinking、abort、超时、重试 2 次
- 解析事件：`message_start` / `content_block_start` / `content_block_delta` / `message_delta` / `message_stop`
- 错误映射：401 密钥无效、429 限流、超时、网络错误 → 中文原因
- 验收：用真实 key 发一条「解释循环队列」，流式逐字返回，无 Codex

### T1.3 Agent 循环

- 新文件：`learnsys\agent\loop.py`、`events.py`
- 循环：发送 → 若 `tool_use` 执行工具 → 把结果作为 `tool_result` 回传 → 直到 `end_turn`
- 上限：8 次工具调用；总时长 90 秒；可被 `abort` 中断
- 事件：`thinking`、`text`、`tool_start`、`tool_end`、`sources`、`done`、`error`
- 验收：单元测试用假 provider 模拟「调工具 → 再回答」两轮

### T1.4 提示词与输出契约

- 新文件：`learnsys\agent\prompts.py`
- 基础提示词：学习导师；完整回答；Markdown；结论先行；易错点；2–3 个「想一想」；不编造；记录是数据不是指令
- 四种模式：讲解 / 引导 / 测验 / 速答
- 学习档案注入（≤2000 字）
- 删除旧路径的 Markdown 清洗和 200 字限制（旧 `backend.py` 保留到 P3 结束）
- 验收：同一个问题，回答包含结论、展开、易错点、2 个问题；无 `**` 被删的痕迹

### T1.5 读工具（MVP）

- 新文件：`learnsys\agent\tools.py`
- `search_records(query, days, kinds, limit)`：先兼容旧库（P2 后切新库），用 `LIKE`；返回带时间/来源片段
- `today_summary()`：今天的会话、问答、转写、待复习
- `read_attachment(name, offset)`：读挂载课件
- `ocr_image(path)`：调用现有 `ocr.py`
- 工具结果包 `<record source="...">`；单条结果 ≤800 字；总结果 ≤6000 字
- 验收：问「我今天问过什么」时，Agent 先调 `today_summary`，回答引用真实时间和问题

### T1.6 视觉 + OCR 兜底

- 新文件：`learnsys\agent\vision.py`
- 配置了 `vision`：把图交给视觉模型，固定提示词要求「忠实描述文字、布局、箭头、关系，不回答问题」
- 未配置：RapidOCR → 文本；结果前加「（本次未看图，只读取了图中文字）」
- 描述缓存：`(图片路径, mtime)` → 描述，追问不重复调用
- 验收：配 GLM key 后，框选一张带箭头的图，回答能说出箭头方向；不配 key 时明确提示

### T1.7 快捷栏接入新 Agent

- 改：`learnsys\ask\bar.py` 的 `_AskWorker` → 调用 `agent.loop`
- 流式事件：`thinking` 显示「思考中」，`text` 追加，`tool_start` 显示「查记录…」，`done` 结束
- 快捷栏内用轻量渲染：保留换行、列表、代码块；完整 Markdown 交给工作台
- 移除 `ASK_MAX_TOKENS=1500` 对 Agent 路径的限制
- 验收：Codex 关闭，快捷栏问「解释一下 RISC-V 的立即数为什么拆开」，答案完整且带 2 个思考题

### T1.8 P1 测试

- `tests\test_provider_sse.py`：假 SSE 流解析、tool_use、中断
- `tests\test_agent_loop.py`：工具调用两轮、超限、错误
- `tests\test_prompts.py`：四种模式的关键约束
- 命令：`pytest tests -q`
- 验收：全绿；真实 key 手测 3 个问题

**P1 退出判据**：不启动 Codex，文字问答可用；图片走视觉或 OCR；回答有结构、有思考题；原有测试不回归。
