## 顺手修掉的根因

`store/_base.py` 的写锁和 `core/db/fts.py::index_row` 的锁是**两把不同的锁**，而它们共用同一个 SQLite 连接。录像启停时 ASR 线程写转写、主线程写窗口事件，曾在测试里稳定复现：

```text
sqlite3.OperationalError: cannot commit - no transaction is active
```

现在两处共用 `core.db._LOCK`；`tests/test_liverec.py` 连续跑 8 次全过。
