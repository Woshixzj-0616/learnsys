# 学习工作台 2.38.4 发布说明

> 2026-10-27 · 横栏固定墨夜深色 + 展开不再伸出屏幕

## 改了什么

### 1. 横栏固定「墨夜」深色

- 快捷栏是浮在桌面/浏览器上的小工具，按负责人要求固定用深色，不再跟网页默认的晨雾跑；
- 颜色仍来自同一份 `web/css/tokens.css`，读取 `body[data-mood="ink"]` 块（新增 `read_web_tokens(mood=...)`）；
- 网页工作台仍默认晨雾，两边互不影响。

### 2. 展开后不再被屏幕边缘/窗口按钮挡

- 旧版 `_clamp()` 只要求 90px 留在屏内，展开时右端会伸出屏幕，压到浏览器右上角的最小化/最大化按钮；
- 现在整窗必须完整落在可用屏幕内，放不下时自动左移。
