## 2. 明确仍然没做

- **BKT 掌握度**：方向决策里就是「先不做」，需要知识点标签和足够答题数据。
- **模型路由的自动策略**：现在只支持显式映射，不做按成本/可用性自动选。要等第二家模型真实接入后再谈。
- **深度分析的真实 API 实测**：本机只验证了命令模式；API 模式（Claude）等填了 key 再验。
- **Obsidian 笔记导出到库**：只做了只读导入，导出仍走单份资料「导出 Markdown」。
- **六级 localStorage ↔ DB 双写退休**：条件是连续 14 天无差异，10-21 起算要到 11-04。
- **P11 八项目视 / T3.5 框选焦点**：仍需真人看屏幕确认。
