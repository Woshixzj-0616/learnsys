# 学习工作台 2.28.3 · 录像内嵌问一问：第二个回答串到第一条

> 2026-10-25 · 本地部署版（未 push GitHub、未建 Release）

## 修复

同一个录像会话里连续问两个问题，第二个回答会出现在第一个回答的气泡里。

根因：流式气泡用 `querySelector(".rec-ai-stream")` 找，第一问完成后没有清掉
这个类，第二问再查时拿到的还是第一问的旧气泡。

修复：

- 取**最后一条**助手气泡，而不是第一条带 `rec-ai-stream` 的；
- done / error / finally / stop 都移除 `rec-ai-stream`；
- SW 缓存升 v24。

  第一气泡不含第二问；DB 为 4 条独立消息。
