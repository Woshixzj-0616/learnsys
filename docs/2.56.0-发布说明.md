# 学习工作台 2.56.0 发布说明

## 生词本：去重 + 一句一译的问题也进本

### 根因

- 整篇翻译批改的术语卡原本存的是「学生写错 → 正确英文」，
  直接写进生词本会变成 `spring paper → spring couplets` 这种英文-英文条目；
- 翻译页「加入生词本」存的是中文词头 + 英文释义，每日积累存的是英文词头 + 中文释义，
  同一个概念从两个方向各落一条；
- 去重只看词头，跨方向不会合并。

### 修复

- **统一方向**：`store.add_vocab` 统一「英文词头 + 中文释义」；中文词头 + 英文释义
  自动交换，释义后的「｜备注」跟着释义走。翻译页、每日积累、精听工作台、手动添加
  现在都按同一方向落库。
- **整篇翻译术语卡**：词头取正确英文、释义取中文 `why`、`context` 记
  `改译：写错 → 改对`，不再产生英文-英文条目。
- **一句一译**：每个 `must_fix` 也记入生词本——正确英文 + 中文原因，
  `context` 带原句和我当时的写法；结果页显示「已自动记录：错题本 +N · 生词本 +M」。
- **一次性清理**：`tools/vocab_dedupe_report.py` 默认只读，`--apply` 后
  归档旧英文-英文术语卡，中文词头原地转英文词头（保留 id、复习状态和复习日志）。
  生产 33 条活动生词中：归档 3 条旧术语卡，转写 10 条中文词头。
