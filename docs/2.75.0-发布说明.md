# 学习工作台 2.75.0 发布说明

日期：2026-11-22

## 一、快捷栏：快答优先，深入按需

- 新增请求级 `AgentRequest.deep`：只有用户点「深入讲」才开思考；默认回答仍是
  `deepseek-flash` 快答，不拖慢日常使用。
- 生产 `strong_model` 已留空：深入讲 = 主模型 `deepseek-flash` + 思考（6 题 A/B 全对、平均约 3.8 秒）；
  设置里填 `deepseek-v4-pro` 可换强模型（同样 6/6，但平均约 9.5 秒、最慢 28 秒）。
- 快捷栏答完后，若系统判断这题偏复杂，答案底部出现「这题可以深入讲」入口；
  「⋯ → 深入讲上一题」随时可用。
- 答案里出现「我上面说错了 / 等一下……改为」这类改口时，底部出现「答案中途改过口 · 点此深入复核」。
  审计只提示，不改写答案。
- 深入轮统一按讲解口径，复用的截图只给模型看、不重复归档。
- 提示词增加两条纪律：用户说没懂/再讲/为什么时换讲法；不要边写边改口。

## 二、公式不再乱码

- 原生快捷栏新增 LaTeX→Unicode 兜底：`$H(K)=3K \bmod 11$` → `H(K)=3K mod 11`、
  `$\frac{10}{8}=1.25$` → `10/8=1.25`、`$\lceil \log_2(23) \rceil=5$` → `⌈ log₂(23) ⌉ = 5`。
- 代码围栏、行内代码、货币 `$5` 不误伤；复制答案与显示一致。
- 复杂矩阵/多行环境会降级成线性文本，不做 KaTeX 排版。

## 三、逐轮可观测

- 快捷栏每轮写 `agent_runs`：实际模型、首字、总时长、steps/model_calls/tool_count、
  usage/cost、trace、error；done / error / cancel 只写一次。
- `asks.backend` 改为本轮实际路由模型，补 `first_ms`。
- 流水折叠唯一落点 `agent/run_record.py`，服务端与快捷栏共用。

## 四、智能旅行整合

- 新增只读工具 `travel_trace`：工作台/快捷栏 AI 可查智能旅行最近的调用路径、
  最慢请求、单条请求的模型/工具/打回耗时；不返回用户名，缺库回中文原因。
- 新增 `tools/import_travel_architecture.py`：把智能旅行的《症状与排查》《行为开关总表》
  《架构总览》导入资料库课程「智能旅行后端」；默认 `--dry-run`，`--apply` 前备份，按 sha256/同名跳过。
- 设计原则（控制流归代码 / 打回 / 一处为源 / 逐轮观测）记录在 `docs/Agent-改进-20261122.md`。
