# 学习工作台 2.49.0 发布说明

## 六级专项新增「真题自评」

- 入口：六级训练 → 专项 → 顶部切换「逐句听写 / 真题自评」；
  直达地址 `#/cet6?tab=drill&mode=exam`。
- 流程：按段播完整真题（正文 / 全部题目 / 单题，可 0.75x）→ 逐题标 ✓ 对 / ✗ 错 →
  提交 → 看自评正确率、错题号，并可展开原文对照。
- 题干与音频只从试卷 `data.js` 读，不复制进数据库；试卷里没有 A/B/C/D 选项和标准答案，
  所以口径固定叫「自评正确率」，不是机器判分。
- 队列：A 段优先、B 段其次、C 段最后；最近 3 天做过的段排后；练得少的先上。
  候选只来自 `cet6_progress` 里已同步的试卷（在工作台打开过一次即可）。
- 统计：`#/cet6?tab=stats` 新增「真题自评」卡，按 A/B/C 分段显示自评正确率。
- 今日目标：真题自评计入“训练 / 复习”格，今日页会写「真题自评 · 今天已完成 N 段」。
- 新增 `cet6_exam_attempts`（schema 18），只存段、题数、自评对题数、错题号、时长；
  **不建错题卡、不进 FSRS**，本轮只做测量。

## 顺手修正

- 专项页已有听写模式在“今日计划”里没有完成标题的问题：今天只做听写时，
  今日页现在会写「专项听写 · 今天已完成 N 句」，不再落到「问答 0 个问题」。
- 试卷音频路径规则抽到 `services/cet6_paper.py`，逐句听写与真题自评共用一份，
  不再各写一套目录 slug。

## 验证

- 1468 个后端测试、41 个前端测试通过；架构 / 分层门禁通过。
- 8766 隔离实例（生产库副本迁移 17→18，1202 条逐句进度不变）：
  队列 A 段优先、提交 3/4 得 75%、统计分段 83%、非法题号 422、
  原文对照、音频 206、今日页完成文案；控制台 0 报错。

## 已知边界

- 试卷没有选项和标准答案，正确率来自逐题自评；同一段可重复练，各算一次。
- 个别试卷的个别段 `question_items` 为空（转写缺失），队列会跳过该段，不补造题目。
- 真题自评不写 `wrong_items`、不进复习队列；错题诊断目前只到题号与分段。
