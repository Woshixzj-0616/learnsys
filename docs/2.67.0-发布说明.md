# 学习工作台 2.67.0 发布说明

## 派活任务条

有任务在运行或排队时，页面底部中间浮出一条小任务条：

- 显示「N 运行中 · M 排队 · 当前任务摘要」；
- 点一下直接进 Agent 中枢看过程与结果；
- 点「×」收起，任务状态变化时会再出现；
- 没任务时完全不占页面；右下角的精听 AI 不受影响。

实现是壳层的 `web/js/agent-bar.js`，每 8 秒轮询一次任务列表，页面隐藏时不请求。

## 项目卡显示相关经验

- 每张项目卡新增「经验 N」按钮，点进去就是经验库按该项目筛选后的列表；
- `GET /api/projects` 多返回 `experience_count`，只统计 `status='active'` 的经验；
- 经验库支持 `#/practice?project=ID` 深链，下拉框自动选中对应项目。
