# 学习工作台 2.45.1 发布说明

> 2026-10-29 · 修复打包版运行 Python 代码超时

## 修什么

2.45.0 打包版里，复习卡「▶ 运行代码」和代码调试的 `run_code` 在运行 **Python** 时会卡满 10 秒超时。

原因：沙箱把 `sys.executable` 当 Python 解释器；源码模式下它就是 `python.exe`，
打包后它指向「学习工作台.exe」，于是每次「运行代码」都等于再启动一个工作台，
被超时机制杀掉。

修复（`learnsys/agent/sandbox.py::_python_argv`）：

- 源码模式：行为不变，仍用当前解释器；
- 打包版：依次查找系统 `python` / `python3` / `py -3`，并排除 Windows 商店的占位
  `WindowsApps\python.exe`（调用它只会打开商店）；
- 都找不到时明确提示「没有找到可用的系统 Python」，不再静默超时；
  C++ / C 运行不受影响。

## 测试

- 新增 `tests/test_sandbox_frozen.py` 5 例：源码模式、系统 Python 优先、
  跳过商店占位、回落到 `py -3`、无解释器时的中文提示；
- 全量 1328 个 Python 测试通过；两个结构门禁通过；
- 生产包实测 `POST /api/code/run` 运行 `print(sum(range(4)))` 返回 `6`。
