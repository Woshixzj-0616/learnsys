## 四、本次修掉的显示问题

1. **Markdown 被旧后处理删光**：新路径不再走 `tidy_answer`，正文按原样流式；结束时渲染 Markdown。
2. **Qt 对中文加粗漏解析**：`**（同一端）**` 会留下 `**`；已换成行内 `<b>`，并跳过代码围栏里的 `**`。
3. **渲染后字号缩回 9pt**：给 `QTextDocument` 设了 15px 默认字体，答案不会在结束瞬间变小。
4. **状态重复刷屏**：thinking 增量每片都发活动信号；现在同一句话只发一次。
5. **电脑助手回归**：`>` 开头的请求原本会被导师提示词带偏；已加 `system_override` + `use_tools=False`，只出 JSON 计划。
