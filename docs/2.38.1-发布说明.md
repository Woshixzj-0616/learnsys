# 学习工作台 2.38.1 发布说明

> 2026-10-27 · P26.1 续：Qt 壳层对齐新界面（快捷栏 / 今日页 / 设置页）

## 这次新增什么

### 1. 快捷栏（Alt+Q）改吃设计令牌

- 原来 `quickbar/common.py` 里是一整段写死的深色 QSS；现在改成 `QSS_TEMPLATE` + `render_qss()`，
  颜色全部来自 `web/css/tokens.css`（`:root` = 晨雾浅色），和网页工作台同色；
- 流式回答的 Markdown、思考过程、`我：` 引用块、链接/代码颜色同步走令牌；
- 托盘菜单也吃同一套样式，不再单独维护一份。

### 2. Qt 今日页对齐新设计

- Hero 卡去掉深色渐变，改白卡 + 细边框 + 16px 圆角；
- 右上角新增目标圆环（底环 + 进度弧 + 百分比），对应 Web Hero；
- 等级 / 连续天数改成一排 badge（`Lv.6` `协议解剖师` `▲ 8 天连续`）；
- 插件区改名「所有工具」，卡片收紧为 4 列；行动区改名「今天还可以」；
- 「本周」面板换成七天柱状图（数据来自 `/api/overview` 的 `week.daily`）；
- 时间线问题摘要截到 120 字，避免一段代码把页面撑得很长。

### 3. 设置页

- 令牌补齐 `--surface` / `--surface-2`；危险按钮去掉硬编码红色，统一走 `--err` / `--err-soft`。
