## 3. 与施工单/旧行为的差异

1. **新收错题仍从明天开始出现**（沿用旧版「刚答错不立刻催」的口径）：
   迁移种子用旧 `next_review`，不把今天新收的题立刻算到期。
2. **`wrong_items.review_stage/last_review` 退休为历史列**，不再写入；
   `next_review` 优先读 `review_state.due`，没有状态时回退旧算法。
3. **不再「练完 3 轮自动掌握」**：FSRS 不自动判定掌握，只有用户手动「标记掌握」；
   取消掌握会重置为今天到期的新卡。
4. 生词卡已能进队列（`item_type=vocab`），但还没有生词复习界面；UI 留到下一阶段。
