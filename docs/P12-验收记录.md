## 3. 与施工单的差异（有意为之）

1. **分析 + 六级「直接问」改为 `fast_model`（deepseek-flash）**：用户 2026-10-21 明确要求，
   不再用 pro；翻译本来就是快模型。施工单原写“复用主模型”，这里按用户口径覆盖。
   普通问一问/快捷栏仍用主模型。
2. **`analysis.recover()` 改为首次提交时懒执行**：`create_app()` 在测试里也会被调用，
   启动即连库会误触真实 `D:\学习系统\learning.db`；懒执行仍然覆盖进程重启。
3. **`translate-item` 分块 12 句、batch `max_tokens=2000`**：实测 23 句 + 600 token 会截断 JSON。
4. **`cet6_events` 只写有标签/笔记/循环的句子**：逐句进度全量写 `cet6_progress`，
   时间线不写空句子，避免今日页/学习点被刷屏。
5. **`ContextSnapshot` 默认标题保留旧文案**：CET6 传「当前学习上下文」，
   快捷栏仍显示「刚录到的课堂转写片段」，避免旧界面语义变差。
