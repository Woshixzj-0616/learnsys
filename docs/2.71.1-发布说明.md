# 学习工作台 2.71.1 发布说明

> 2026-11-10 · 翻译批改：逐句对照与错误清单修正

## 这次改什么

### 逐句对照不再崩

- 翻译批改提示词改列**编号意群**（`prompts.PROMPT_VERSION = train-review-v6`），
  要求 alignment 对 1–N 每个意群各给一条、只引对应英文片段；
  之前按「中文段落」理解，单段原文只回一条，整篇译文被塞进第一行。
- 超长 quote 不再截断（截断会留下 `artificial ` 这种半截词），直接丢弃并计数。
- 对齐片段按该意群参考译文长度校验，防止模型复制整段。
- 三次样本的对齐按 segment 合并，不再只取中位那一次的；新增
  `alignment_missing` / `alignment_dropped`。
- 前端删掉「第 N 个中文意群配第 N 个英文句子」的序号兜底；没对齐显示「—」。

### 错误清单

- 翻译错误类型白名单补 `拼写` / `标点`，不再把大小写塞进「中式英语」、
  把句号空格塞进「语法」。
- `fix` 必须是可以直接替换 quote 的英文片段，说明写进 `why`。
- 程序补机械标点/空格错（标点前多空格、标点后缺空格、句号后缺空格），
  与模型条目按内容重叠去重；模型填满 12 条时顶掉末尾「建议」。
- 生词释义改为「模型 gloss → 题库术语表」，都没有就不入本；
  不再把 `why` 当释义（避免「电子支付拼写错误」这种条目）。

## 验证

- 后端 176 个测试文件全过；前端 59 个全过。
- 用 t25 二稿实测：alignment 8/8，missing 0，dropped 0。
- 生产 #17 已用新管线重批：档位 9（三次 9/9/10），12 条错误，4 条生词卡。
