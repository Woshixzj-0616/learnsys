# 学习工作台 2.38.6 发布说明

> 2026-10-27 · 搜索与模式入口移到侧栏底部

## 改了什么

- 「搜索 / 提问」和「模式」从顶栏右侧移到**侧栏底部工具区**，与「快捷栏」「框选」并列；
- 顶栏右侧不再有任何常驻控件，浏览器的最小化/最大化/关闭按钮不会再挡住它们；
- 模式面板改为从左下角弹出（侧栏右侧），不再贴窗口右上角；
- 侧栏收窄到 64px 时，面板位置跟着侧栏宽度走；
- Service Worker 缓存版本升到 v35。

快捷键不变：`/` 仍是搜索 / 提问。

## 验证

- 1104 后端 / 16 网页测试 / ruff / 体量 / 分层全过；
- 无头 Edge 截图：1400 宽（晨雾/墨夜）与 900 宽下，顶栏右侧为空、侧栏底部入口完整、面板不越界。
