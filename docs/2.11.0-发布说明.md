## 这一版带来了什么

### 2.10.2 体验修复

- 回答速度三档：fast / balanced / deep；balanced 实测 9.4 秒（原 35.4 秒）。
- Agent 长期记忆（`agent_memories`）：说「记住」就落库，每轮注入，设置页可改。
- 回答与思考一律中文；横栏流式 Markdown 渐进渲染；会话空回答自动重试；滚动问题修复。

### P16.1 计划 → 执行 → 自检

- 复杂任务先 `make_plan`（≤6 步），界面显示步骤和进度。
- 新增只读 `recent_wrong_items`；工具失败标红、不静默跳过。
- 自检核对资料 id/页码、错题编号、记录时间；不通过用快模型重写一次。
- 写操作必须用户确认（网页原生确认框 / 横栏 Qt 弹窗），拒绝后答案强制「没有执行」。
- `agent_runs` 记录每次运行，可在会话里「运行回放」。

### P16.2 写入与代码沙箱

- `save_material_note` 保存资料笔记（资料页可见）；`write_study_file` 只能写「学习档案」。
- `run_code`：C++ / C / Python，临时目录、10 秒超时、512MB 内存、8 子进程、64KB 输出上限。
- 默认禁网：网络模块/头文件/API/网址静态拒绝；运行环境没有密钥和代理。
- **边界**：这是资源沙箱，不是对抗恶意代码的内核级隔离；不要运行不可信第三方代码。

### P16.3 可观测性与成本

- 「运行记录」页（`#/agentruns`）：最近运行、首 token、总耗时、工具聚合、异常、逐事件回放。
- 设置页可填输入/输出/缓存单价与币种；没填就显示「未配置单价」，不猜价格。
- 问题入库截 200 字，写入/运行参数只存摘要。

### P16.4 A/B 评测

- 14 个固定学习任务，对照组模拟 2.10.2 工具集与提示词。
- 结果：总体正确性 0.66 → 0.98；公共任务 0.94 → 1.0，总耗时 0.96 倍；成本约 +9%。
- 结论：保留默认开启，不加开关。详见 [P16.4-AB评测](P16.4-AB评测.md)。

## 升级 / 回滚

- 新后台以 `--background` 启动：8765 + 横栏，不自动弹网页。
- 回滚：退出 2.11.0 → 把 `dist\学习工作台-2.10.2-backup` 改回 `dist\学习工作台` → 重新启动。
- MCP 服务（`learnsys.mcp_server`）独立运行，不受这次替换影响；新会话才会加载新工具定义。
