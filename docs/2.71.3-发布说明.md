# 学习工作台 2.71.3 发布说明

> 2026-11-10 · 架构收口：今日推荐单一候选池、六级壳层统一、服务层 SQL 下沉

## 这次改什么

### 今日推荐只有一个决策点

- 新增 `services/train/agenda.py`：按「到期复习（≥20 且前两天没复习）→ 二稿 →
  弱项技能 → 当天未练科目 → 少量到期复习 → 本周整篇 → 听力断点 / 昨天资料 →
  薄弱点」排一次。
- `day_plan` 取 `OUTPUT_KINDS` 填训练格；`today_actions` 取 `EXTRA_KINDS` 填行动卡；
  `coach` 取 `COACH_KINDS`；`home` 用训练格主推的 `href` 作为学习域入口。
- 今日页三处推荐不再互相打架；教练提醒与训练格同一件事时不再重复显示。

### 六级壳层统一

- `web/js/shell.js::legacyEnglishHash` 把旧 `#/cet6` 重定向到 `#/english`
  （writing / translation / review / stats / paper 都有映射），旧书签和外部深链不用逐个改。
- 英语聚合页补「统计」tab，`#/cet6?tab=stats` 现在落到 `#/english?tab=stats`。
- 共用模块从 `web/js/pages/cet6/` 迁到 `web/js/pages/english/`；
  `cet6/index.js` 退成兜底 shim，`cet6/` 只剩这一个文件。

### 服务层不再直接写业务 SQL

- 只读查询下沉：`store/stats.py`（今日计数 / 精听 / 复习冷却 / 学习时长动作数）、
  `store/train.py`（整篇流水 / 二稿草稿 / 周整篇数 / 时长行）、
  `store/study.py`（专注与转写区间）、`store/vocab.py`（本地词条）、
  `store/materials.py`（SHA 去重）、`store/review.py`（新卡配额）。
- `tools/layering_report.py` 新增 `scan_service_sql()`，`services` 直接写业务 SQL
  现在会让 `tests/test_architecture.py` 失败；`results.py` / `observability.py` /
  `dialog_archive/` 是服务层自己的数据边界，保留白名单。

## 数据 / 接口

- 无 schema 变更；
- `/api/home.learning.href` 改为训练格主推的 href（不再固定 `#/review` 或 `#/cet6`）；
- `today_actions.build()` 新增 `exclude_href` 参数，避免和训练格主推重复；
- 旧 `#/cet6` 路由由前端重定向，后端深链已同步改成 `#/english`。

## 验证

- 后端 177 个测试文件全过；前端 62 个全过；
- 体量、分层、路由 SQL、services SQL、`agent.complete` 门禁全部通过；
- 真实库只读预览：训练格「写二稿」、行动卡「复习 20 张 / 听力断点 / 薄弱点」、
  学习域 href 与训练格一致。
