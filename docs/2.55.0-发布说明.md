# 学习工作台 2.55.0 发布说明

## 修复：每日积累跨天重复

- **写作句型**：旧实现每天只平移 1 条，今天的第一条正好是昨天的第二条，
  相邻两天必然重 1 条。改为每天平移 `WRITING_PER_DAY` 条（锚点 `WRITING_EPOCH=2026-11-04`），
  相邻两天不重叠，24 天轮完 48 条。
- **翻译主题词**：旧选词下标是 `日期 + 组内偏移`，组轮换每天减 1 会和日期的 +1
  互相抵消，导致相邻两天 4 个主题词里重 3 个。改为只跟日期走，同一组在相邻两天
  一定换词；4 个主题词仍来自不同篇目。
- `ACCUM_VERSION=4`：升级后当天已生成的写作/翻译自动重生成，往期历史不动。
  今天（11-04）的写作会从 `p05/p06` 换成 `p01/p02`，翻译主题词也会刷新。
