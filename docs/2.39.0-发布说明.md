# 学习工作台 2.39.0 发布说明

> 2026-10-28 · P26.2：Agent 中枢可写派活 + 逐条审批

## 这次新增什么

### 1. 可写任务

- 派活表单新增「模式：只读 / 可写」；可写任务在允许的目录里真正改文件、跑命令。
- **Claude Code 逐条审批**：每次 `Write` / `Edit` / `Bash` 等操作前，网页弹出审批卡，
  显示中文摘要、新建文件内容、统一 diff 或命令原文；点「允许」才执行，点「拒绝」就不执行，
  并把拒绝原因交回给 agent。
- **Codex 目录内授权**：`codex exec` 无头模式没有人工审批通道，本版用 `workspace-write`
  沙箱，只在所选目录内写；界面明确标注「整任务授权，不逐条确认」，不假装有逐条审批。

### 2. 审批留痕

- 新表 `agent_approvals`：每条提议的工具、目标、摘要、预览、决定与时间。
- 结果文件新增「写操作审批」表；历史任务重新打开也能看到每条操作的最终结果。
- 等待确认默认 110 秒（`设置.json` 的 `agents.approval_timeout`，10–600 秒可调），超时按拒绝处理。

### 3. 安全边界

- 写模式仍用 `--restricted`：文件工具限制在工作目录，MCP 仍为空；
- 钩子只使用系统自带 `curl.exe`，脚本放在数据目录，URL / 令牌 / 任务号全走环境变量；
- 钩子令牌只能提交提议，**允许 / 拒绝必须用网页令牌**；每条提议只允许决定一次。
