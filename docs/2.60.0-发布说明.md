# 学习工作台 2.60.0 发布说明

## 英语复习：先自己答，再看答案

之前复习散在三个入口：错题本展开看答案、生词本弹层、六级页的复习标签。
错题本主要是「看」，而看是记忆效果最差的方式；到期数还合在一起，点进去只看到一部分。

本期把英语复习收成一个页面，按学习对象分成两个 tab：

| tab | 卡片来源 | 卡面 |
|---|---|---|
| 句子 | 写作 / 翻译批改（含一句一译） | 正面中文原句；先自己重译，再看参考译文、上次译文和必改点 |
| 单词短语 | 精听、翻译、每日积累 | 正面词或短语；先回忆词义，再显示释义和语境 |

### 1. 每张卡都先答后看

- 句子卡：输入框先写一遍，点「看参考译文」才显示答案；
- 词卡：先显示词，点「显示释义」才显示中文；
- 显示后按四档评分（忘了 / 模糊 / 记得 / 简单），仍走同一套 FSRS。

### 2. 每天每个 tab 最多 10 张新卡

- 到期队列一次取 10 张，做完这一轮可以「再来一轮」；
- 新卡上限按 `review_log` 里当天 `state_before='new'` 的条数计算，不新增字段；
- 句子和单词分别计数，互不挤占。

### 3. 到期提醒按类型分流

今日页「今日到期」拆成「句子 N · 单词 M」，点哪个进哪个 tab；
今日行动卡的「去复习」也改指英语复习页，不再把人带回六级页的旧标签。

### 4. 数据仍然只有一份

- 句子卡继续用 `wrong_items`（`source` 白名单：writing / translation / sentence）；
- 词卡继续用 `vocab_items`；
- 状态与日志仍是 `review_state` / `review_log`，没有第二套 SRS。
