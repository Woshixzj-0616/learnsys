## 0. 一句话

把 `stock` 从「暂不支持」改成**可生成日线卡片**：Tushare `daily` 接口，token 存本地设置；
没配 token 时给中文提示，不编数据。`price` 仍不支持；手机价格走事务箱的目标价提醒。

## 2. 实现

新增 `learnsys/services/life/stock.py`：

```python
configured_token() -> str              # env TUSHARE_TOKEN 优先，其次 设置.json life.tushare_token
save_token(token) -> None              # 原子写 设置.json
normalize_codes(raw: list[str]) -> list[str]  # 6 位数字补 .SH/.SZ/.BJ；最多 5 个
fetch_quotes(codes, token, day) -> list[dict] # POST https://api.tushare.pro daily
generate_card(conn, sub, day) -> dict  # 每只股票一行，写 daily_cards
```

- 订阅的 `sources_json` 复用为**股票代码列表**（如 `["600519.SH","000001.SZ"]`）；
- 取最近 14 天内的最后一个交易日；`open/high/low/close/pre_close/change/pct_chg/vol/amount`；
- 缺 token / 缺代码 → `LifeUnsupported`（当天只记一次，不空转）；
- 网络错误 → 普通异常，走既有 30 分钟退避；
- Tushare 返回 `code != 0` → 中文错误（权限/参数），按 `LifeUnsupported` 处理。

`cards.generate`：`kind == "stock"` 分派到 `stock.generate_card`；`UNSUPPORTED_KINDS` 只剩 `price`。

接口（`routes_data/life.py`）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/life/stock/config` | `{configured, token_tail, source}`（不回明文） |
| POST | `/api/life/stock/config` | `{token}` 保存；空串 = 清除 |

页面：

- 订阅表单「股票」类型启用；`sources` 输入框按类型切换标签；
- 订阅面板顶部加「股票数据（Tushare 免费档）」token 输入 + 状态（已配置尾号 / 未配置）；
- 卡片按代码显示「收盘价（涨跌幅）」。

测试：

- `tests/test_life_stock.py`：代码归一、token 保存/掩码、mock Tushare 解析、
  缺 token/缺代码、网络错误、卡片落库；
- 更新 `tests/test_life_cards.py`（stock 不再是不支持）、`tests/test_life_routes.py`（config 接口）。
