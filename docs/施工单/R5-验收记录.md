## 5. 已知限制

1. **深链只打开 Web 工作台**：时间线、六级行、快捷入口调用 `navigate(href)`；已有 Web 工作台窗口时可能只聚焦，不保证跳到目标 hash。Qt 内导航/深链桥仍未做（B 方案）。
2. 图片「图」标记在问题行右端（Web 是紧跟问题文字）；信息不丢，位置有差异。
3. 不自动刷新；数据变化需点「刷新」或重开窗口。
4. 今天没有问答时，时间线列为空状态提示，右侧栏更长，左列会出现空白。
5. 系统标题栏仍是浅色（Qt 无法改）。
6. 真实学习库里今天没有问答，时间线的「有内容」视觉由合成数据验证；生产截图显示的是空状态。
