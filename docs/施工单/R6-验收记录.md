## 4. 已知限制与未验证项

- **未用真实生产 PWA 窗口验证**：只用了 Edge `--app=` + 临时 profile；生产 PWA 是同一套页面与同一端口，理论上一致，最终以用户目视点击为准。
- **未做真人点击**：Qt 今日页/托盘的鼠标点击路径由 `open_workbench_link` 单元测试覆盖，最终需要用户实际点一次。
- **后台窗口可能被 Edge 冻结**：测试中未聚焦的应用窗口会暂停轮询；真实点击会先把窗口提到前台，冻结即解除。若将来发现「聚焦后仍不跳」，优先查浏览器节能/冻结策略。
- **多窗口会同时跳转**：待跳转是 30 秒内广播，所有打开的工作台页面都会应用；典型单窗口无影响。若要「只跳目标窗口」，需增加 ack/认领机制，本期不做。
- **后台重启后旧页面令牌失效**：页面会一直 403，需刷新页面（既有行为，不是本次引入）。
- **未重打 exe、未部署生产、未发版**。
