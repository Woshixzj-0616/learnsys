## 口径说明（先验证再下结论）

R2 规则表覆盖的反向依赖已全部清零，包括后续补做的两条：

1. `ask ↔ server`：已断开。`VERSION` 唯一来源移到 `product.py`，`backup` 移到 `services/backup.py`；
   `server` 不再导入 `ask`，门禁新增 `server → ask` 禁止规则。
2. `services ↔ agent`：`agent/config.py`、`agent/provider_anthropic.py` 已下沉到 `llm/`，
   services 不再为了模型配置与协议反向依赖 agent。**但完整包图仍有一条同级循环**：
   `agent → services → agent`（services 的翻译 / 六级分析调用 `agent.run` 做单轮模型调用，
   agent 的工具又复用 services 的 OCR / 操作 / 分析）。

这条循环没法在不改行为的前提下断开：要拆就得把「单轮模型完成」从 Agent 编排里独立出来，
属于 R3 议题。当前门禁只拦 R2 规则表里的反向依赖，不要求全图无环；脚本会把这条循环
打印出来（标注「同级复用，不计入失败」），避免它被忽略。
