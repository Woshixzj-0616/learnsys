## 口径说明（先验证再下结论）

R2 规则表覆盖的四组反向依赖已全部清零。**完整包图仍有两条双向边，不在本次规则范围内**：

1. `ask ↔ server`：`ask` 启动本地服务（`ask/desktop/web_service.py` → `server.app`）；
   反过来 `server/app.py` 与 `server/routes_settings.py` 导入 `ask.VERSION` / `ask.backup`。
2. `services ↔ agent`：`services/{analysis,textops,translate}.py` 使用 `agent.config` / `agent.provider_anthropic`；
   `agent` 也使用 `services`。

如果「包级双向依赖清零」按完整包图理解，这两条还未达标；如果按 R2 规则表理解，则已达标。
当前门禁按后者实现。是否继续收紧（例如把 `VERSION` 移到 `product.py`、把 `backup` 移到 `services`），
建议在 R3 前单独拍板，避免把 R2 扩成跨层重构。
