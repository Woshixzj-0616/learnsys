## 1. 目标与非目标

### 1.1 目标

1. 每天打开就知道练什么：一个主任务，25 分钟内完成。
2. 每次输出都有三样东西：**档位趋势、可执行的错误清单、进复习队列的错误卡**。
3. 写作与翻译共享同一套句子训练、错误分类、FSRS 复习，不出现第二个错题本。
4. 精听入口、断点深链、今日页、复习队列不回归。

### 1.2 非目标

- 不承诺提分，不冒充官方评分。
- MVP 不做手写识别，只支持键盘输入。
- 不做大题库、不抄真题原文；题库原创，后续支持用户导入。
- 不新建第二套复习系统或第二套错题本。
- 不改精听工作台的静态源码（真源在 `D:\cet6_tool`，不在 Git）。

## 2. 考试事实与评分口径

| 项 | 写作 | 翻译 |
|---|---|---|
| 时间 | 30 分钟 | 30 分钟 |
| 长度 | 150–200 词 | 180–200 汉字（汉译英段落） |
| 分值 | 15%（106.5） | 15%（106.5） |
| 形式 | 题目 + 提纲/情景/图表，多为议论文、说明文 | 中国文化、历史、经济、社会发展类段落 |
| 评分 | 总体印象，15 分六档（13–15 / 10–12 / 7–9 / 4–6 / 1–3 / 0） | 同左 |

口径说明：

- 官方是**总体印象评分**，先定档、再在档内上下浮动 1 分，无半分。
- 网上“2026 新增逻辑/地道权重、模板超 30% 降档”属于机构解读，不是官方大纲原文；本项目只把模板比例当提示，不硬扣分。
- 训练里显示档位，但**硬规则和错误清单优先于档位**。

- [沪江：六级写作翻译评分标准与扣分点](https://m.hujiang.com/en/p1438618/)

## 3. 训练模型

```
诊断（基线两篇）
  → 今日计划（到期错卡 → 最弱技能 → 计划内输出）
  → 每日 25 分钟微训练
  → 每周写作/翻译各 1 次限时
  → AI 批改 + 硬规则校验
  → 二稿（只改 3 个最影响分数的点）
  → 句子级错误进 wrong_items，术语进 vocab_items
  → FSRS 复习
  → 每 2 周换新题盲测
```

三条铁律：

1. **限时模式不给 AI、词典、参考译文**；提交后才批改。
2. **每次只改 3 个最影响分数的点**；改完必须换新题再写一次。
3. **只有可独立重练的句子级/搭配级错误进错误卡**；审题、结构问题留在提交记录里，不污染复习队列。

## 4. 写作训练内容

### 4.1 技能树

| 层 | 技能 | 训练形式 | 达标信号 |
|---|---|---|---|
| 审题 | 题型识别、立场、分论点 | 90 秒审题卡 | 3 个分论点不跑题、不重叠 |
| 结构 | 三段式、主题句、TEEL、结尾 | 段落扩写 | 主题句可辩论；例证具体 |
| 句子 | 长短句、从句、非谓语、名词化、衔接 | 句子升级 5 句 | 每段至少 1 个复杂句；无粘连句 |
| 语言 | 话题搭配、准确度、中式英语、字数 | 改错 + 限时 | 严重错误 ≤ 2 处/百词 |

TEEL = Topic sentence → Explain → Example → Link back。

### 4.2 MVP 题库（12 题）

| # | 题目 | 类型 | 主要训练点 |
|---|---|---|---|
| 1 | Should college students take part-time jobs? | 观点论证 | 立场 + 让步 |
| 2 | Generalist or specialist? | 对比选择 | 比较结构 |
| 3 | The value of failure in learning | 观点论证 | 例证具体化 |
| 4 | Should AI tools be allowed in academic writing? | 现象 + 立场 | 限定范围 |
| 5 | Short videos and our attention span | 现象分析 | 因果链 |
| 6 | Why more students pursue postgraduate study | 原因分析 | 分层归因 |
| 7 | Volunteering among young people | 现象分析 | 数据/例证 |
| 8 | The digital gap between generations | 问题 + 建议 | 建议句 |
| 9 | “Action speaks louder than words.” | 引言阐释 | 释义 + 论证 |
| 10 | “The best way to predict the future is to create it.” | 引言阐释 | 抽象概念落地 |
| 11 | Chart: screen time vs sleep | 图表描述 + 评论 | 数据描述 + 趋势 |
| 12 | Studying abroad vs studying at home | 对比选择 | 权衡 + 结论 |

### 4.3 每题内容包字段

- 题干（中文 + 英文）、建议用时、目标字数
- 审题要点 3 条、可选立场 2–3 个、分论点库 4–6 条
- 8–12 个话题搭配、5 个可复用句式
- 一篇 13–15 分档范文 + 逐段批注
- 5 组“低分句 → 升级句”对照
- 常见跑题/中式英语清单
- 二稿任务（只改哪 3 处）

**范文只在复盘时展示，不进入评分提示词。**

### 4.4 微训练类型

1. 90 秒审题：题干 → 立场 + 2 个分论点 + 三段提纲。
2. 主题句改写：5 个模糊主题句 → 具体、可辩论。
3. 段落扩写：主题句 + 1 个例子 → 80 词 TEEL。
4. 句子升级：5 个简单句 → 合并/从句/名词化。
5. 衔接填空：挖掉连接词，选最合适的。
6. 中式英语纠错：8 句，找错 + 改对。
7. 范文拆解 + 仿写：标结构、抄 3 个句式，再仿写一段。
8. 错误卡重练：到期卡看中文说英文 / 改错。

### 4.5 每日 25 分钟模板

| 时间 | 内容 |
|---|---|
| 3 分钟 | 到期错误卡 5 张 |
| 5 分钟 | 审题卡 / 主题句 |
| 12 分钟 | 段落扩写或仿写 |
| 5 分钟 | 记录 1–3 张新错误卡 |

每周另加：30 分钟限时 + 15 分钟看批改 + 20 分钟二稿（可放第二天）。

### 4.6 8 周阶梯

| 周 | 写作重点 | 输出 |
|---|---|---|
| 1 | 诊断 + 审题 + 三段结构 | 基线 1 篇 |
| 2 | TEEL + 例证 | 限时 1 篇 |
| 3 | 句子多样 + 衔接 | 微练为主 |
| 4 | 搭配 + 中式英语 | 二稿 + 换题盲写 |
| 5 | 高频话题专项 | 限时 1 篇 |
| 6 | 限时成篇 + 时间分配 | 60 分钟联考 |
| 7 | 弱项专项 | 联考 2 |
| 8 | 稳定输出 + 个人句式库 | 复测 |

## 5. 翻译训练内容

三种模式各管一件事，不互相替代：

| 模式 | 用途 | 规则 |
|---|---|---|
| 一句一译（默认日常） | 练技能、暴露错误 | 不限时、一次一句、提交后立即审核、再译一遍 |
| 整段限时（每周） | 练考场节奏、语篇衔接 | 30 分钟、无词典、整段评分 |
| 整卷模考（每两周） | 练时间分配 | 写作 + 翻译连做 60 分钟 |

一句一译是日常主入口；整段限时不能省，否则会出现“每句都对、整段不通”。

### 5.1 技能树

| 层 | 技能 | 训练形式 |
|---|---|---|
| 读 | 断句/意群、主干识别、逻辑关系 | 标注切分、提取主谓宾 |
| 译 | 语序调整、长句拆分/合并、词性转换、增补省译 | 句子专项、一句多译 |
| 词 | 文化术语、四字格、搭配、数字/时间/比较 | 术语卡、改译 |
| 校 | 漏译/误译、指代一致、中式英语 | 改译、回译 |

核心口径：**准确 > 通顺 > 句式花哨**。

### 5.2 MVP 题库（12 篇，每篇 180–200 汉字）

| # | 主题 | 篇目 | 主要训练点 |
|---|---|---|---|
| 1 | 传统节日 | 春节与年夜饭 | 习俗动词、时间顺序 |
| 2 | 传统艺术 | 书法 | 抽象品质、四字格 |
| 3 | 生活文化 | 茶文化 | 文化术语、增补 |
| 4 | 传统艺术 | 京剧 | 专有名词、定语处理 |
| 5 | 历史 | 丝绸之路 | 长句拆分、历史时态 |
| 6 | 历史 | 大运河 | 数字、地理描述 |
| 7 | 地理 | 长城 | 定语从句、被动 |
| 8 | 经济 | 高铁 | 数字、比较、影响 |
| 9 | 社会 | 移动支付 | 无主句、逻辑连接 |
| 10 | 社会 | 乡村振兴 | 政策术语、范畴词 |
| 11 | 科技 | 中国航天 | 时间线、成就表达 |
| 12 | 教育 | 在线教育 | 利弊、转折 |

### 5.3 每篇内容包字段

- 原文、主题、难度
- 断句切分（意群边界）
- 主干骨架（每句主谓宾）
- 术语表 8–12 个
- 难点/陷阱 5 条
- 参考译文 + 关键句 1–2 个可接受变体
- 信息点清单（评分用）
- 典型错误示例

### 5.4 微训练类型

1. **一句一译（默认）**：给一句中文，用户写英文，提交后立即审核；不显示参考译文，审核后必须再译一遍。
2. 断句标注：先标意群和主干，再翻译。
3. 无主句/存现句专项：10 句，练补主语。
4. 一句多译：直译 / 顺译 / 简洁版。
5. 改译：给一段有错误的译文，找错 + 改对。
6. 术语卡：文化词、政策词进 `vocab_items`。
7. 回译：把自己写的英文翻回中文，看意思丢没丢（每周 1 次）。
8. 错句重译：到期错误卡，只看中文重译。
9. 整段限时：30 分钟，无词典（每周 1 次，不可省）。

### 5.5 每日 25 分钟模板

| 时间 | 内容 |
|---|---|
| 3 分钟 | 术语卡 8 张 |
| 12 分钟 | 一句一译 4–6 句（同一技能） |
| 6 分钟 | 审核后「再译一遍」+ 换同技能新句 |
| 4 分钟 | 记录错句卡 |

每周另加：30 分钟整段限时 + 15 分钟逐句对照 + 20 分钟错句重译。

### 5.6 8 周阶梯

| 周 | 翻译重点 | 输出 |
|---|---|---|
| 1 | 断句 + 主干 + 无主句 | 基线 1 篇 |
| 2 | 语序 + 长句 | 句子专项 |
| 3 | 词性转换 + 增补省译 | 限时 1 篇 |
| 4 | 数字/比较/指代 | 改译专项 |
| 5 | 文化术语 + 四字格 | 限时 1 篇 |
| 6 | 整段限时 + 60 分钟联考 | 联考 |
| 7 | 弱项专项 | 联考 2 |
| 8 | 稳定输出 + 术语库 | 复测 |

### 5.7 单句审核规格（一句一译）

**不出 15 分档**，一句话打档位没有意义。单句只给：

| 字段 | 内容 |
|---|---|
| 结论 | 准确 / 基本准确 / 有偏差 / 误译 |
| 信息点 | 1/1、2/3（漏了哪个） |
| 必改 | 漏译、误译、语法错、搭配错、改变原意 |
| 建议 | 更地道、更简洁、更书面 |
| 参考译文 | 一个主参考 + 1–2 个可接受变体 |
| 最小改动版 | 只改错误，保留用户原句 |
| 更地道版 | 重新组织，供对照 |

规则：

1. **提交前不显示参考译文**；提交后才展示。
2. **参考译文不是唯一答案**；模型必须列出可接受变体，只把“改变原意/不合语法/明显不地道”判为必改。
3. **只有“必改”自动进 `wrong_items`**；“建议”默认只展示，用户可手动收进句式卡。
4. 「卡住了」分两级提示：先关键词，再句子骨架，**不给完整答案**。
5. 审核后默认动作是「再译一遍」；同组结束给同技能新句。
6. 每条必改必须引用用户译文里的精确片段，找不到就丢弃。
7. 单句审核用快模型单次调用，目标 2 秒内返回；**不做 3 次取中位**。

## 6. 评分与错误体系

### 6.1 档位是主口径，维度只做画像

写作诊断维度：内容切题、结构连贯、语言准确、表达地道。
翻译诊断维度：信息点覆盖、准确性、通顺度、用词与术语。

维度**不相加冒充官方分**；官方档位单独给。

### 6.2 硬规则（程序判定）

- 写作：字数 <150 标记；<140 严重提示；无分段标记；跑题 → 最高 5 分档；粘贴事件记录。
- 翻译：关键信息点漏译 → 降档；术语错 → 进术语卡；英文长度异常 → 提示，不直接判错。
- 模板检测：与内置模板库的 n-gram 重合率、自己历史作文的重复句比例，只提示。

### 6.3 批改输出结构

```json
{
  "band": 11,
  "band_reason": "切题、结构清楚，但第二段例证空泛，且有 2 处严重语法错误",
  "dimensions": {"content": 4, "structure": 3, "language": 3, "idiomatic": 1},
  "info_points": {"total": 12, "covered": 9, "missing": ["..."]},
  "errors": [
    {"type": "搭配", "severity": "严重", "quote": "make a progress",
     "fix": "make progress", "why": "progress 不可数"}
  ],
  "priorities": ["把第二段例证换成具体数据", "冠词", "避免 very important"],
  "rewrite_task": "只改第二段例证和 3 处冠词，其余不动",
  "template_flags": {"ratio": 0.12, "phrases": []}
}
```

**每条错误必须引用原文精确片段**。后端逐条校验 quote 是否出现在提交文本里，找不到就丢弃，防止模型编造批改。

### 6.4 可信度措施

1. 每个档位准备内部锚点样本；评分时给档位描述，不给本题范文。
2. 整段/整卷跑 3 次取中位；档位差 >1 标记“不稳定”，不展示单一分数。**单句只跑一次**，用必改/建议和 quote 校验保证质量。
3. 硬规则和错误清单优先于档位。
4. 每周用户盲评 1 篇，记录人机差距。
5. 支持录入真实考试/老师分数（`external_score`），作为唯一外部校准点。

## 7. 整合方案：一个插件，四个标签

把 `learnsys/plugins/cet6/plugin.json` 从 `iframe` 改为 `native-page`：

| 标签 | 内容 | 实现 |
|---|---|---|
| 精听 | 现有精听工作台 | 原 iframe，零改动 |
| 写作 | 今日 / 题库 / 限时编辑器 / 批改 / 二稿 / 历史 | 新原生页 |
| 翻译 | 今日 / 题库 / 编辑器 / 逐句对照 / 术语卡 / 历史 | 新原生页 |
| 统计 | 档位趋势、错误画像、训练量 | 新原生页 |

深链兼容：

- `#/cet6?paper=xxx`：外层页读到 `paper` 自动切到精听标签，并把参数传给 iframe。
- `#/cet6?tab=writing`、`#/cet6?tab=translation`：直接打开对应标签。
- 今日页「六级断点」入口不变。

**为什么不动精听源码**：真源在 `D:\cet6_tool`，静态 HTML、以试卷/Section/句子为中心；写作/翻译需要数据库、异步批改、FSRS、限时状态。硬塞会变成第二套数据层。外层壳只加一个原生页，精听零改动，风险最低。

## 8. 数据模型与接口

### 8.1 数据落点

| 数据 | 落点 | 新增/复用 |

批改沿用录像分析的后台任务模式：

```
提交 → 建 service_results(pending) → 单 worker 队列
     → agent.run(prompt, mode=analyze, 超时 120s)
     → JSON 修复 → 逐条 quote 校验 → 硬规则钳制档位
```

- 模型默认 `deepseek-flash`、不思考；写作/翻译可设独立 routes。
- 成本走现有 `model_usage` 账本，受每日上限约束。

## 12. 风险与对策
