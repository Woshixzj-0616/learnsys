## 0. 一句话

**不造第二套抓取和调度**：`news` 类直接过滤当天已有的每日简报条目（0 模型成本），
`word` / `custom` 类各走一次单轮模型调用；结果统一写进已有的 `daily_cards`；
新 `services/life` 只负责「到期 → 生成 → 落卡 → 记时间」。

邮件/微信推送、订阅自动发现。

## 3. 生成规则（`services/life/cards.py`）

### 3.1 `news`：过滤当天简报，不调模型

```python
def _news_items(conn, sub, day) -> list[dict] | None
```

- 读 `store.get_day(conn, day)`；简报 `status` 不在 `ready/partial` 时返回 `None`
  → 调用方**不落卡、不记 `last_run`**，下个 tick 重试（简报 07:30 生成，订阅早于它不会空转）。
- 过滤：
  - `sub["sources"]` 非空 → 先按 `source`（源名）或 `category` 匹配；
  - 主题词按空白、`、`、`，`、`·` 切分，任一命中 `title/title_zh/summary` 即算匹配；
  - 主题里没有可切分词时，用整串做子串匹配。
- 最多取 5 条；每条只存 `title/title_zh/url/source/published_at/summary(≤160 字)`。

### 3.2 `word` / `custom`：一次单轮模型调用

```python
def _model_text(topic, kind, day) -> str   # 走 agent.complete()
```

- 固定 `system_override`：中文、150 字以内、不编事实、素材只当数据；
- 失败（`error` 非空或空文本）→ 抛 `ValueError("模型没有返回内容：…")`，**不落卡**；
- `agent.complete()` 内部已按 `mode` 记账（`agent/usage.py`），不另起账本。

### 3.3 卡片形状（`content_json`）

```json
{
  "kind": "news|word|custom",
  "topic": "AI 前沿",
  "summary": "一句话（news 由标题拼；其余取模型首段）",
  "items": [{"title": "", "title_zh": "", "url": "", "source": "", "summary": ""}],
  "model": "deepseek-flash",
  "prompt_version": "life-sub-v1"
}
```

- `daily_cards.title` 固定写订阅的 `topic` → 同一天重复生成走 `upsert_card`，**不会产生重复卡**。
- `news` 没匹配到任何条目时仍落卡，`summary` 写「今天简报里没有与「X」相关的内容」，
  `items=[]`；不伪造条目。
- `price` / `stock`：`generate` 直接抛 `ValueError("价格/行情订阅暂不支持，本轮未接数据源")`。

### 3.4 函数边界

```python
def generate(conn, sub: dict, day: str) -> dict      # 生成并落卡，返回 card；失败抛 ValueError
def supported(kind: str) -> bool
```

`generate` **不写 `last_run`**：成功与否的时间戳由调用方（调度/路由）决定，避免「写了卡但没记时间」
和「记了时间但没写卡」两种半成功。

## 4. 调度（`services/life/scheduler.py`）

照抄简报的线程口径，**不共用简报循环**（简报可被用户关掉，生活订阅不该跟着停）：

```python
def tick(now: dt.datetime | None = None) -> None   # 测试直接调
def ensure_started() -> None                        # server/app.py lifespan 调
def shutdown() -> None
```

- 线程：启动后等 30 秒首检，之后每 300 秒一次。
- `tick`：`store.due_subscriptions(conn, at=now)` → 逐条 `generate` → 成功后 `store.mark_run`。
- 失败退避：`_FAILED_UNTIL[sub_id]` 记 30 分钟，期内 tick 跳过；手动运行不受限。
- 测试进程（`unittest` 已加载）不启动线程，同 `briefing.runner._is_test_process`。
- 每条订阅独立 try/except，一条失败不影响其它条。
