## 3. 总体架构

```
六级工作台（HTTP /cet6/）
  │
  ├─ 分析：POST /api/cet6/analysis ──> AnalysisQueue（后台线程）
  │                                  └─ agent.run(use_tools=False)
  │                                      └─ service_results（done/error/canceled）
  │        GET /api/cet6/analysis/{id}（轮询）
  │
  ├─ 提问：POST /api/agent/chat（surface=cet6 + context_snapshot）
  │        └─ Agent 工具循环 ──> conversations / messages
  │
  ├─ 翻译：POST /api/cet6/translate / translate-item
  │        └─ 缓存查 service_results ──> 未命中才调模型
  │
  └─ 同步：POST /api/cet6/sync ──> cet6_progress（当前状态）
                                 └─ cet6_events（时间线，带去重键）

学习工作台（Web/今日/复盘）
  └─ 读同一张 learning.db；P12 不新增页面
```

**并发模型**

- 分析队列：`queue.Queue` + 1 个 daemon worker（可配 2）。任务粒度是「一次分析」。
- 每个任务独立 `store.connect()`；SQLite WAL + `timeout=15`。
- 取消：`threading.Event`；`agent.run(abort=...)` 已支持。
- 进程重启：启动时把所有 `pending/running` 结果标为 `error`，`error='后台重启，任务中断，请重试'`。
- 超时：默认 180 秒；超时置 abort，结果 `error='分析超时'`。

`cet6_events` 补列与去重：

**状态值**（代码校验，不写 CHECK，便于扩展）：

`pending` → `running` → `done` / `error` / `canceled`；重新分析时旧行改 `superseded`。

**结果资产规则**

- 唯一键命中且 `status='done'` → 直接返回，`cache_hit=1`，不调模型。
- 唯一键命中且 `pending/running` → 返回同一行，不新建。
- `force=true` → 旧行 `superseded`，新建一行。
- 每次实际调用模型都写 `service_runs`；缓存命中只写 `service_results.cache_hit=1` 和一条 `service_runs`（`cache_hit=1`，无 token）。

### 6.1 新文件 `learnsys/context.py`

```python
@dataclass(frozen=True)
class ContextSnapshot:
    surface: str
    object_type: str
    object_id: str
    title: str = ""
    selection: str = ""
    surrounding: dict = field(default_factory=dict)
    learning_state: dict = field(default_factory=dict)
    recent_actions: list = field(default_factory=list)
    provenance: dict = field(default_factory=dict)

    @classmethod
    def from_dict(cls, raw: dict) -> "ContextSnapshot": ...
    def to_dict(self) -> dict: ...
    def digest(self) -> str: ...          # sha1(canonical json)[:16]
    def render_text(self, max_chars: int = 2000) -> str: ...
```

约束：

- 只接受 `surface/object_type/object_id/title/selection/surrounding/learning_state/recent_actions/provenance` 九个键；多余键丢弃。
- 单字符串截断：selection 2000 字、title 200 字、surrounding 各 1000 字、recent_actions 最多 20 条。
- `render_text` 输出固定格式，最后一行带「采集时间 / 来源」。
- 序列化后超过 20KB → 抛 `ValueError("上下文太大")`，路由返回 413。

### 6.3 新文件 `learnsys/services/analysis.py`

```python
ANALYSIS_KIND = "cet6_analyze"
PROMPT_VERSION = "cet6-analyze-v1"
ANALYSIS_TIMEOUT = 180.0

def normalize_record(raw: dict) -> dict: ...
def context_hash(record: dict) -> str: ...
def build_prompt(record: dict) -> str: ...       # 复用 PROMPT_HEAD / PROMPT_PAPER
def validate_analysis(obj: dict) -> dict: ...    # 缺字段补空，错类型丢弃
def submit(record: dict, *, force: bool = False) -> dict: ...
def cancel(result_id: int) -> bool: ...
def run_job(result_id: int, record: dict, abort: threading.Event) -> None: ...
def _worker_loop() -> None: ...
def recover() -> int: ...                        # 进程启动调用
```

`submit` 流程：

1. `normalize_record`（按 sentence 排序、去重、限制 120 条）。
2. `context_hash = sha1(canonical json)[:16]`。
3. `find_done` 命中且非 force → 返回 `{id, status:"done", cached:true}`。
4. 有 `pending/running` → 返回该行，`cached:true`。
5. force → `mark_superseded`。
6. `create` pending → 入队 → 返回 `{id, status:"pending", cached:false}`。

`run_job` 流程：

1. 更新 `running`；`start_run`。
2. 开定时器 `abort.set()` after timeout。
3. `agent.run(AgentRequest(prompt, system_override=SYSTEM, use_tools=False, mode="quick"), abort=abort)`。
4. 收 `done.text`；`parse_json_text`；`validate_analysis`。
5. 更新 `done` + `content_json` + tokens/ms；`finish_run`。
6. 异常：`abort` → `canceled`；超时 → `error='分析超时'`；其他 → `error=str(exc)`。
7. 关闭连接；清理 abort 表。

### 6.4 新文件 `learnsys/services/translate.py`

```python
def translate(text: str, *, kind: str = "word", context: dict | None = None) -> dict: ...
def translate_sentences(sentences: list[dict], *, paper_id: str,
                        section: str, item: str) -> dict: ...
def _cache_key(text: str, kind: str, context: dict) -> tuple[str, str]: ...
```

- `kind`：`word` / `sentence` / `paragraph`；默认 `word`。
- 单词缓存键：`target_id=sha1(word.lower())[:16]`，`scope=sha1(context_sentence)[:16]`。
- 句子缓存键：`target_id=sha1(sentence)[:16]`，`scope=paper_id|section|item`。
- 模型：`cfg.fast_model`（默认 `deepseek-flash`）；`max_tokens=600`。
- 单词提示词要求 JSON：`{"translation","meaning","phonetic"}`；句子只要求 `{"translation"}`。
- 失败重试 1 次；仍失败返回 `{"translation":"", "error":"翻译服务暂时不可用"}`，不抛 500。
- `translate_sentences` 先批量查缓存，未命中的一次请求翻译（最多 40 句/次），解析 JSON 映射；失败逐句降级。

function buildContext(){
  const sec = WB.paper.currentSection();
  const cur = WB.paper.currentItem();
  const i = WB.session.activeSentence;
  const s = i >= 0 ? WB.paper.findSentence(i) : null;
  const st = WB.state.loopStats[WB.paper.currentItemId()] || {};
  const sel = String(window.getSelection ? window.getSelection().toString() : "").trim();
  return {
    surface: "cet6",
    object_type: "item",
    object_id: WB.paper.currentItemId(),
    title: WB.session.paper.title + " / " + sec.name + " / " + cur.title,
    selection: sel.slice(0, 2000),
    surrounding: s ? {before: "", after: "", en: s.en} : {},
    learning_state: {
      sentence: i, en: s ? s.en : "",
      tags: (WB.state.errors[WB.paper.currentItemId()] || {})[i] || [],
      note: (WB.state.notes[WB.paper.currentItemId()] || {})[i] || "",
      loops: (st[i] || {}).loops || 0,
      plays: (st[i] || {}).plays || 0
    },
    recent_actions: WB.state.recentActions || [],
    provenance: {source: "cet6", captured_at: new Date().toISOString(), ttl: 300}
  };
}

**整段/整篇播放**

```js
function itemRange(item){
  const end = (item.questions && item.questions.end > item.questions.start + 0.5)
    ? item.questions.end : item.content.end;
  return {start: Math.max(0, item.content.start - 0.2), end: end + 0.5};
}
function sectionRange(sec){
  return {start: Math.max(0, sec.start), end: sec.end};
}
function playItem(){ const r = itemRange(WB.paper.currentItem()); playRange(r.start, r.end); }
function playSection(){ const r = sectionRange(WB.paper.currentSection()); playRange(r.start, r.end); }
```

- 按钮：本段工具栏「整段播放」；侧栏每个 Section 标题旁「整篇」。
- 播放中不显示句子高亮（`activeSentence=-1`），与逐句播放互不干扰。
- 现有「播放正文/播放题目」保留。
