# P28 · 学习闭环（P28.1 收进复习）

> 2026-10-29 起。P28 总目标见 [P27 施工单第 11 节](P27-个人AI工作台-地基.md)：
> 问答里能把错误收进复习、错题支持代码题字段、复习时能跑代码。
> 本文先定 **P28.1**；P28.2（编程类目）见 [P28.2 施工单](P28.2-编程类目.md)，
> P28.3（今日页 / 错题本展示）另开。

## 0. 一句话

把「收进错题本」升级成**一个写入工具**：测验判错、代码调试定位到错误、用户主动说
「收进复习」都走同一条路；错题本新增代码题字段；保存后立刻进 FSRS 队列。
同时把 P27 遗留的快捷栏个人状态注入补上（60 秒缓存）。

**不做**：编程类目 / BKT 样本（P28.2）、错题本与今日页 UI（P28.3）、自动批量收题。

## 1. 数据层：schema 12 → 13（只加列）

`wrong_items` 末尾新增 4 列，全部 `NOT NULL DEFAULT ''`：

| 列 | 含义 |
|---|---|
| `code` | 用户原始代码 / 代码片段（不复制整份仓库） |
| `language` | `cpp` / `c` / `python` / 空 |
| `error_type` | 错误类型：语法 / 边界 / 超时 / 逻辑 / 空指针 / 其他 |
| `test_cases` | 关键用例：输入 → 实际输出 → 期望输出（纯文本） |

- `core/db/schema.py::SCHEMA_VERSION = 13`；新库建表直接带 4 列。
- `core/db/migrate.py::_migrate_columns` 给旧库 `ALTER TABLE ... ADD COLUMN`；不改旧列。
- `store/wrongbook.py` 的 `_WRONG_COLUMNS` / `_wrong_dict` / `add_wrong_item` 一并支持。
- `WRONG_SOURCES` 增加 `"code"`（代码题来源，便于错题本按来源筛选）。
- 迁移验收：生产库副本 12 → 13，旧表行数与旧字段值不变。

## 2. 工具：`save_wrongbook` 扩成「收进复习」

**只保留一个工具名**，不新增第二个写入工具（避免两套收题逻辑）。

### 2.1 暴露范围

| 入口 / 模式 | 是否暴露 |
|---|---|
| 工作台 ask · explain / guide | 是（P28.1 新增） |
| 工作台 ask · quiz | 是（原有） |
| quick 速答 | 否（只保留记忆工具） |
| cet6 / video / quickbar | 否 |
| `use_tools=False` | 否 |

### 2.2 参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `question` | 是 | 题干 / 现象原话，不改写 |
| `my_answer` | 否 | 用户原作答；纯概念题可空 |
| `correct_answer` | 否 | 正确答案 / 正确写法 |
| `tags` | 否 | 知识点类目；P28.1 时沿用 8 类，P28.2 起扩为 13 类（英语 7 + 编程 5 + 其他） |
| `code` | 否 | 用户原始代码 |
| `language` | 否 | `cpp` / `c` / `python` |
| `error_type` | 否 | 错误类型 |
| `test_cases` | 否 | 关键用例 |

校验：`question` 为空 → 不写；`my_answer` 与 `code` 都为空且 `correct_answer` 也为空 →
仍允许（概念卡可以只存题干），但内容不能全是空。

### 2.3 写入口径

- 去重键：`source_id = f"{source}:{ref}:{fingerprint(question + code)}"`；
  `ref = conversation_id or conversation_key or "0"`。
- `source`：`quiz`（测验） / `code`（带 code 的问答） / `manual`（其它问答）。
- `auto`：quiz 原有 `True`；问答手动收 `False`。
- 成功后调用 `store.seed_review_states(conn)`，新卡马上有 FSRS 初始状态（明天到期）。
- 返回中文结果：「已收进复习（#id）」/「这道题已经收过了」。

### 2.4 确认卡

`save_wrongbook` 已在 `CONFIRM_TOOLS`，保持写前确认；`WRITE_LABELS` 改为「收进复习」。

---

## 3. 代码调试结束：主动提议一次

`agent/turn.py::_finish` 在 `code_debug=True` 时，若最终正文还没有「收进复习」：
在末尾追加一行固定提议：

> 想把这道题收进复习吗？回复「收进复习」，我会先弹确认卡再保存。

- 只提议一次，不自动调用工具（是否值得收由用户确认）。
- 用户同意后，模型调用 `save_wrongbook`，走现有确认卡。
- 提示词补充：代码调试收题时，`question` 写原题/现象，`code` 写原代码，
  `error_type` 写错误类型，`test_cases` 写关键用例。
