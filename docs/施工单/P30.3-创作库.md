## 0. 一句话

把「生成过的图 + 用的提示词 + 风格 + 模型 + 备注」落成**本地档案**；
风格可复用；支持从豆包导出的文本粘贴导入；图片用现有 `/api/upload` 上传后按 id 安全回显。

**本轮不做**：调用任何图像生成 API、批量抓取豆包、云端同步、图片编辑、相似度检索。

## 2. 数据层（schema 16）

在 `core/db/schema_personal.py` 追加：

```sql
CREATE TABLE IF NOT EXISTS style_presets (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    name       TEXT NOT NULL UNIQUE,
    prompt     TEXT NOT NULL DEFAULT '',   -- 风格描述 / 正向前缀
    negative   TEXT NOT NULL DEFAULT '',   -- 反向词
    note       TEXT NOT NULL DEFAULT '',
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS art_works (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    title      TEXT NOT NULL,
    prompt     TEXT NOT NULL DEFAULT '',
    preset_id  INTEGER NOT NULL DEFAULT 0,
    model      TEXT NOT NULL DEFAULT '',   -- 豆包 / 即梦 / 其他，自由文本
    file_path  TEXT NOT NULL DEFAULT '',   -- 只接受 DATA_ROOT 内的图片
    note       TEXT NOT NULL DEFAULT '',
    status     TEXT NOT NULL DEFAULT 'active', -- active / archived
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_art_works_status ON art_works (status, id);
```

- `SCHEMA_VERSION = 16`；只加表建索引。
- 删除风格预设时把引用它的作品 `preset_id` 清零（作品不跟着删）。

新增 `learnsys/store/art.py`（不往 `personal.py` 里塞）：

```python
list_presets / get_preset / upsert_preset / update_preset / delete_preset
list_works(status="active") / get_work / add_work / update_work
set_work_status / delete_work
```

## 3. 服务层 `services/life/art.py`

- `validate_work(title, file_path)`：标题必填；`file_path` 非空时必须
  **resolve 在 `config.DATA_ROOT` 内**且后缀是 png/jpg/jpeg/webp/gif。
- `parse_import(text) -> list[dict]`：
  - 按空行切块，最多 20 块；
  - 块内识别 `标题：/提示词：/风格：/模型：/备注：`；无标签行并入 prompt；
  - 整块无标签时：首行（≤60 字）当标题，其余当 prompt；
  - `风格：X` 先按名字找预设，找不到就**新建一个同名空预设**（可复用）。
- `import_works(conn, text) -> list[dict]`：解析 + 落库，空文本抛 ValueError。

## 4. 接口 `routes_data/art.py`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/art/works?status=active&limit=200` | `status=all` 看全部 |
| GET | `/api/art/works/{id}` | 详情 |
| POST | `/api/art/works` | 新建：`title` 必填 |
| PATCH | `/api/art/works/{id}` | 部分更新 |
| POST | `/api/art/works/{id}/archive` | 归档 |
| POST | `/api/art/works/{id}/restore` | 恢复 |
| DELETE | `/api/art/works/{id}` | 硬删（不动图片文件） |
| GET | `/api/art/presets` | 风格列表 |
| POST | `/api/art/presets` | 按 `name` upsert |
| PATCH | `/api/art/presets/{id}` | 部分更新 |
| DELETE | `/api/art/presets/{id}` | 删除并清零引用 |
| POST | `/api/art/import` | `{text}` → `{items, count}` |
| GET | `/media/art/{id}/image` | **不加令牌**，只回 `DATA_ROOT` 内图片（`<img>` 用） |

- 路由层不写 SQL；错误中文 400/404。
- `/media/art/{id}/image` 使用 `FileResponse`，路径校验复用服务的 `safe_image_path`。

## 10. 风险与规避

| 风险 | 规避 |
|---|---|
| 作品档案变成空壳 | 必须能挂真实图片（上传回显）且能导入豆包文本 |
| 文件路径穿越 | 只接受 `DATA_ROOT` 下、图片后缀；`/media` 再校验一次 |
| 图片文件被删后白屏 | 前端 `onerror` 显示占位，不报错 |
| 导入乱码/格式不一 | 解析容错：标签优先，无标签按首行标题；最多 20 块 |
| 表越加越多 | 只加 2 张；复用 `art_works` 一张表，不做版本/收藏/标签表 |
