## 2. API 契约（Qt 只当 HTTP 客户端）

### 2.1 认证

- 所有 `/api/*`（除 `/api/health`）要令牌：请求头 `X-Learnsys-Token: <token>`，或 `Authorization: Bearer <token>`。
- 令牌从公开的 `GET /api/health` 取；令牌只存进程内存，不写日志、不进异常文案。
- `QNetworkAccessManager` 默认不带 `Origin`，后端 `origin_allowed()` 对空 Origin 放行（与 curl 同口径）。
- 令牌错 → `403`，`detail` 为「缺少或错误的本地令牌」；Qt 侧要换成可操作的中文提示。

### 2.2 接口清单

| 接口 | 方法 | 令牌 | 请求体 | 成功响应 | 错误 |
|---|---|---|---|---|---|
| `/api/health` | GET | 否 | — | `ok, version, model, vision_ready, token, port, db, quickbar` | — |
| `/api/settings` | GET | 是 | — | `agent{base_url,model,fast_model,max_tokens,thinking,speed,auto_route,strong_model,price_input,price_output,price_cache_read,currency,ready,auth_token_set,auth_token_mask,auth_token_source}`、`vision{base_url,model,ready,api_key_set,api_key_mask,api_key_source}`、`hotkey,data_root,backup_dir,settings_path,modules{id:bool},restart_fields[]` | `403` |
| `/api/settings` | POST | 是 | `SettingsPatch`：`agent?`、`vision?`、`hotkey?`、`modules?` | `ok, saved[], restart_required[], message` | `400` 校验失败、`500` 写盘失败、`403` |
| `/api/settings/test` | POST | 是 | `{"kind":"text"｜"vision"}` | `ok, message, sample?` | `403`；业务失败仍是 `200 + ok:false` |
| `/api/settings/backup` | POST | 是 | `{}` | `ok, path, size_mb, message` | `500`、`403` |
| `/api/memory` | GET | 是 | — | `items[]`（最多 100 条） | `403` |
| `/api/memory` | POST | 是 | `{content: 1–500 字, kind?: "preference"}` | `ok, id, created, message` | `422` 长度、`403` |
| `/api/memory/{id}` | POST | 是 | `{content: 1–500 字}` | `ok, message` | `404`、`422`、`403` |
| `/api/memory/{id}` | DELETE | 是 | — | `ok, message` | `404`、`403` |
| `/api/modules` | GET | 是 | — | `{schema: 2, modules: [{id,name,status,order,…}]}` | `403` |

### 2.3 字段语义（Qt 必须照抄，不得另造）

- **密钥只进不出**：GET 只给 `*_set` / `*_mask`（`••••` + 尾 4 位）/ `*_source`（`file`｜`env`｜`none`）；POST 空串 = 不改。
- **数字字段留空 = 不传**：`max_tokens`、三个单价；Web `collect()` 只在 `raw !== ""` 且合法时放进 payload。
- **`speed` 是唯一口径**：后端保存 `speed` 时同步写 `thinking = (speed == "deep")`，Qt 不要单独改 `thinking`。
- **`auto_route`**：只能 `off` / `shadow` / `on`，否则 400。
- **`hotkey`**：修饰键（Alt/Ctrl/Shift/Win，可组合）+ 一个字母/数字/F1–F24；保存后 `restart_required` 含 `hotkey`。
- **`modules`**：只接受白名单内 id；其余忽略。
- **备份目录**：Web 页不可编辑，只展示；Qt 同样只读。

## 4. 已知差异（Qt 与 Web 的呈现差异，不减少功能）

| 差异 | Web | Qt 试点处理 |
|---|---|---|
| 备份目录 / 最近备份 | 共用 `#backup-dir` 一行，备份后原文案被覆盖 | 分两行展示：备份目录 + 最近备份，信息不减少 |
| 模块清单来源 | 壳层启动时已拉好，设置页读 `ctx.registry` | 设置页自己 `GET /api/modules`（施工单 R3.2） |
| 403 文案 | 「本地令牌不对，刷新页面再试」 | 「本地令牌不对，关掉窗口重试；还不行就重启学习工作台」 |
| 测试连接提示 | `toast` | 状态标签 + 按钮禁用（行为一致，呈现不同） |
| 模块开关即时生效 | 保存后派发 `learnsys:prefs` 更新当前侧栏 | 已打开的 Web 页要刷新才看到（施工单已定，不加跨进程事件） |
