## 2. 目标与非目标

### 2.1 目标（本单验收）

1. **强制取证**：`ops_mode=on` 且意图 `needs_evidence=True`、用户又没提供配置/输出时，
   本轮必须至少调用一次 `web_search` 或 `fetch_url`，否则回答前补一轮；
2. **最多补一轮**，不无限循环；补轮后仍没证据，答案必须显式写「未查证 / 未验证」；
3. **写操作让路**：取证轮不开放写工具（`save_wrongbook` / `save_memory` 等），
   避免半截确认卡住整轮；
4. **摘要防污染**：摘要生成提示词加入事实分级；后置检查兜底，未验证候选不得写成
   「根因是 / 已解决 / 已确认」；
5. **可量化**：golden 结果记录每条的工具调用；新增 `evidence_gate` 流水；验收用
   「取证命中率 + 多轮重放 + 摘要原文」三项，而不是只看关键词通过率。

### 2.2 非目标

- 不在用户机器上执行 shell（`run_code` 只在临时沙箱跑 Python/C/C++，不碰 nginx）；
- 不新增工具；不引入 `tool_choice` 以外的强制手段（见 5.2，`tool_choice` 也要开关）；
- 不改 M1 的 `intent.py` / `claims.py` 判据（除非验收发现误伤，单独修并补测试）；
- 不默认切 `deepseek-v4-pro`；不自动发版 / push；
- 不改前端设置页（配置项先进 `public()`，页面后续单开）。

## 3. 设计原则

1. **先门控，后审核**：能不让错误答案流出去，就不要靠事后重写；
2. **一条规则一个落点**：门控判据只在 `agent/evidence_gate.py`；摘要口径只在 `post_turn.py`；
   工具开关只在 `llm/config.py`；
3. **最多一轮**：补取证最多一次，宁可在答案里明说「没查到」，不要连环调用；
4. **可回滚**：`agent.ops_gate`（`off/shadow/on`）+ `agent.summary_guard`；
5. **不碰 `turn.py` 的 500 行红线**：动手前先把 `_finish` 抽到 `finish_turn.py`（预计腾出 30+ 行），
   之后 `turn.py` 只留接线。

## 5. 设计细节

### 5.1 新增 `learnsys/agent/evidence_gate.py`

**职责**：只做规则判断与提示词拼装，不调模型、不读库。

```python
@dataclass(frozen=True)
class GateDecision:
    needed: bool
    kind: str            # none / user_text / tools_missing / already_evidenced
    reason: str

def decide(message: str, attachment_text: str, evidence, *,
           ops: bool, ops_gate: str) -> GateDecision: ...
def nudge_text(decision: GateDecision) -> str: ...
def needs_round(evidence) -> bool: ...
```

判定：

| 情况 | `kind` | 处理 |
|---|---|---|
| `ops_gate=off` / 非 ops | `none` | 不干预 |
| 用户消息/附件里已有配置原文、报错原文、命令输出 | `user_text` | 不强制联网；提示词按 M1 规则分级即可 |
| 本轮已有 `web_search` / `fetch_url` / `run_code` 证据 | `already_evidenced` | 不再补轮 |
| 需要外部事实（版本、默认行为、发行版默认配置）且零证据 | `tools_missing` | 补一轮取证 |

**实测后收紧**：只有消息含「版本 / 最新 / 默认 / 弃用 / 兼容」才判定「需要外部事实」。
端口排查（`80 端口被占用`）、读配置（`nginx.conf 改了没变化`）不强制联网 ——
这类问题靠本地规则和 M1 的提示/审核即可；否则模型会连搜 5–7 次、单题 30–50 秒。

「用户已提供证据」的粗判（保守，宁可少判）：
- 有 ```` ``` ```` 代码块且含 `server {` / `listen` / `Traceback`；
- 含 `输出：` / `报错：` / `exit code` / `退出码` + 数字；
- 含 `/etc/` 路径且长度 ≥ 80 字。

### 5.2 强制取证的两道手段

1. **前置提示（`ops_gate=on` 时）**：`loop._prepare` 里，`decide().needed` 为真时，在用户消息末尾追加
   `nudge_text()`：
   ```text
   【本轮系统要求：先取证】你需要外部事实才能下结论。回答前必须至少调用一次
   `web_search` 或 `fetch_url`；查不到就写「没查到，以下为候选」。取证轮不要调用写操作工具。
   ```
   同时把工具列表裁剪为只读工具（去掉 `save_*` / `add_*` / `rate_*`）。
2. **后置补轮（`ops_gate=on` 时）**：`loop.run` 在第一次 `_run_tool_loop` 返回后调用
   `evidence_gate.needs_round(turn.state.evidence)`：
   - 为真 → 保留草稿到 `messages`，追加 `nudge_text()`，重置 `state.text`，
     再跑一次 `_run_tool_loop(max_steps=2)`；最终正文以第二次为准，并发 `rewrite` 事件；
   - 为假 → 原样进入 `_retry_thinking_only` / `_finish`。

约束：
- **最多补一轮**，用 `state.gate_rounds` 计数（新增 1 个字段）；
- 补轮工具只读；补轮发生时不重复 `first_ms` 的计时口径（首 token 仍按第一次算）；
- `tool_choice` 本单**不做**，理由：DeepSeek/中转兼容性未验证；若后续要加，
  另开 `agent.force_tool_choice` 开关并先在中转上实测。

### 5.3 写操作门控

- `ops_gate=on` 且 `turn.ops` 为真时，`tools.schemas_for(...)` 之后做一次过滤：
  `CONFIRM_TOOLS` 全部移除（代码调试保留 `run_code`）；需要建议用户保存时，回答里用文字提议，
  用户下一轮说「收进复习」再走正常确认；
- 只影响 ops 轮，普通轮不变；`shadow` / `off` 不裁剪；
- 过滤在 `evidence_gate.filter_schemas(schemas, keep=...)`，`loop.py` 调一行。

### 5.4 摘要防污染（`agent/post_turn.py`）

`SYSTEM` 的「摘要要求」追加：

```text
- 排错 / 配置类结论必须分级：用户确认过的现象、工具查到的原文写事实；
  凭记忆或社区经验的候选写「候选：…（未验证）」；
- 不许把未验证的候选写成「根因是 / 根因就是 / 已解决 / 已确认 / 已分析出根因」；
- 用户被纠正过的错误结论要删掉，不要保留在摘要里。
```

后置检查 `_sanitize_summary(text)`：

```python
ABSOLUTE = ("根因是", "根因就是", "一定是", "已解决", "已确认", "已分析出根因")
UNVERIFIED = ("候选", "未验证", "待确认", "需要你确认")
if any(w in text for w in ABSOLUTE) and not any(w in text for w in UNVERIFIED):
    text += "（部分排错结论未验证）"
```

- 只追加标记，不改写原句（避免二次模型调用）；
- 受 `summary_guard` 开关控制；关闭后恢复现行为；
- 摘要写入 `conversations.summary` 前调用；失败只记诊断日志。

### 5.5 事件与流水

- 新增 `gate` 事件（`data={"needed": true, "kind": "tools_missing", "round": 1}`）；
- `server/routes_agent/common.py` 的 `_TRACE_KINDS` 加 `gate`；
- `chat.py` 不需要新字段；`trace_json` 里可统计取证轮次；
- 不升 schema。

## 8. 风险与回滚

| 风险 | 处理 |
|---|---|
| 强制联网让本可本地回答的问题变慢 | `ops_gate=shadow` 先跑；只有 `tools_missing` 才强制；用户已给证据不强制 |
| 补轮导致答案重复/抖动 | 草稿进 `messages` 后要求「修正而不是重写」；最终只保留第二轮正文；最多一轮 |
| 写工具全禁影响「收进错题」 | ops 轮用文字提议，下一轮再走确认；普通轮不受影响 |
| 摘要标记被用户看到不舒服 | 只在摘要内部注入下一轮，不在聊天正文展示 |
| 中转不认新参数 | 本单不加 `tool_choice`；只加提示词和事件 |

**回滚**：`ops_gate=off` + `summary_guard=false` 即完全恢复 P31 行为；无需改代码。
