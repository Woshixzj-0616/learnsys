## 3. 后端：`POST /api/code/run`

### 3.1 新文件 `learnsys/server/routes_code.py`

```python
"""复习卡「运行代码」：薄转接沙箱，不复制执行逻辑。"""
from __future__ import annotations

from fastapi import APIRouter, Depends
from pydantic import BaseModel, Field

from learnsys.agent import sandbox
from learnsys.server.security import require_token

router = APIRouter()


class CodeRunIn(BaseModel):
    language: str = Field(default="", description="cpp / c / python；空=按代码推断")
    code: str = Field(min_length=1, max_length=100_000)
    stdin: str = Field(default="", max_length=10_000)


@router.post("/api/code/run")
def run_code(req: CodeRunIn, _=Depends(require_token)):
    result = sandbox.run(req.language, req.code, stdin_text=req.stdin)
    return {
        "ok": result.ok, "language": result.language,
        "command": result.command, "stdout": result.stdout,
        "stderr": result.stderr, "exit_code": result.exit_code,
        "timed_out": result.timed_out, "truncated": result.truncated,
        "duration_ms": result.duration_ms, "note": result.note,
    }
```

在 `learnsys/server/app.py` 的 `include_router` 区注册（`routes_review` 旁）。

### 3.2 约束

| 项 | 口径 | 理由 |
|---|---|---|
| 鉴权 | `require_token` | 与所有 `/api` 一致；不能变成无令牌执行入口 |
| 超时 | `sandbox.DEFAULT_TIMEOUT`（10 秒） | 复习场景可能要跑完整程序；不用 code_debug 的 5 秒短超时 |
| 语言 | 空值交给 `sandbox.run` 推断 | 错题 `language` 允许为空 |
| 长度 | code ≤ 100 KB，stdin ≤ 10 KB | 与 `sandbox.MAX_CODE_BYTES` 对齐 |
| 禁网/内存/临时目录 | **全部复用现有沙箱** | 不在路由里重复实现任何一条 |
| 并发 | 不加队列 | 本地单用户 + 令牌 + 10 秒上限；快速连点最多几个进程。记为已知限制 |

**不要**在路由里直接 `subprocess`，也不要把 `sandbox.run` 复制到 services——
沙箱是唯一执行落点，路由只做参数校验与结果转 dict。

## 4. 前端：错题本卡片

### 4.1 代码题展示（`web/js/pages/wrongbook.js::renderList`）

在 `wrong-card-body` 的「正确答案」前后插入：

```
${item.code ? `<div class="wrong-block wrong-code-block">
  <h4>代码 <span class="hint">${escapeHtml(LANGUAGE_LABEL[item.language] || item.language || "自动识别")}</span></h4>
  <pre class="wrong-code"><code>${escapeHtml(item.code)}</code></pre>
  <div class="wrong-run">
    <textarea class="wrong-stdin" rows="1" placeholder="标准输入（可空）"></textarea>
    <button class="btn" type="button" data-act="run">▶ 运行代码</button>
    <span class="wrong-run-status" aria-live="polite"></span>
  </div>
  <pre class="wrong-run-output" hidden></pre>
</div>` : ""}
${item.error_type || item.test_cases ? `<div class="wrong-block wrong-code-meta">
  ${item.error_type ? `<h4>错误类型</h4><p>${escapeHtml(item.error_type)}</p>` : ""}
  ${item.test_cases ? `<h4>关键用例</h4><pre class="wrong-cases">${escapeHtml(item.test_cases)}</pre>` : ""}
</div>` : ""}
```

- `LANGUAGE_LABEL = { cpp: "C++", c: "C", python: "Python" }`
- 代码一律 `escapeHtml`，**不走 markdown**（避免 `#`、`*` 被渲染成标题/列表）。
- 非代码题（`code` 空）不输出任何新块，卡片与现在完全一样。

### 4.2 运行代码（`wrongbook.js::act` 增加 `run` 分支）

```
点了「▶ 运行代码」
  → 从同一张卡片读 .wrong-stdin 的值
  → POST /api/code/run { language: item.language, code: item.code, stdin }
  → 结果展开在 .wrong-run-output：
      · 成功：stdout（没有输出就写「（无输出）」）
      · stderr 非空：追加「标准错误」段
      · 退出码 / 耗时 / timed_out / truncated 写一行状态
      · note 非空（编译失败、禁网拒绝、无运行时）：显示 note
```

- 按钮运行期间 `disabled`，完成后恢复；失败用 `toast(error.message)`。
- 不触发评级，不改任何数据——**运行代码是只读操作**。
- 语言为空时后端推断；前端不猜。

### 4.3 来源下拉与徽章

- `wrongbook.html` 来源下拉补 `<option value="code">代码调试</option>`、`<option value="cet6">六级断点</option>`。
- `wrongbook.js::SOURCE_LABEL` 补 `code: "代码调试"`（`cet6` 已有）。
- 后端 `routes_data/wrongbook.py` 的 add 白名单补 `code`（与 `store/wrongbook.py::WRONG_SOURCES` 对齐；
  agent 写库不走这个接口，但手动补录应允许同来源）。

### 4.4 样式（`web/css/review.css`，错题本样式在这里）

新增：`.wrong-code-block`、`.wrong-code`（等宽、深底、横向滚动、`max-height:320px`）、
`.wrong-run`（textarea + 按钮 + 状态一行）、`.wrong-run-output`（等宽、保留换行）、
`.wrong-code-meta`。桌面与窄屏（≤720px）都保证按钮不溢出。

**不做**

- 不做「运行结果 vs 期望输出」的自动判定（后续可做，需要结构化 test_cases）。

**风险**

| 风险 | 处理 |
|---|---|
| Web 端变成任意代码执行入口 | 需令牌；沙箱禁网、10 秒、内存限制、临时目录清理；只支持 cpp/c/python |

| 打包版缺 g++ | `sandbox.runtime_available` 已给中文原因；前端显示 note |

**回退**

- 代码回退：revert 提交即可；无数据/结构变更。
- 前端缓存：SW 版本号已升，回退代码时同步回退版本号。
