# R3.10 · Qt 设置页视觉对齐（默认深色）

> 用户拍板（2026-10-24）：**Qt 设置页默认深色**，视觉**仿照现在的 HTML 工作台**。
> 前置：R3.0–R3.9.1 已完成（`db832e4`），Qt 窗口功能 48/48，生产仍是 2.20.2。
> 本阶段只改 Qt 外观与尺寸，不改后端、不改 Web、不改交互口径。

## 0. 边界

**做：**

- `learnsys/ask/qt/style.py` 换成深色 QSS，默认深色，不做主题切换开关。
- 颜色、字号、间距、圆角**以 `web/css/tokens.css` 为唯一来源**，不在 Qt 里另抄一套数值。
- 设置页的控件尺寸/排布向 `web/css/settings.css` + `web/css/shell.css` 靠拢。
- 原生的下拉弹层、滚动条、复选框、提示框也要变深（否则会闪白）。
- 保留 R3 全部功能与测试；新增样式装载的单元测试。

**不做：**

- 不改 `web/css/*`、不改后端接口。
- 不引入 QML / WebEngine / 新的第三方主题库。
- 不做浅色主题切换（用户只要求「默认黑色」）。
- 不把 Web 页面塞进 Qt（Qt 仍是原生控件）。

## 2. Web 口径 → Qt 映射

### 2.1 页面与分组

| Web | 值 / 规则 | Qt 落地 |
|---|---|---|
| `.settings-page` | `max-width: 780px` | 内容区最大宽度 780，居中 |
| `.settings-section` | 下边距 36px | `Section` 间距 24–32px |
| `.settings-section h2` | `--fs-md` 16px / 600 | `SectionTitle` 16px / 600 / `--text` |

### 2.4 原生弹层（容易漏，漏了会闪白）

- `QComboBox` 下拉列表：`QComboBox QAbstractItemView { background: --bg-raised; color: --text; border: 1px solid --line; selection-background-color: --accent-soft; selection-color: --text; }`
- `QListWidget`：底 `--bg-sunken`，边框 `--line`，行间分隔 `--line`。
- `QScrollBar`：轨道 `--bg`，滑块 `--line-strong`，hover `--text-faint`，宽 10–12px。
- `QToolTip`：`--bg-raised` 底、`--text` 字、`--line` 边。
- `QMessageBox`（如果以后用）：跟随同一套 QSS；当前没有模态框，先不引入。
- 窗口标题栏是系统绘制的，Qt 无法改；**不承诺标题栏也变黑**，只保证窗口内容区默认深色。

## 3. 施工步骤

### R3.10.1 令牌装载器

- `learnsys/ask/qt/tokens.py`：
  ```python
  def load_tokens(text: str) -> dict[str, str]: ...   # 解析 :root { --x: y; }
  def default_tokens() -> dict[str, str]: ...          # 内置兜底（只放必要项）
  def read_web_tokens() -> dict[str, str]: ...         # 读 web/css/tokens.css，失败回退
  ```
- 解析只认 `--name: value;`，忽略注释与媒体查询之外的块；测试覆盖：正常、缺文件、空文件、值含逗号/括号（`rgba(...)`）。
- `styles.py` 的 QSS 模板用 `{bg}`、`{line}` 占位，装载后 `format_map`；**缺失键回退兜底**，不允许 KeyError。

### R3.10.2 深色 QSS

- 按第 2 节重写 `learnsys/ask/qt/style.py`（或拆 `style_dark.py`，由 `style.py` 统一导出）。
- 底色 `--bg`，卡片 `--bg-raised`，输入 `--bg-input`，按钮/焦点/状态按表。
- 字号：正文 15、标签 13、提示 12、分组标题 16、页标题 20。
- 间距：4 的倍数；分组间距 24；卡片内边距 16。
- 给 `SettingsWindow` 设 `QPalette`（Window/Base/Text/WindowText/Highlight 等）以覆盖原生弹窗的浅色默认。

### R3.10.3 尺寸与排布对齐

- `FieldRow` 左列 `setMinimumWidth(190)`；行间距按 Web。
- 内容区最大宽度 780，窗口默认 900×760（逻辑像素），最小 640×420。
- 记忆列表高度、按钮高度与 Web 对齐；模块两列间距 24。
- 检查高 DPI（125% / 150%）下不裁字、不挤压。

### R3.10.4 验证与重打包

- 单元测试：令牌解析 5 例、QSS 必需键齐全、窗口样式表非空、深色底实际生效（取渲染像素）。
- 现有 71 例 Qt 测试全过；后端 778 / 前端 16 / 六级 25 / ruff / 门禁。
- 进程内渲染 `window.grab()` 截图，与 Web 设置页截图并排对比，记录在 `R3-验收记录.md`。
- 重新打包 `dist-build`，打开打包版确认无白闪、下拉弹层是深色。
- 用户目视确认后再部署。

## 4. 验收口径

| 项 | 门槛 |
|---|---|
| 默认深色 | 打开即深色，不依赖系统主题；内容区无白底、无白闪 |
| 视觉一致 | 颜色/字号/圆角/控件高度与 `tokens.css` 对得上；与 Web 设置页并排不突兀 |
| 功能不回退 | R3 的 48 条功能全部仍可用，71 例 Qt 测试全过 |
| 单一来源 | Qt 不维护第二份完整配色表；改 `tokens.css` 重启即生效（或文档写明缓存时机） |
| 原生弹层 | 下拉列表、滚动条、列表、tooltip 均为深色 |
| 包体 | 增量 < 1 MB |

## 5. 风险

| 风险 | 处理 |
|---|---|
| 运行时读 `tokens.css` 在打包环境漏收集 | `web/` 已整体进包（spec `datas`），加测试在 `_MEIPASS` 下也能读到；读不到回退内置值 |
| QSS 不支持 `box-shadow` | 用边框色 + 2px 边框近似聚焦光晕；不追求像素级一致 |
| 系统标题栏仍是浅色 | 明确不承诺；若用户要求，再评估 `DwmSetWindowAttribute` 深色标题栏 |
| 深色下禁用态看不清 | 禁用用 `opacity` 或 `--text-faint` + `--bg-sunken`，逐项截图检查 |
| 高 DPI 下排版变化 | 150% 缩放实测；字段左列最小宽度用逻辑像素 |
