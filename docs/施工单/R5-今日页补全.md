# R5 · Qt 今日页补全面板

> 前置：R4 今日页（Hero / 插件舞台 / 统计条 / 行动卡）已随 2.21.0 部署生产。
> 目标：把 Qt 今日页补到与 Web 今日页**信息等价**：时间线 + 右侧四个面板 + 快捷入口，再做双栏响应式布局。
> 只改 Qt 页面与样式；不改后端接口、不改 Web 页面、不改学习数据。
>
> **状态（2026-10-24）**：已拍板——范围取「五面板 + 快捷入口」，时间线点击打开 Web 深链。R5.1–R5.4 已实现，待打包目视后部署。起点 `origin/v2` HEAD `958757f`、2.21.0，目标版本 2.22.0。

## 0. 边界

**做（R5.1–R5.5）：**

| 区域 | Web 对应 | Qt 落地 |
|---|---|---|
| 时间线 | `#today-timeline` | 今日最近 10 条问答：时间 + 问题（图片条带「图」标记）+ 180 字纯文本摘要；空状态；点击打开会话 |
| 本周 | `#week-body` | 活跃天数 / 专注时长 / 问答条数 |
| 专注 | `#focus-body` | 专注时长、窗口切换、按程序明细；无录制时给提示 |
| 六级断点 | `#cet6-panel` | 有数据才显示；点击回到 `#/cet6?paper=<paper_id>` |
| 成就 | `#achievements` | 已得优先，最多 8 条；标题右侧 `已得 / 总数` |
| 快捷入口 | `.shortcuts` | 问一个问题 / 去训练场 / 继续最近的会话 |
| 布局 | `.today-body` | ≥ 880 双栏（左时间线 + 右 292–320 侧栏）；< 880 上下堆叠 |

**不做：**

- Qt 内会话阅读器 / 输入框；时间线、快捷入口点击仍打开 Web 深链（`navigate(href)`），已有 Web 窗口时可能只聚焦 —— 与 R4 同一已知限制。
- 自动刷新、后台轮询。
- 深链桥、Qt 单窗口壳层（B 方案后置）。
- 不改 `/api/*`、不改 `web/`、不新增第三方依赖。

## 1. 数据来源（全部现有接口）

| 请求 | 本页用途 | 状态 |
|---|---|---|
| `GET /api/overview` | `week`、`achievements` | 已有请求，补渲染 |
| `GET /api/today` | `asks`（时间线）、`focus`（专注）、`cet6`（断点） | 已有请求，补渲染 |
| `GET /api/conversations?limit=8` | 「继续最近的会话」找最新有消息的会话 | **新增可选请求** |

- 现有必需接口失败口径不变：整页错误 +「重试」。
- `conversations` 失败不影响主内容；快捷入口降级为提示「还没有会话，先问一个问题吧」，状态行并入「部分数据没读到」。
- 所有请求复用 `learnsys/ask/qt/api.py`。

## 2. 视觉与尺寸

- 颜色/字号/圆角/间距全部走 `tokens.py` → `web/css/tokens.css`，不新增第二份配色表。
- 时间线：左侧 16px 轨道（1px `--line` 竖线 + 7px 圆点，圆点 `--mark`，图片条 `--accent`）；条目 hover 背景 `--bg-raised`；时间 12px `--text-faint`，问题 14px `--text`，摘要 13px `--text-faint` 两行截断。
- 侧栏面板：`--bg-raised` 底、`--line` 边、`--r-md` 圆角；面板头 13px/600 `--text-dim`，底部 1px 分隔；行 7px 上下内边距，左 `--text-dim`、右 `--text-faint` 12px，行间 1px `--line`（最后一行无线）。
- 成就行：已得 `--mark-soft` 底、未得整行 62% 不透明度；✓ / · 与 `value/target` 同 Web 口径。
- 快捷入口：透明底 + 1px `--line` 边、`--r-sm`；hover 边 `--line-strong`、底 `--bg-raised`。
- 双栏断点 880（与 R4 行动卡/插件卡断点一致）；右栏固定 320，左栏 `minmax(0, 1fr)` 效果用 stretch 2:0 实现。
- 窄屏堆叠顺序：时间线在上、侧栏面板在下。

## 3. 施工步骤

### R5.1 时间线

- `today.py` 增加纯文本摘要函数 `plain(text, limit=180)`，与 `web/js/markdown.js::plain` 同口径（代码块→`［代码］`、去 markdown 符号、压缩空白、超长截尾 `…`）。
- 时间格式 `timeOf`：`ts[11:16]`。
- 条目点击：有 `conversation_id` → `#/ask/<id>`；没有 → 状态行提示「这条是快捷栏问的，暂时只能在横栏历史里看」。
- 空状态文案照 Web：「今天还没有问答 / 从问一问开始，每个问题都会自动记进这条时间线。」
- 标题右侧计数「最近 N 条」。

### R5.2 侧栏四面板

- 本周：`active_days / 7`、`minutesParts(week.minutes)`、`week.asks 条`。
- 专注：`minutesParts(focus.minutes)`、`switches 次`、`apps` 逐行「程序名 / N 分钟」；无 `apps` 时提示「今天还没有开始录制。托盘里点「开始完整录制」才有专注数据。」
- 六级：`cet6` 非空才显示；每行「试卷 · 小节 · 条」+「N 个断点」；点击 `#/cet6?paper=<paper_id>`（缺失时用 `paper`）。
- 成就：`earned` 在前、未得在后，截前 8；头部 `已得 / 总数`；tooltip 显示 `desc`。

### R5.3 快捷入口

- 「问一个问题」→ `#/ask`；「去训练场」→ `#/netlab`。
- 「继续最近的会话」：取 `conversations.items` 里第一条 `messages > 0`；有 → `#/ask/<id>`，无 → 状态行提示并打开 `#/ask`。

### R5.4 双栏布局与响应式

- 行动卡之后新增底部区域：`QGridLayout`，左时间线（stretch 2）、右侧栏（固定 320）。
- `resizeEvent` 里按 880 断点重排：宽 → 左右两列；窄 → 时间线第 0 行、侧栏第 1 行。
- 侧栏面板纵向排布，间距 12；快捷入口距最后面板 16。

### R5.5 验证

- 单测（假 ApiClient）：时间线条数/空状态/图片标记/点击目标/`plain()` 边界；本周三行；专注明细与空状态；六级隐藏与点击；成就排序与截断；快捷入口有/无会话；880 断点重排；缺字段不崩。
- 回归：Qt 全部、后端全量、网页 16 / 六级 25、ruff、分层/体量门禁。
- 真实后台抓图：默认 1040×700、最小 760×560、有/无数据四种组合，与 Web 同尺寸并排对比。
- 打包 `dist-build`，`PrintWindow` 抓图；用户目视后再部署。

## 3.6 代码落点（实际）

- 新增 `learnsys/ask/qt/today_bottom.py`：底栏组装、五块渲染、快捷入口、880 断点堆叠。

- 唯一新增接口调用：`GET /api/conversations?limit=8`（可选，失败只提示「最近会话没读到」）。

## 4. 验收口径

| 项 | 门槛 |
|---|---|
| 信息等价 | Web 今日页出现的五块内容与三个快捷入口，Qt 都有对应展示 |
| 数据正确 | 每块内容与 `/api/*` 返回值逐项断言一致 |
| 空状态 | 时间线/专注/六级/成就各有明确中文空状态，不空白、不报错 |
| 交互 | 时间线条目、六级行、快捷入口都调用 `navigate`；无会话时提示 |
| 降级 | `conversations` 失败仍显示主内容；必需接口失败可重试 |
| 布局 | 1040 双栏、760 堆叠，无横向滚动、无文字裁切 |
| 可维护性 | `today.py` / `today_widgets.py` / `qss_today.py` 各 < 500 行；超限先拆文件 |
| 性能 | 数据到齐到渲染完成 < 100ms；RSS 增量 < 10MB |

## 5. 风险

| 风险 | 处理 |
|---|---|
| `today.py` 已 393 行，加入时间线与四面板易超 500 行门禁 | 面板控件全部进 `today_widgets.py`；数据组装留在 `today.py`，接近 500 行就拆 `today_panels.py` |
| QSS 画不了时间线竖线/圆点 | 用一个 16px 轨道控件：`QFrame` 竖线 + `QLabel` 圆点，颜色走令牌 |
| 成就行动态状态（已得/未得）QSS 不刷新 | 用动态属性 `earned` + `unpolish/polish`，或直接两个 objectName |
| 窄窗口侧栏被压扁 | 880 断点堆叠；760 最小尺寸抓图验收 |
| 时间线摘要把代码块当正文 | `plain()` 与 Web 同规则，先替换代码块再截断 |
