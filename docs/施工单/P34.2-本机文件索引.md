# P34.2 本机可读目录：后台增量索引

> 状态：已实现并部署 2.65.0（2026-11-07）。实现口径以本文为准。

## 一、问题

2.64.0 的 `search_local_files` 是「按需 `os.scandir` + 60 秒内存缓存」：

- 进程重启后首次搜索要重扫；
- `_scan()` 有 **3 秒截止 / 4 万条上限**，大目录会**静默漏文件**（正确性问题）；
- 索引只活在内存里，无法跨请求/跨重启复用。

## 二、方案

### 2.1 数据（schema 23 → 24）

`learnsys/core/db/schema_local_files.py`：

| 表 | 用途 |
|---|---|
| `local_files` | 每个文件的 root / path / name / name_l / path_l / ext / size / mtime_ns / indexed_at |
| `local_file_roots` | 每个白名单目录的 scanned_at / file_count / status（ok/missing/truncated/error）/ note |

- 只存元数据，不存正文；敏感文件与排除目录在入库前过滤。
- `indexed_at` 是本轮扫描时间戳，用「标记-清除」删除已消失文件，避免拼巨大的 IN 列表。
- 新表用 `CREATE TABLE IF NOT EXISTS`，老库直接升级，无需进 `migrate.py`。

### 2.2 服务：`learnsys/services/local_index.py`

唯一扫描落点。从 `agent/tools/local_files.py` 迁入白名单、路径解析、敏感判断；
工具反过来 import，不保留第二份规则。

| 函数 | 行为 |
|---|---|
| `roots()` / `resolve_path()` / `is_allowed_path()` | 白名单与路径判断的唯一来源 |
| `_iter_files(root, state)` | `os.scandir` 遍历；单根上限 20 万，触顶置 `truncated` |
| `reconcile(root, max_age)` | 增量同步：批量 upsert（每 200 条提交）→ 标记清除 → 写根状态；截断时不删旧行 |
| `tick()` | 新增根扫描、移除根清行、缺失根标 `missing` 保留行、过期根重扫 |
| `search(query, limit, suffix)` | 纯 SQL 查询 + 原打分；某根从未扫过时同步补扫一次 |
| `status()` | 根状态、总数、是否正在扫、刷新间隔 |
| `ensure_started()` / `shutdown()` / `wake()` / `rebuild()` | 线程调度，仿 `services/life/scheduler.py`；测试进程跳过 |

调度：启动后 5 秒首扫，之后每 `materials.index_refresh_s`（默认 120 秒，夹在 30–3600）；
设置页保存白名单后 `wake()`；「立即更新」走 `rebuild()` 强制重扫。

### 2.3 接口与界面

- `GET /api/local-index`：`{ok, scanning, total, interval_s, roots:[{root, scanned_at, file_count, status, note, scanning}]}`
- `POST /api/local-index/rebuild`：异步强制重扫。
- 设置页「本机可读目录」下方显示「已索引 N 个文件 · 最后更新 HH:MM」与「立即更新」；
  状态异常时悬停显示每个根的原因。

### 2.4 保持不变的边界

- 只读；目录外读取仍要确认；敏感文件/二进制/25 MB 上限不变。
- `materials.import_dirs` 仍是唯一白名单，不另存第二份。
- 工具入口裁剪不变：只有工作台问答页能用本机文件工具。

## 三、验收

- 全量并行测试 173 个文件全过；前端 50；`arch_report --check` / `layering_report --check` 退出码 0。
- 8766 隔离库真机：启动 `pending` → 7 秒后 `ok` 3 个文件；搜索命中；新增文件 + 重建 → 4 个；
  保存空白名单 → 索引清零、根列表为空。
- 生产 8765 = 2.65.0（见 `docs/2.65.0-发布说明.md`）。

## 四、不做什么

- 不索引正文、不做全文搜索；
- 不做跨进程索引锁（当前单服务进程）；
- 不给快捷栏/六级/录像放开本机文件入口。
