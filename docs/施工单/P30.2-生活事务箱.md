## 2. 数据层（schema 15）

在 `core/db/schema_personal.py` 追加（只做加法）：

```sql
CREATE TABLE IF NOT EXISTS life_items (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    title      TEXT NOT NULL,
    kind       TEXT NOT NULL DEFAULT 'todo',    -- todo / habit / note
    due_date   TEXT NOT NULL DEFAULT '',        -- YYYY-MM-DD；空 = 不限期
    status     TEXT NOT NULL DEFAULT 'open',    -- open / done / archived
    note       TEXT NOT NULL DEFAULT '',
    value      TEXT NOT NULL DEFAULT '',        -- habit/note 的一行轻记录
    done_at    TEXT NOT NULL DEFAULT '',
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_life_items_status
    ON life_items (status, due_date);
```

- `SCHEMA_VERSION = 15`；迁移只建表建索引，不动旧行。
- `value` 只存一行文本，不做结构化数值——「精力 3/5」也当文本，避免提前造追踪器。

新增 `learnsys/store/life_items.py`（**不改 personal.py**，它已 445 行、接近红线）：

```python
ITEM_KINDS = ("todo", "habit", "note")
ITEM_STATUSES = ("open", "done", "archived")
list_items(conn, *, status="open", limit=200)     # status="" 表示全部
get_item(conn, item_id)
add_item(conn, *, title, kind="todo", due_date="", note="", value="")
update_item(conn, item_id, **changes)             # 白名单字段
set_status(conn, item_id, status, *, ts="")
mark_done(conn, item_id) / reopen / archive
delete_item(conn, item_id)
due_items(conn, day, *, limit=20)                 # open 且 due_date != '' 且 <= day
item_counts(conn, day)                            # open / done / overdue
```

- 状态机只允许 `open→done→archived`、`done→open`、`archived→open`；非法转换由服务层拒绝。
- `mark_done` 写 `done_at`；`reopen` 清空 `done_at`。

## 4. 接口

新增 `learnsys/server/routes_data/life.py`（只鉴权/转接，SQL 全在 store）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/life/items?status=open&limit=200` | `status=all` 或空 = 全部 |
| GET | `/api/life/items/{id}` | 详情 |
| POST | `/api/life/items` | 新建：`title` 必填；`kind/due_date/note/value` 可选 |

| POST | `/api/life/items/{id}/reopen` | 重开 |
| POST | `/api/life/items/{id}/archive` | 归档（不物理删除） |

`routes_data/life.py`**（同一域一个路由文件），`home.py` 只保留首页/偏好/项目/订阅；
在 `routes_data/__init__.py` 聚合。行为不变，测试仍走原路径。

校验与错误：

- `title` 为空 → 400「事务标题不能为空」；

- `due_date` 非 `YYYY-MM-DD` → 400「到期日要用 YYYY-MM-DD」；
- 不存在 → 404「没有找到这条事务」。
