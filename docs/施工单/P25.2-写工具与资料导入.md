## 0. 一句话

## 1. 写工具（负责人拍板：4 个）

| 工具 | 入参 | 写入 | 暴露入口 | 确认文案 |
|---|---|---|---|---|
| `add_vocab` | `word`、`meaning`、`phonetic`、`context`、`source` | `vocab_items` + FSRS 卡 | 工作台、快捷栏、六级、录像 | 加进生词本：「word」— meaning |
| `delete_vocab` | `item_id` 或 `word` 二选一 | 删除 `vocab_items` + 复习卡 | 工作台 | 删除生词 #id「word」 |
| `rate_review` | `item_type`(wrong/vocab)、`item_id`、`rating`(1–4) | `review_state` + `review_log` | 工作台、快捷栏、六级 | 复习 错题 #id「题干前 40 字」：记得 |
| `save_training_error` | `question`、`my_answer`、`correct_answer`、`skill`、`source`(writing/translation) | `wrong_items` + FSRS 卡（懒补） | 工作台、六级 | 收进训练错题：「题干前 60 字」 |

### 1.1 安全与口径

- 四个全部进 `WRITE_TOOLS` **和** `CONFIRM_TOOLS`；用户拒绝后答案必须以「没有执行」收尾（沿用 P16.1）。
- `delete_vocab` 只按**精确词形**删除；找不到时返回最多 5 条相近词，不猜。
- `rate_review` 一次只评一张卡；模型必须先通过 `due_reviews` / `recent_wrong_items` 拿到 id，
  不许自己编号。评分 1 忘了 / 2 模糊 / 3 记得 / 4 简单。
- `save_training_error` 的 `source_id` 用「题干 + 我的写法」指纹去重；同一错误重复说只留一条。
- `add_vocab` 复用 `store.add_vocab`：同词只补空字段，不覆盖用户手填释义；新词明天到期。
- 不新增表、不改 schema。

### 1.2 入口裁剪（防止工具面膨胀）

| 入口 | 新增工具 | 工具总数（估算） |
|---|---|---|
| 速答 quick | 无（仍只有记忆） | 2 |
| 快捷栏 quickbar | `add_vocab` | 18 |
| 录像 video | `add_vocab` + 原有 `save_material_note` | 17 |
| 六级 cet6 | `add_vocab`、`save_training_error`、`rate_review` | 19 |
| 工作台 ask（非测验） | 四个全给 | 29 |

测验模式仍不给这四个（测验已有 `save_wrongbook`），避免一次答错同时进错题本和训练错题。

### 1.3 提示词

BASE 增加「学习写入纪律」四条：

1. 用户说「记一下这个词 / 加进生词本」→ `add_vocab`；已有就补空字段，不重复造词；
2. 用户说「这题我记住了 / 忘了」→ 先拿 id，再 `rate_review`，一次一张，不替用户批量评；
3. 用户说「把这个错误收进复习」→ `save_training_error`，原句、用户写法、正确写法分开填；
4. 删除生词前先让用户确认；用户拒绝写操作时不要假装成功。

## 3. MCP 写工具（P25 P2 评估结论）

**结论：本轮不加写工具，MCP 保持只读。**

理由：

1. MCP 客户端（Claude Code / Codex）没有工作台的确认弹窗，写操作缺少人工闸门；
2. 用「confirm=true 参数」代替确认，等于模型自己给自己授权，不满足 P16.1 的确认口径；
3. 工作台已有完整确认链路，MCP 的价值在「读上下文」而不是「替用户改数据」。

后续若要做，唯一可接受的形态是**提议箱**：MCP 写操作只落 `pending_actions` 表，
工作台插件页逐条确认后才真正执行；落到 P25.3 评估，不在本轮实现。
`docs/MCP接入.md` 同步写明这条结论。

## 5. 验收

**单测**

- `add_vocab`：新建 + 明天到期、同词合并补空字段、空词拒绝；
- `delete_vocab`：按 id / 按词精确删、找不到给相近词、复习卡同步删；
- `rate_review`：wrong/vocab 各一次、非法评分、不存在的卡、下次到期日合理；
- `save_training_error`：writing/translation 落库、指纹去重、缺题干拒绝、卡进复习队列；
- schema：四个入口的包含/排除、`CONFIRM_TOOLS`/`WRITE_TOOLS` 成员、确认文案含关键词；
- 拒绝写操作时答案不声称成功（沿用既有测试，补一条新工具）。

**真机**

- 工作台里说「把 ubiquitous 记进生词本，意思是无处不在的」→ 确认框 → 生词页可见、明天到期；
- 说「把这句错误收进复习：I go to school yesterday / 我写成 I went」→ 错题本可见、来源写作；
- `due_reviews` 拿一张卡 → `rate_review` 3 → 下次到期推进；
- 工作台说「把 ubiquitous 删掉」→ 确认框显示词形 → 生词页消失；
- 5 份资料上传后搜索、挂资料、出题各一次。

**门禁**：后端全量 / 网页 / 六级前端 / ruff / 体量 / 分层全过；
`agent_capability_report.py` 前后各跑一次，写工具数与资料数写进验收。
