# P18.2 · BKT 掌握度

> FSRS 管「何时复习」，BKT 管「懂没懂」。P18.1 已经把作答流水备好，本轮只做
> 掌握概率与展示；不做按知识点自动出题/排程，不做参数学习，不改今天页。
> 2026-10-23 开工，版本 2.15.0。

## 1. 取数口径

只用 `store.ready_attempts(conn, start_day)`：

- `source='quiz'`、`correct IS NOT NULL`、`points_source='model'`、`parse_ok=1`；
- 回填、兜底「其他」、判不出对错、格式异常都不进 BKT；
- 严格按返回的 id 顺序 fold（BKT 的对错更新不可交换）；
- 一题挂 k 个类目，就对 k 个类目各更新一次，不除以 k；
- 「其他」是兜底类目，不建模。

## 2. 模型

新 `learnsys/services/bkt.py`（纯函数，不碰 DB / FastAPI）：

```text
PARAMS = {p_l0: 0.1, p_t: 0.15, p_s: 0.1, p_g: 0.25}
MIN_SAMPLES = 5
WEAK_BELOW = 0.4
MASTERED_AT = 0.7

答对：p_post = p(1-S) / [p(1-S) + (1-p)G]
答错：p_post = pS / [pS + (1-p)(1-G)]
p_next = p_post + (1-p_post)T
clamp [0.001, 0.999]
```

- 空列表返回 `p_l0`；`correct=None` 显式抛错；分母有 1e-12 下限。
- `level`：不建模 / 未开始 / 样本不足 / 薄弱 / 在学 / 掌握。
- 参数写死为常量，`params_meta()` 暴露给 API，前端不硬编码 5 / 0.4 / 0.7。

## 3. 服务层

`services/knowledge.py::attempt_stats` 保持 P18.1 字段不变，追加：

- 每个类目：`mastery`（不足 5 条为 null）、`mastery_attempts`、`mastery_ready`、
  `mastery_level`；
- totals：`mastery_ready_points`、`average_mastery`（仅 ready 类目，不加权）、
  `weakest`（最低掌握度；并列时样本多者优先，再按 sort/id）；
- 顶层 `bkt` 静态说明块。

不改 `store.knowledge_stats()`、不改 `store.ready_attempts()`、不改路由。

时间窗口与计数一致：全部 / 近 30 天 / 近 7 天都从 `L0` 重新估算，页面写明
「掌握度按当前时间范围重新估算」。

## 6. 已知边界

- BKT 不建模遗忘：长期不练掌握度不会自动下降；FSRS 负责「何时复习」。
- 「其他」仍计入 P18.1 的 `bkt_ready`，但 `mastery_attempts=0`、不参与平均/最弱。
- 一题多类目共享同一次对错，是粗粒度取舍；以后可加主类目/权重。
- 5 条是产品展示门槛，不是统计置信区间；参数未拟合。
- 同一道题重复练 5 次也能解锁样本门槛；若出现刷题现象，再按 `question_key`
  加「不同题目数」第二道门槛。
