# R4 · 今日页 Qt 试点

> 前置：R3/R3.10 设置页已在生产（2.20.2 构建，深色）。
> 目标：用 Qt 原生控件复刻今日页的**首屏代表区域**，验证「卡片 / 统计 / 行动卡」这类信息页在 Qt 下的开发成本、启动速度、内存与可维护性。
> 只新增 Qt 页面与入口；不改后端接口、不改 Web 页面、不改学习数据。
>
> **状态（2026-10-24）**：R4.1–R4.5 已完成，验收见 `docs/施工单/R4-验收记录.md`；打包版已构建，**未部署生产**，等用户目视。

## 0. 边界

**做（R4.1–R4.5）：**

| 区域 | Web 对应 | Qt 落地 |
|---|---|---|
| 页头 | `today.html` 顶部 | 标题「今日」+ 日期 + 刷新 +「打开 Web 工作台」 |
| Hero | `.stage-hero` | 问候 / 主标题 / 副标题 / 今日学习点进度条 / 连续天数 / 等级 |
| 统计条 | `.stat-strip` | 专注、问答、课堂转写、今日计划 四格 |
| 行动卡 | `#today-actions` | 最多 3 张，点击打开对应 Web 页 |
| 插件卡 | `#plugin-grid` | `home=true` 且启用的插件，点击打开对应 Web 页 |
| 首次引导 | `#onboarding` | 只做一行提示条：未配置模型时显示「去配置」，打开 Qt 设置页 |
| 连接态 | — | 连接中 / 已更新 / 失败可重试 |

**不做：**

- 时间线、本周、专注明细、六级断点、成就面板 —— 留给 R4 之后（本轮只验证首屏代表区域）。
- Qt 内跨页导航：行动卡和插件卡**打开 Web 工作台**（`#/...` 深链）。已有工作台窗口时只聚焦、不保证跳转，这是本轮已知限制。
- 不改 `/api/*`、不改 `web/`、不新增第三方依赖。
- 不做自动刷新（手动「刷新」+ 每次打开窗口重新拉）。

## 1. 数据来源（全部现有接口）

| 请求 | 用途 | 必需 |
|---|---|---|
| `GET /api/overview` | 今日学习点/目标/连续/等级/周数据 | 是 |
| `GET /api/today` | 专注/问答/转写/到期/行动卡 | 是 |
| `GET /api/modules` | 插件清单（home、status、icon、order） | 否 |
| `GET /api/settings` | 模块开关、`agent.ready` | 否 |
| `GET /api/review/stats` | 今日已复习/下次到期 | 否 |

- 必需接口失败 → 整页错误 +「重试」；可选接口失败 → 用空默认值继续渲染，状态行注明「部分数据没读到」。
- 所有请求复用 `learnsys/ask/qt/api.py`（令牌从 `/api/health` 取，403 中文提示）。

## 2. 视觉与尺寸

- 颜色、字号、圆角、间距全部走 `learnsys/ask/qt/tokens.py` → `web/css/tokens.css`；不新增第二份配色表。
- 复用 `style.apply_theme()`（深色 QSS + QPalette）；新增的选择器写在 `style.py` 的 QSS 模板里。
- Hero：`--bg-raised` 底的卡片，`qlineargradient` 近似 Web 的墨蓝渐变；`--r-lg` 圆角；标题 30px/650，副标题 13px `--text-dim`。
- 统计条：一个 `--bg-raised` 外框 + 四个格子 + 分隔线；数值 28px/600，标签/备注 12px。
- 行动卡 / 插件卡：`--bg-raised` 底、`--line` 边、`--r-md` 圆角；hover 时边框 `--accent-line`、底 `--accent-soft`。
- 进度条：轨道 `--bg-sunken` + 1px `--line`，填充 `--accent`，高 9px、圆角 999。
- 窗口：默认 1040×700（逻辑像素），最小 760×560；用 `style.fit_size()` 按工作区收缩。
- 响应式：宽度 ≥ 880 时行动卡 3 列、插件卡 3 列；否则行动卡 1 列、插件卡 2 列。统计条始终 4 列。

## 3. 施工步骤

### R4.1 数据与窗口骨架

- 新增 `learnsys/ask/qt/today.py`（窗口、拉数、状态、刷新）。
- 新增 `learnsys/ask/qt/today_widgets.py`（HeroCard、StatStrip、ActionCard、PluginCard、进度条）。
- `TodayWindow(ApiClient, navigate=callable)`：`navigate(href)` 由入口注入，测试时替换为记录器。
- 单实例窗口 + 每次打开重新拉数据，与设置页一致。

### R4.2 Hero + 统计条

- 问候语按小时（夜深了/早上好/中午好/下午好/晚上好）。
- 主标题/副标题按 `today.percent` 与 `streak` 切换，口径照 `web/js/pages/today.js::renderHero`。
- 今日学习点、进度条、剩余点数、连续天数、等级徽章/标题/经验条。
- 统计条四格：
  - 专注：`minutesParts` 口径 + 切换次数；
  - 问答：`ask_count` 条 + 最近 10 条带图数；
  - 课堂转写：段数 + `charsParts`；
  - 今日计划：到期条数 + `reviewStats.reviewed_today/next_due`。

### R4.3 行动卡 + 插件卡

- 行动卡最多 3 张，编号 1/2/3，标题/说明/按钮文字；无卡时整段隐藏。
- 插件卡只取 `home === true && status === "ready"` 且未被 `settings.modules` 关掉的；按 `order` 排序；显示 icon/name/category/tagline/今日计数。
- 今日计数口径与 Web 一致：`ask` 问、`netlab` 训练、`cet6` 断点、`review` 复盘、`quiz` 测验。
- 点击：`navigate(href)`；插件为 `#/<id>`。

### R4.4 入口

- 托盘菜单新增「今日（Qt 试点）」。
- `--qt-today`：已有后台时只开窗口；没有后台时起服务再开窗（照 `--qt-settings`）。
- 首次引导条：`settings.agent.ready === false` 时显示「文本模型还没配好 → 去设置」，点击打开 Qt 设置窗口。

### R4.5 验证

- 单元测试（假 ApiClient）：Hero 文案/进度、统计四格、行动卡数量与点击、插件过滤/排序/计数、空状态、必需接口失败重试、可选接口失败降级、刷新、响应式列数、深色调色板。
- 回归：Qt 全部测试、后端全量、网页 16 / 六级 25、ruff、分层/体量门禁。
- 真实窗口 150% DPI 抓图（默认尺寸、最小尺寸、空行动卡、插件多卡），与 Web 今日页同尺寸并排对比。
- 打包 `dist-build`，`PrintWindow` 抓图确认；用户目视后再部署。

## 4. 验收口径

| 项 | 门槛 |
|---|---|
| 默认深色 | 与设置页同一套令牌，无白底/白闪 |
| 核心数据正确 | Hero/统计/行动卡/插件计数与 `/api/*` 返回值一致（单测逐项断言） |
| 交互 | 刷新可用；行动卡/插件卡点击调用 `navigate`；未配置模型能进设置 |
| 降级 | 必需接口失败可重试；可选接口失败仍显示主内容 |
| 功能不回退 | 设置页与现有 Qt 测试全过 |
| 可维护性 | 两个新文件各 < 500 行；不复制 Web 的 HTML/CSS |
| 性能 | 冷打开到首屏 < 300ms（本地后台）；RSS 增量 < 40MB |
| 导航限制 | 深链只打开 Web 工作台；已有窗口时可能只聚焦，文档写明 |

## 5. 风险

| 风险 | 处理 |
|---|---|
| Qt 布局在窄窗口挤压 | 880 断点切换列数；最小 760×560 抓图验收 |
| 插件图标是 Unicode | 直接 `QLabel` 显示；字体沿 `--font-ui` |
| 已有 Web 窗口不跳深链 | 本轮明确不承诺；下一阶段做 Qt 内导航或事件桥 |
| 可选接口慢拖住首屏 | 必需接口一到就渲染，可选数据到了再局部更新；状态行提示「部分数据加载中」 |
| QSS hover 不生效 | 卡片设 `WA_Hover`，QSS 用 `:hover`；抓图检查 |
