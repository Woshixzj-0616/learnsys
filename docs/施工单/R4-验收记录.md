## 5. 已知限制

1. **深链只打开 Web 工作台**：行动卡/插件卡调用 `workbench.open_or_focus`。已有 Web 工作台窗口时只聚焦，不保证跳到目标 hash；Qt 内导航或 Web↔Qt 事件桥留到下一阶段。
2. 时间线/本周/专注/六级/成就面板未做；今日页目前是「首屏仪表盘 + 插件入口」。
3. 不自动刷新；数据变化需点「刷新」或重开窗口。
4. 行动卡说明较长时可能换到 3 行（Web 用 CSS 裁 2 行）；不影响点击。
5. 系统标题栏仍是浅色（Qt 无法改），与 R3.10 结论一致。
6. 本轮没有测 Web 今日页的首屏耗时基线；R3 的设置页基线不能直接类比。性能栏只声明 Qt 侧。
