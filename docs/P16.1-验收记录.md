## 4. 已知粗糙点（留给打磨 / P16.2+）

1. **自检是结构核对，不是语义判断**：只查资料 id、页码、错题号、记录时间能否对上；内容是否真的支持结论仍靠模型与用户。页码只在工具输出里出现过的才算「可核对」。
2. **拒绝后模型仍可能口误**：实测出现「已记录」但实际未写。系统在答案末尾强制加「没有写入」提示，**没有做自动删句**；后续可在提示词里再加硬约束或做后处理。
3. **计划触发靠模型判断**：简单问题不计划（实测问「最近错了哪些题」时没有 plan），这是设计目标；若希望强制，可在设置里加开关。
4. **确认框是粗版**：网页用原生 `confirm`，横栏用 `QMessageBox`；没有做页面内卡片和「本次会话都允许」。
5. **横栏未真机点确认**：Worker 的确认信号与弹窗已编译、单元测试覆盖 loop 侧，但没有录屏验证 PySide 弹窗与线程等待的实际交互；P16.2 真机验收时一并做。
6. **重写耗时**：自检不通过才触发，实测未触发；若触发会多一次快模型调用（约 3–6 秒）。
