# 学习工作台 2.36.0 发布说明

> 2026-10-27 · P25.3 深度分析启用

## 新增

- 「问一问」页的**深度分析**按钮现在可用：显式点击才触发，调用强模型
  `deepseek-v4-pro`，返回带推理过程的独立答案。
- 配置只需要三行：`agent.deep.enabled=true` + `model=deepseek-v4-pro`；
  `api_base` / `api_key` **留空即复用主模型**，不新增第二份密钥。

## 口径

- 仍不自动触发，不混进主对话，结果不写问答/错题；
- 每次调用过每日预算（当前 10 元 / 300 次），并写 `agent_runs` 与 `model_usage`
  （`source=deep`），成本可在运行记录页看到；
- 命令模式（本地 Claude CLI）保留，填 `command` 即走命令。

## 验证

- 1089 后端 / 42 网页 / 30 六级前端，ruff、体量、分层门禁全过；
- 真机一次：21.7 秒，中文回答正确，账本 0.02898 CNY；
