## 4. 已知粗糙点

1. **单价要用户填**：内置不写死价格（模型名会变、地区价格不同）；没填时成本显示「未配置单价」，只统计 token。
2. **老运行记录**：P16.3 之前的行没有 `model_calls` / 工具耗时；面板会从 trace 反推工具次数，模型调用显示「模型未记录」，不假装精确。
3. **缓存写入按输入价计**：Anthropic 的 `cache_creation_input_tokens` 没有单独单价字段，暂按输入单价估算。
4. **运行输出保留 8KB**：属于审计证据；如果代码输出含隐私，用户可在运行记录里看到，也会落库。
5. **没有图表**：按天数据已返回，但面板先做表格，没画趋势图。
6. **统计窗口只按 started_at 截断**：最近 7 天是自然日，不是滚动 168 小时。
