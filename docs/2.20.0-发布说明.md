# 学习工作台 2.20.0 发布说明

> 2026-10-24。自动模型路由先做**影子模式**：记录「如果自动路由会选哪档」，不改实际模型。
> 起点 2.19.0（664 测试）→ 2.20.0（679 测试）。

## 1. 为什么

- 本机 `model = fast_model = deepseek-flash`，所有请求同一档，**没有办法按复杂度升级**。
- `routes` 手动映射只有代码、设置页没有入口；用户要调只能改 JSON。
- 主模型 == 快模型时，`fallback.py` 的降级链实际是空转。
- 直接开自动升级会新增 token 支出；先把「会选什么」记下来，再用数据决定阈值。

## 2. 这次做了什么

| 改动 | 落地 |
|---|---|
| 路由决策唯一落点 | 新增 `learnsys/agent/router.py`；`loop._speed_config` 也改为走它 |
| 三态开关 | `agent.auto_route = off / shadow / on`，设置页可选，默认 off |
| 强模型槽位 | `agent.strong_model`；空 = 升级时用主模型并多开思考 |
| 影子记录 | 决策写入 `agent_runs.trace_json`，流水页显示「实际 → 建议」 |
| 优先级 | 手动 speed（fast/deep）> 手动 routes > 自动路由；自动只影响 balanced 档 |
| 修旧 bug | ① 任务路由不再把 deep 打回“不思考 + 精简档”；② `agent_runs` 记录路由后的真实模型 |
| 设置页 | 新增「强模型」「自动路由」两项；`POST /api/settings` 校验三态 |

难度粗筛（`explain` / `guide`）：难度词命中 ≥3 记 3 分、2 个记 2 分、1 个记 1 分；
问题 ≥120 字 +1、≥300 字 +2；上下文/附件 ≥1500 字 +1；对话 ≥6 轮 +1；带图 +1。
总分 ≥3 建议 deep，否则 standard。**纯规则，不调用模型**。

## 4. 明确没做

- **不默认开启 on**：本机设 `shadow`，只积累数据；开源默认 `off`。
- **没有每日升级上限**：on 模式暂不限制，因为当前不启用；启用前要补预算闸门。
- **成本估算仍用单一单价**：`price_input/price_output` 不区分 flash / pro；on 前要补。
- 不引入模型分类器：多一次调用 = 多一份延迟和成本，规则式够用。
