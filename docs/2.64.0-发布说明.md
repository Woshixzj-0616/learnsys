# 学习工作台 2.64.0 发布说明

## 本机文件：agent 直接读，不用先导入

资料库以前只能读「已导入」的文件，课件放在磁盘上也答「资料库里没有」。
本期给 agent 加了两个只读工具：

| 工具 | 作用 |
|---|---|
| `search_local_files` | 在「本机可读目录」里按文件名 / 路径找文件，返回路径、大小、修改时间 |
| `read_local_file` | 按路径分段读正文；支持 txt / md / 代码 / PDF / Word / PPT |

找到路径就能读；**本机可读目录里的文件不需要先导入资料库**。
导入仍然保留，只用于精读、批注、术语表与提纲。

## 安全边界（第一版就定死）

- **只读**：不改文件、不移动、不删除；写仍只落「学习档案」。
- **白名单目录**：设置页「本机可读目录」最多 20 个；与资料批量导入共用
  `materials.import_dirs` 这一份清单，不另存第二份。
- **默认拒绝**：密钥 / 数据库 / 浏览器登录数据（`.env`、`*.pem`、`*.db`、`Login Data` 等）
  即使目录里有也不读；二进制文件拒绝；单文件上限 25 MB。
- **目录外读取要确认**：白名单内直接读；目录外弹确认框，同一个文件确认一次后
  后续分段读不再重复弹。
- **审计**：每次读取写 `数据目录/日志/本机文件读取.jsonl`（路径、字数、时间、会话）。
- **入口裁剪**：两个工具只给工作台问答页；快捷栏 / 六级 / 录像 / 测验不暴露本机文件。
