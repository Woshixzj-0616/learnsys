# 2.77.3 · 示意链接不再判伪造

> 2026-11-24。2.77.2 的延续：继续收紧「什么才算可核对的引用链接」。

## 用户可见

- 助手回答里出现 `http://xxx:8080/...`、`http://…` 这类**示意写法**时，
  不再被当成「伪造引用」触发无谓重写。
- 真实域名（主机名带点，如 `nginx.org`）的链接仍照常核对。

## 内核

- `agent/claims.py`：新增 `_has_real_host(url)`，主机名必须带点才算引用；
  `is_citation_url` 统一排除本机地址、占位示例与无点主机。
  `selfcheck` 与评测 harness 共用这一口径。

## 测试
