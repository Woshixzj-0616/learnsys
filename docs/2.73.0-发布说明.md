# 学习工作台 2.73.0 发布说明

> 2026-11-16 · 新增「智能旅行 Agent」统一入口 + 内置 AI 圆圈

## 这次改什么

### 一个入口：智能旅行 Agent

- 原「Agent 设计」「调用路径」两个侧栏入口合并为一个 **智能旅行 Agent**；
- 页内两个 tab：**Agent 设计** / **调用路径**；
- 右下角新增和英语页一样的 **AI 圆圈**（可拖、Ctrl+J、划词问 AI、对话 / 历史 / 新对话）。

### Agent 设计：设计原则 + 机制卡片

- 页内三个子 tab：**设计原则 / 机制卡片 / 自测**；
- 10 条设计原则，每条带「为什么 / 不这么做会怎样 / 业内不同做法 + 举例」；
- 13 张机制卡，按四组排：编排与工具 / 证据与审核 / 上下文与记忆 / 工程与评估；
- 每张机制卡带：问题 → 真实事故 → 代码落点 → trace 事件 → 取舍 → 业内不同做法 → 设计要点；
- 横向对照不再单开表，直接放进每条原则 / 每张卡里；
- 主列单列，卡片展开不会影响旁边；右侧 sticky 侧栏放「先看哪 / 当前展开 / 术语小抄 / 常见误区」。

### 调用路径：真实 trace + 直接对话

- 顶部可登录智能旅行，直接发消息；
- 发完自动刷新到最新 trace；
- 左侧 trace 列表，右侧摘要 / 横向路径 / 时间线 / 耗时分解；
- 「原始事件 + 字段解释」内联显示每个字段的中文说明，原始 JSON 收在最后一层；
- `direct` 轻量档补一条「直接流式」，模型次数 / 耗时不再显示 0。

### AI 圆圈参数化

- 英语页的 `ai-dock` / `ai-session` / `ai-view` / `ai-context` 支持
  `title / surface / module / page / titlePrefix / convKey / overlay`；
- 英语页默认行为不变（标题「六级 AI」、打开时让出 432px）；
- 智能旅行页传 `overlay: true`：抽屉浮在上面，**不压缩页面**；
- AI 上下文会带当前机制 / 原则正文，或当前 trace 的 summary / spans / path / detail。

## 数据 / 接口

- 无 schema 变更；
- 新增只读接口 `GET /api/agent-trace`、`GET /api/agent-trace/{trace_id}`；
- 新增本机代理 `POST /api/agent-trace/login`、`POST /api/agent-trace/chat`：
  只允许 `127.0.0.1 / localhost` 的 **8000 / 8001** 智能旅行后端，防 SSRF；
- 旅行库默认 `D:\Desktop\智能旅行\backend\travel.db`，可在 `设置.json` 的
  `agent_trace.travel_db` 覆盖，或设 `LEARNSYS_TRAVEL_DB`；
- SW 缓存版本 `v76 → v77`，预缓存新增 3 个页面 + 6 个前端模块。
