# 学习工作台 2.23.0 发布说明

> 2026-10-24。**B1 深链桥**：Qt 今日页/托盘点击深链时，已经打开的 Web 工作台窗口也会跳到目标页，不再只是「聚焦但不跳」。
> 起点 2.22.0（835 后端 + 127 Qt + 16 网页 + 25 六级）→ 2.23.0（860 后端 + 23 网页 + 25 六级）。

## 1. 为什么

- 2.22.0 的 Qt 今日页点时间线/行动卡/六级断点，只会 `open_workbench_link` 把已有 Web 窗口提到前台，**不保证跳到目标 hash**——用户看到的是「窗口来了，页面没变」。
- 不做全量 Qt 窗口壳层（B2）之前，先用最小改动把「点击 → 目标页」补通：Qt 写一条待跳转，Web 壳自己拉取并应用。

## 2. 这次做了什么

| 改动 | 落地 |
|---|---|
| 待跳转队列 | 新增 `learnsys/server/nav_bridge.py`：`server id` + 递增 `seq` + 30 秒 TTL；只接受 `#/` 开头的内部 hash |
| 接口 | `POST /api/ui/navigate`（写）、`GET /api/ui/navigate`（读）；沿用本地令牌与同源校验，非法 href 返回 400 且不覆盖上一条 |
| Web 壳 | 新增 `web/js/nav_bridge.js`：前台每 2 秒轮询 + `focus`/`visibilitychange` 补拉；按 `server+seq` 增量应用，后台重启归零不误跳 |
| Qt 深链 | 有 Web 窗口 → 先写队列再聚焦；没有 → 新开窗口直接带 hash |
| 窗口身份 | `workbench.py` 增加浏览器进程判定：标题同样以「· 学习工作台」结尾的 Qt 窗口不再被误认成 Web 窗口 |
| 回归修复 | 排查中发现并补回 `focus_window` 的 `ShowWindow(SW_RESTORE)`（此前替换时误删） |

## 4. 明确没做 / 已知限制

- **不是「只跳目标窗口」**：待跳转 30 秒内广播给所有打开的工作台页面；典型单窗口无影响。ack/认领机制本期不做。
- **未做 B2 Qt 单窗口壳层**：Qt 仍是试点入口，Web 工作台仍是主界面。
- Edge 后台窗口会被冻结，聚焦后恢复；真实点击会先聚焦，冻结即解除。
- 后台重启后旧页面令牌失效需刷新（既有行为，不是本次引入）。
- 打包版**托盘菜单**未真人点过（Qt 今日页窗口已用打包版真人点击）；125% DPI 仍待补验（沿用 2.21.0 的遗留项）。
