# 学习工作台 2.43.0 发布说明

> 2026-10-28 · 今日页减法重排 + Qt 今日页同步

## 这次改什么

### 今日页：从 4.5 屏收到 1.8 屏

按「只放今天会变的内容」重排：

- **今日简报升为 Hero 下面的整幅横条**：1 条主稿（标题 + 两行摘要 + 来源/时间）+
  3 条次条，右上「已生成 / 来源数」和「打开简报 →」；
- **问答时间线改成按时段分组的会话轨道**：晚上 / 上午分组，左侧竖轨 + 节点，
  问句 + 两行摘要；普通问答蓝点、图片橙点、代码绿点；最多展示最近 6 条；
- **「接着上次」成为唯一主卡**：原「今天还可以」行动卡并入主卡底部「也可以」，
  同一份试卷不再重复出现（后端 `_today_actions` 按今日试卷 id 去重）；
- **删掉**：所有工具网格（侧栏已有一份）、四统计格（并成本周卡底部「今天」一行）、
  六级断点面板（并入接着上次）、无数据时的专注面板；
- **成就折成一行**：显示「已得 / 总数 · 下一项」，点开才展开；
- 右侧「本周 + 今天一行 + 成就」吸顶，长页面滚动时保持可见；
- 工作场景保留：学习场景显示六级主卡，工作场景换成 Agent 中枢入口。

### Qt 今日页同步

- 结构、文案、数据口径与 Web 一致：Hero → 简报横条 → 接着上次 + 问答轨道 / 本周 + 成就折叠；
- 新增原生简报横条、问答分组轨道、今天一行、成就折叠；
- 删除插件网格、统计条、行动卡、六级面板、专注面板、快捷入口；
- 加载接口减为 `/api/overview`、`/api/today`、`/api/settings`、`/api/briefing/today`；
- Qt 字体族跳过 `-apple-system`，Windows 直接用「Microsoft YaHei UI」。

## 数据 / 接口

- 无 schema 变更；
- `/api/today.actions` 新增去重：同一份试卷当天已经出现在 `cet6` 里时，
  不再发「接着昨天的听力断点」卡；
- `/api/briefing/today` 继续供 Web / Qt 简报横条使用。

## 新增门禁

- `tests/test_today_layout.py`：今日页顶层结构检查——禁止 `plugin-grid`、
  统计格、六级面板、`today-lower` 等旧块回潮；简报必须在双栏之前；
  时间线必须按组渲染且只取摘要。
- `docs/架构-前后端.md` 新增「今日页准入」：常设导航 / 工具清单 / 成就全集不进今日页；
  同一事实只允许一个落点；空态模块默认隐藏；列表不展示正文。
