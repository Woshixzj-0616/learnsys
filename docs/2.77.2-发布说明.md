# 2.77.2 · 链接误判修复（只发内核修复）

> 2026-11-24。只保留已验证的链接核对修复；未闭环的提示词改动回滚，不在本版发布。

## 用户可见

- 助手回答里出现本机地址（`127.0.0.1` / `localhost`）或占位示例域名（`example.com/org/net`）时，
  不再被当成「伪造引用」触发无谓重写；真实网页链接的核对规则不变。

## 内核

- `agent/claims.py`：新增 `is_citation_url(url)`，作为「链接是否参与引用核对」的唯一口径
  （排除本机地址与占位示例）；尾部标点剥离集合补反引号。
- `agent/selfcheck.py`：答案里的链接先过 `is_citation_url` 再核对，避免示例链接误判。

## 未包含（已回滚）

- 否定轮「已排除」注入与强制首行（`correction.negation/exclusions`、`NEGATION_RULE`）。
- 前缀表达式 `&(a,b)` / `|(a,b)` / `!(a)` 识别规则。
- 禁止附和、禁止编无来源规则。

原因：在线实测均未闭环——siege 第 3 轮仍在本机找 Java 容器、第 4 轮才停；
logic-or 第 1 轮识别前缀，第 2 轮被用户一推就编「多数题允许单参数」。
按「第 3 次不收敛停手」处理，转多轮负例回归集后再修。
