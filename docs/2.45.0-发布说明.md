# 学习工作台 2.45.0 发布说明

> 2026-10-29 · 个人 AI 工作台 + 学习闭环：收进复习 → 编程类目 → 复习时能跑代码

## 这次改什么

### 今日页变成个人工作台

- 学习 / 工作 / 生活三张域卡：学习看今日目标与到期复习，工作看进行中任务，
  生活看订阅与待办；数据来自同一个 `services/home.py`；
- Agent 每轮问答带上「个人状态」串（≤600 字，60 秒缓存），回答能结合今天的三格进度、
  卡点、项目和生活事项；
- 打开工作台默认回到今日页（P27.2）。

### 收进复习：一个入口，三处可用

- 测验判错、代码调试定位到错误、用户主动说「收进复习」，都走同一个 `save_wrongbook`；
- 错题支持代码题四个字段：`code / language / error_type / test_cases`；
- 保存后立即进 FSRS 队列（明天到期），不再等第二天扫描；
- 代码调试结束主动提议一次，回复「收进复习」才弹确认卡，不自动写。

### 编程类目并入同一套知识点

- 知识点类目 8 → **13**：英语 7 + 编程 5（数据结构、算法、`C/C++`、计算机网络、操作系统）+ 其他；
- 与英语类目共用同一张表、同一套 BKT、同一份提示词；同一道题只能选同学科的 1–3 个类目；
- 旧库打开时自动补 5 行（`knowledge_seed_version`），**不改**任何旧答题、旧错题 tags；
  表结构未变，`SCHEMA_VERSION` 仍是 13。

### 错题本：看得到代码，也跑得起来

- 错题卡片直接展示代码块（标注 C++ / C / Python）、错误类型、关键用例；
- 「▶ 运行代码」就地调用同一个沙箱（禁网、10 秒、内存上限、临时目录），
  内联显示标准输出 / 标准错误 / 退出码 / 耗时；
- 运行是只读操作：不写错题、不记学习点、不触发评级；
- 来源筛选新增「代码调试」「六级断点」。

### 今天该复习什么，首页就能看到

- 今日页 Hero 下新增窄提醒条：「今日 N 张到期 → 去复习」，到期为 0 时隐藏；
- 点进去就是错题本「待复习」，在卡片里直接评级（忘了 / 模糊 / 记得 / 简单）。

## 数据 / 接口

- `SCHEMA_VERSION` 仍 **13**；生产库首次打开会从 11 迁到 13（P27 四表 + 错题代码四列）；

- `/api/wrongbook` 的手动补收允许 `source=code / cet6`，并接收代码四字段。
