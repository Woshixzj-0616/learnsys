# 学习工作台 2.65.0 发布说明

## 本机文件搜索：后台索引

2.64.0 的搜索是「每次按需扫目录 + 60 秒内存缓存」：进程重启要重扫，大目录还会因为
3 秒截止 / 4 万条上限**漏文件**。2.65.0 改成后台增量索引：

| 之前 | 现在 |
|---|---|
| 首次搜索扫盘，目录大时慢 | 搜索只查库，索引由后台线程维护 |
| 重启后重新扫 | 索引落统一库，重启不重扫 |
| 3 秒 / 4 万条截断，可能漏 | 单根最多 20 万个文件；触顶会明确标「只索引了前 20 万」 |
| 新建文件要等下一次按需扫描 | 后台默认每 2 分钟同步；设置页可点「立即更新」 |

索引只存**文件名 / 路径 / 大小 / 修改时间**，不存正文；正文仍由 `read_local_file`
按需分段读取。敏感文件、排除目录在入库前就过滤，库里不会出现 `.env` / `*.db` /
浏览器登录数据。

## 页面

- 设置 →「本机可读目录」下方新增索引状态：
  「已索引 N 个文件 · 最后更新 HH:MM」以及「立即更新」按钮；
  目录暂时不可用 / 文件过多 / 扫描出错时会显示中文原因。
- 保存白名单后索引立即开始处理新增或移除的目录，不需要重启。

## 数据与兼容

- schema 23 → 24，新增 `local_files` / `local_file_roots` 两张表；只做加法，旧数据不动。
- `materials.import_dirs` 仍是唯一白名单，与资料批量导入共用。
- 新增可选设置 `materials.index_refresh_s`（默认 120 秒，30–3600）。
- 读取的安全边界不变：只读、目录外确认、敏感文件/二进制/25 MB 拒绝、读取审计日志。
