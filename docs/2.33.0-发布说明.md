# 学习工作台 2.33.0 · Agent 补齐学习数据域与能力体检

> 2026-10-26 · 生产 8765 已运行 2.33.0
> 上一版 2.32.0（六级写作题库扩容：首句续写）

## 新能力

### 1. Agent 能读全部学习数据了

新增四个只读工具：

| 工具 | 回答什么问题 |
|---|---|
| `due_reviews` | 「今天该复习什么」「有哪些到期」——错题/生词同一套 FSRS 排期 |
| `get_mastery` | 「我最弱的知识点」「阅读掌握得怎么样」——BKT 掌握度、样本数、等级 |
| `get_train_summary` | 「写作练得怎么样」「档位有没有提高」——连续天数、档位趋势、错误画像 |
| `list_recordings` | 「我录过哪些课」「找一段讲 X 的录像」——时长、转写量、开头片段 |

之前 P18（知识点）、P23（录像）、P24（写作翻译）都只做了页面和接口，
Agent 看不到这些数据；现在七个学习数据域都有读工具（能力体检会检查这条）。

### 2. 模型账本补漏

- `agent/usage.py` 成为 `model_usage` 的唯一写入口；主对话、自检重写、看图、
  深度分析全部记同一本账。
- 深度分析执行前先过每日预算（之前只在主对话前检查）。
- 账单没配单价时仍显示「未配置单价」，不猜价格。

### 3. 工具按入口裁剪

| 入口 | 工具数 | 说明 |
|---|---|---|
| 工作台问答页 | 23 | 唯一能打开文件 / 启动程序 / 跑代码的入口 |
| 快捷栏 | 15 | 只留学习读取 + 记忆；不再放本机文件和代码执行 |
| 六级训练 / 录像 | 16 | 学习读取 + 记忆 + 存资料笔记 |
| 速答模式 | 2 | 只留长期记忆，避免一两句话带二十多个工具 |

这是一处**行为变化**：快捷栏不再直接打开文件/启动程序；需要这些操作请到工作台问答页。

### 4. 能力体检（长期监控）

```bash
python tools/agent_capability_report.py          # 五断面报告
python tools/agent_capability_report.py --save   # 更新基线
```

口径与判定规则：`docs/施工单/Agent-能力监控.md`；基线：`docs/agent-capability-baseline.json`。
以后每次动 Agent 前后各跑一次，工具面新增数据域必须同时有读工具。
