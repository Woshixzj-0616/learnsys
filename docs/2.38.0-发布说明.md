# 学习工作台 2.38.0 发布说明

> 2026-10-27 · P26.1 界面改版：三套气质 + 四类页面模式 + 今日页重排

## 这次新增什么

### 1. 三套界面气质

- **晨雾**（浅灰蓝，默认）/ **墨夜**（深色）/ **纸感**（米黄暖色）；
- 全部颜色收敛到 `web/css/tokens.css` 的 `:root`，页面组件只引用令牌；
- 旧变量名（`--ink` / `--muted` / `--danger`）保留别名，未改到的页面不会突然变色；
- Qt 原生窗口（快捷栏 / 今日页）运行时读同一份 `tokens.css`，不再抄第二份颜色表。

### 2. 四类页面模式

右上角「模式」面板，状态只有一个落点 `web/js/modes.js`：

| 模式 | 取值 | 作用 |
|---|---|---|
| 气质 | 晨雾 / 墨夜 / 纸感 | 全局配色 |
| 页面 | 标准 / 专注 | 专注模式隐藏侧栏与次要区块，Esc 退出 |
| 场景 | 学习 / 工作 | 今日页内容与入口按场景切换 |
| 视图 | 卡片 / 列表 | 列表更密，适合快速扫 |
| 密度 | 舒适 / 紧凑 | 间距与行高整体缩放 |

- 选择存 `localStorage`，刷新后保留；`learnsys:modes` 事件供各页面自行响应；
- 深链可直达：`?mood=ink&scene=work&view=list&density=compact&focus=1`；
- `modes.css` 从 `shell.css` 拆出（避开 600 行门禁），`shell.css` 只留骨架。

### 3. 今日页重排

- 新顶栏 + 周柱状图（数据来自 `/api/overview` 新增的 `week.daily`）；
- 今日学习点、待复习、最近问答重排为卡片/列表两种视图；
- 「工作场景」入口：切到工作模式时展示不同区块；
- 问一问页同步新壳（会话栏 / 消息卡 / 输入区）；
- 资料 / 录像 / 错题本 / 生词本 / 设置 / 中枢 / 运行记录 / 浏览器 / 插件中心 / 训练场 / 知识点 / 测验 / 复盘统一走 `stage-hero` + `panel` 新壳。
