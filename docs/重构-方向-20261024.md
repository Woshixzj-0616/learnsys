# 重构方向决策 · 2026-10-24

> 拍板范围：**保留混合架构 + 单页 Qt 试点**；不做全量 Qt 重写，不把后端改成 Qt。
> 首要目标（用户多选）：可维护性、原生体验 / 单一窗口、降低长期成本。

## 1. 背景

用户提出「对整个项目进行重构，并把项目转换为 Qt 的形式」。当前项目已经是混合架构：

| 部分 | 现状 |
|---|---|
| 横栏 Alt+Q、托盘、截屏、框选、快捷栏 | Qt（PySide6） |
| 工作台 22 个页面 | Web（HTML + ES module；5,020 行 JS / 2,405 行 CSS） |
| 六级精听 | 独立 HTML/JS，嵌在 `/cet6/` |
| 后台 / MCP | FastAPI + SQLite，`127.0.0.1:8765`；Claude Code / Codex 通过 MCP 接入 |

所以「转 Qt」实际是「是否把内容量最大的 Web 工作台重写成 Qt」。

## 2. 决策

1. **不做全量 Qt 重写**。理由见第 3 节。
2. **重构与换 UI 拆成两件事**：先做后端架构加固与边界清理，再用单页试点验证 Qt。
3. **Qt 试点只选一个页面**，按可量化的验收指标决定是否扩大；不一次性押注。
4. **保留 Web 工作台、PWA、HTTP API 与 MCP**：它们是远程访问、插件页和 Claude Code 接入的基础。

## 3. 为什么不全量 Qt

| 维度 | 全量原生的代价 |
|---|---|
| 页面量 | 22 个页面、5,020 行 JS、2,405 行 CSS 重写 |
| 富内容 | Markdown / KaTeX 公式 / 代码高亮 / 表格；Qt 原生富文本不支持 KaTeX，绕不开 `QWebEngineView`，等于又回到 HTML |
| 六级精听 | 152 句音频切分、循环、分析面板要重做 |
| 插件机制 | `plugin.json` + HTML 页 → Widget 工厂 + 重新编译 |
| 生态 | PWA、手机/远程打开、浏览器调试、MCP 全部要重新设计或丢失 |
| 工期 | 保守 3–6 个月业余时间，期间功能停摆 |
| 收益 | 单栈、原生观感、少一层 localhost/token/Origin、打包更简单 |

**后端不需要 Qt 化**：Qt 是 GUI / 事件框架；把 HTTP 换成信号槽会直接切断 MCP、PWA 与远程访问。

## 4. 三个阶段

### R1 · 后端架构加固（5–8 个工作日）

| 任务 | 验收 |
|---|---|
| 拆 `agent/loop.py::run()`（当前 327 行，文件 498/500） | `run()` < 120 行、`loop.py` < 400 行；事件顺序不变；全量测试 + 事件序列测试 |
| CI 补齐 | 后端 unittest + `web/tests/*.mjs` + `cet6-src/workbench_src/tests/*.mjs` + `ruff --select F,E9` |
| schema 版本号 | `PRAGMA user_version`；版本一致时 `connect()` 不再跑 DDL/补列/种子 |
| 部署脚本 | `tools/deploy.py`：停守护 → 停进程 → 备份 → 换目录 → 启动 → 健康检查 → 恢复守护；支持 `--rollback`、`--dry-run` |
| 核心层静默异常 | 只处理核心层的 `except Exception: pass`，写 `启动错误.log`；清理类保持不动 |

### R3 · Qt 试点（3–5 天 + 观察 1 周）

> 施工单：[施工单/R3-Qt试点](施工单/R3-Qt试点.md)（设置页，R3.0–R3.9）。

试点顺序：

1. **设置页**（`web/js/pages/settings.js`，292 行）：表单型、风险最低，验证 Qt 表单/校验/密钥掩码。
2. 若设置页达标，再试点**今日页**（卡片/统计/行动卡），验证代表性。
3. 资料/错题/测验这类富内容页**不参加首轮试点**。

验收指标（全部满足才扩大）：

| 指标 | 门槛 |
|---|---|
| 功能对齐 | 试点页功能清单逐条通过 |
| 开发耗时 | ≤ Web 版同页的 1.5 倍 |
| 内存 / 启动 | 不高于现有工作台 |
| 打包体积 | 增量可接受 |
| 可测试性 | 有自动化测试，不靠人眼看 |
| 现有能力 | PWA、远程、MCP 不受影响 |

试点放在独立入口（例如托盘「设置（Qt）」），默认不替换 Web 页；达标后再逐页替换。

## 5. 风险与回滚

- **不冻结功能**：R1/R2 只动结构，不改行为；每个任务单独提交。
- **生产替换**：沿用现有流程，替换前备份 `dist\学习工作台-<版本>-backup`。
- **Qt 试点失败**：删除试点入口即可，不影响 Web 工作台。
- **成本控制**：R1 与 R2 结束后各停一次，评审后再进入下一阶段。

## 6. 总验收

- 后端测试 ≥ 现有 683；新增事件序列、分层、连接版本、部署脚本测试。
- CI 在 Windows 上跑通后端 + 两套前端测试 + ruff。
- `loop.py` 与 `run()` 达标，体量门禁不再贴线。
- 包级反向依赖为 0。
- Qt 试点有量化报告，再决定是否扩大。
