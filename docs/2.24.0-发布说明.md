# 学习工作台 2.24.0 发布说明

> 2026-10-24。**模型调用账本与每日上限**：每次成功调用按模型记一行 token 与成本，设置页可按模型填单价、设每日花费/调用上限，超限整轮不发模型请求。
> 起点 2.23.0（860 后端 + 23 网页 + 25 六级）→ 2.24.0（875 后端 + 23 网页 + 25 六级）。

## 1. 为什么

- 2.20.0 起 `auto_route` 影子模式会在 `agent_runs` 里记录「建议升到强模型」，但**没有钱的口径**：不知道一次运行花了多少、按模型分别花多少，也不知道一天总共花了多少。
- 没有账本就无法安全地把自动路由从 `shadow` 切到 `on`：强模型单价是 flash 的数倍，一次跑飞可能产生意外账单。每日上限必须先有落地检查点。

## 2. 这次做了什么

| 改动 | 落地 |
|---|---|
| 调用账本 | 新表 `model_usage`：每次成功调用一行，按模型记 prompt / 未命中 / 缓存读 / 缓存写 / 输出 / total token、成本、币种；`store/model_usage.py` |
| 单价 | `agent/cost.py::price_for` 按模型取价（`agent.prices` 覆盖全局 `price_*`）；没配单价时明确显示「未配置单价」，不猜价格 |
| 每日上限 | `agent/budget.py::check` 硬拒绝；唯一检查点在 `agent/loop.py::_prepare`，超限整轮不发模型请求（连首 token 都不发） |
| 记账唯一落点 | `agent/turn.py::_record_usage`：用 `cfg.data_root` 开库（测试不会写生产库）；`done` 事件带 `usage_by_model` / `cost` |
| 数据库版本 | `SCHEMA_VERSION` 1→2，`user_version` 门禁升级 |
| 设置页 | 网页 + Qt 都新增「模型单价」表（模型 / 输入 / 输出 / 缓存命中）与「每日花费上限」「每日调用上限」 |
| 运行记录页 | 顶部新增「今日调用 / 今日花费」；按模型聚合 |
| Qt 回归 | 修 `QTableWidget` 白底，深色主题下表格不再刺眼 |

## 4. 单价口径（2026-10-24 官方页）

DeepSeek 官方价格分空闲/高峰两档（空闲价为高峰价一半；高峰＝北京时间工作日 9–12、14–18 点）。账本每个模型只存一个价，**默认按高峰价填**，宁可高估也不让每日上限被突破。

| 模型 | 输入（未命中） | 输出 | 缓存命中 |
|---|---:|---:|---:|
| `deepseek-flash` | 2 元 | 8 元 | 0.04 元 |
| `deepseek-v4-pro` | 9 元 | 27 元 | 0.30 元 |

单位：元 / 百万 tokens。全局默认价设成 flash 高峰价，未知模型名不会算成 0。

## 5. 明确没做 / 已知限制

- **只统计 `agent.run` 调用**：测试连接、文本处理、深度分析 CLI 不计账。
- **上限按已完成调用算**：单轮最多超出一条用量（例如上限 10 元，历史 9.99 元时还会放行一次）。
- **没有分时计价**：使用单档价格；显示成本通常高于实际账单约 20%–100%，上限因此偏保守。
- 每日上限默认 0（不限）；本机已设为 10 元 / 300 次。
