# 学习工作台 2.47.0 发布说明

> 2026-10-30 · 生活助手：订阅中心、生活事务箱、创作库

## 这次改什么

### 生活订阅中心 `#/life`

- 侧栏新增「生活」组，「生活订阅」页集中管理主题、类型、频率、时间与来源；
- 新闻订阅**只筛选当天的每日简报**（不重复抓 RSS、不耗模型），简报未生成时不会落空卡；
- 每日一词 / 自定义订阅各调用一次模型，结果写进当天卡片；
- 到期自动生成（5 分钟检查、失败退避 30 分钟），也可以手动「现在生成」；
- 同一天同一主题只更新一张卡；卡片可标记已读；今日页生活卡显示「待办 / 卡片」并直达本页；
- **价格 / 行情两类暂不支持**：没有行情数据源，界面明确标注，不编数据。

### 生活事务箱（同页）

- 单层待办：标题、类型（待办 / 作息记录 / 备注）、到期日、一行记录、备注；
- 状态 `未完成 → 已完成 → 已归档`，可重开、编辑、删除；
- 到期与逾期事务进入首页生活域「每日提醒」和 Agent 每轮个人状态；
- 作息 / 精力只做一行轻记录，不做健康追踪图。

### 创作库 `#/art`

- 作品档案：标题、完整提示词、风格预设、模型、日期、备注、本地图片；
- 风格预设可复用（正向描述 + 反向词），删除预设不会删作品；
- 图片先上传到工作台数据目录，作品页按 id 安全回显；
- **从豆包粘贴导入**：按空行分块，支持「标题 / 提示词 / 风格 / 模型 / 备注」标签；
  无标签时首行当标题；风格名命中已有预设就复用，否则自动建档；
- 作品支持归档 / 恢复 / 删除；归档只改状态，删除不动图片文件。

### Agent

- 新增三个只读工具：`life_cards`（订阅卡片）、`life_items`（事务箱）、`art_works`（创作库），
  只在工作台问答入口暴露，快速栏 / 六级 / 录像 / 测验不受影响；
- 工作台工具总数 30 → 33，学习与生活数据域 10/10 都有读工具。

## 数据 / 接口

- schema 14 → **16**（只加表，旧行不动）：
  - 15：`life_items`（事务箱）；
  - 16：`style_presets` / `art_works`（创作库）；
  - 升级在第一次打开数据库时自动完成；旧问答、错题、订阅、卡片、项目全部保留。
- 新增接口：
  - `/api/life/cards`、`/api/life/cards/{id}/read`；
  - `/api/life/items*`（CRUD / done / reopen / archive）；
  - `/api/art/works*`、`/api/art/presets*`、`POST /api/art/import`；
  - `/media/art/{id}/image`（只回显数据目录内的图片）。
- 订阅接口补齐 `PATCH` / `DELETE`；`POST /api/subscriptions/{id}/run` 现在会真正生成卡片。

## 已知限制

- 股票行情 / 手机价格两类订阅**只迁移不送达**，等待数据源接入；
- 新闻订阅依赖每日简报（07:30 生成），简报关闭或失败时当天不出新闻卡；
- 作品图片只接受上传到工作台数据目录的文件，外部路径会被拒绝；
- 所有数据仍只在本机，未接云端同步。
