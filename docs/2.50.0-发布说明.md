# 学习工作台 2.50.0 发布说明

## 六级专项新增「意群长句」

- 入口：六级训练 → 专项 → 「意群长句」；直达 `#/cet6?tab=drill&mode=chunk`。
- 队列：只挑 **≥12 词**的长句，每轮 8 句；A/B 段优先、有笔记的优先、练得少的先上；
  3 天内高分通过的句子排后。
- 流程：播放整句（可 0.75x）→ 写下整句 → 提交对照 → **按意群逐段回放**。
- 意群切分是确定性的，不调模型：
  - 标点（, ; : . ? ! —）和从句/并列连词优先切；
  - 过短的块合并，过长的块按真实停顿拆；
  - 每句 2–5 个意群。
- 词级时间轴来自试卷 `transcript.json`；没有时间轴的试卷（如强化刷题卷）不进入队列。
- 漏听词自动建卡：`wrong_items(source='cet6_chunk')`，复习页标签「意群」，
  卡片可播放原句音频；仍复用 `review_state`，不新建第二套 SRS。
- 新增 `cet6_chunk_attempts`（schema 19），只存原句、答案、得分、漏听/多写、
  意群数、建卡数；原文和时间轴不复制进库。
- 统计页新增「意群长句」卡：完成句数、平均得分、自动建卡数。
- 今日目标：意群长句计入“训练 / 复习”格，今日页写「意群长句 · 今天已完成 N 句」。

## 验证

- 1480 个后端测试、41 个前端测试通过；架构 / 分层门禁通过。
- 8766 隔离实例（生产库副本 18→19，1202 条逐句进度不变）：
  - 长句队列 A 段优先、只返回 ≥12 词且不带原文
  - 26 词长句切成 4 个意群，提交得 75%、自动建卡
  - 逐意群回放：播放到段尾自动停、按钮状态复位
  - 错题来源 `cet6_chunk`、复习接口带原句音频
  - 统计页 2 句 / 40% / 7 卡；今日页「意群长句 · 今天已完成 2 句」
  - 控制台 0 报错
- 真实语料抽样：737 个 ≥12 词长句中有 598 个能切出 2–5 个意群（81%）。

## 已知边界

- 意群切分是启发式：以标点/连词和真实停顿为准，不保证与语言学意群完全一致；
  长而平的部分可能仍是一大块。
- 没有 `transcript.json` 的试卷不进入意群队列；词级时间覆盖率不足的长句自动跳过。
- 意群回放依赖句子音频的起始点与 `data.js` 一致；若句子切点被手动改过，回放可能有几十毫秒偏差。
- 意群卡片与逐句听写共用错题本；同句同词重复漏听只保留一张卡。
