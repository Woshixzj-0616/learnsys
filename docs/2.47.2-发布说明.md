# 学习工作台 2.47.2 发布说明

> 2026-10-30 · 股票订阅修正：指数改用免费公开行情，个股继续用 Tushare 免费日线

## 这次改什么

### 指数不再走 Tushare

- 实测 Tushare 免费档（120 积分）调用 `index_daily` 会被限流（1 次/分钟，甚至 1 次/小时），
  官方权限要求 2000 积分；免费档取不到指数；
- 指数（上证 `000001.SH`、深证 `399001.SZ`、创业板 `399006.SZ` 等）改为
  **东方财富公开行情接口**：一次请求多个指数、免 token、免积分；
- 个股（如 `600519.SH`）继续走 **Tushare `daily`**，需要 token；免费档 50 次/分钟，够用。

### 订阅配置

- 一个订阅可以混填指数和个股：指数走东方财富、个股走 Tushare；
- 卡片来源逐条标注（东方财富 / Tushare），并注明可能延迟、不构成投资建议；
- 页面提示改为「指数不需要 token；个股需要」。

## 数据 / 接口

- schema 不变（16），没有新表；
- 无新接口；`/api/life/stock/config` 行为不变。

## 测试

- **1438 个 Python 测试通过**；前端 15 项；两个结构门禁通过；
- 新增：指数走东方财富解析（价格/涨跌幅/名称）、纯指数订阅无需 token。

## 已知限制

- 东方财富是公开行情页接口，不是官方授权 API，页面改版可能失效，届时只改 `stock.py`；
- 指数数据可能有延迟；
- 个股需要 Tushare token；免费档日线非实时。
