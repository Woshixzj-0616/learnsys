# 学习工作台 2.59.0 发布说明

## Agent 验收闸门：跑完了，也要能证明做对了

在此之前，`agent_tasks.status=done` 只表示子进程正常退出；接口连结果正文都不给，
更没有任何机制回答「这个任务到底做成没有」。队列越顺，没人验收的任务积得越多。

本期补第一层：**确定性验收**。不调模型，零额外模型成本。

### 1. 任务一出场就带契约

建任务时不填契约也会自动生成默认契约：

| 模式 | 默认检查 |
|---|---|
| 只读 | `no_workspace_change`（零改动）+ `within_scope` |
| 可写 | `within_scope`（改动都在工作目录、文件数 ≤50） |

写了契约就必须合法：未知检查、缺 `scope`、非法 JSON 一律 422，不会静默放过。

### 2. 派活前记快照，跑完再比一次

- git 仓库用 `git status` 前后差集，**用户自己未提交的改动不会被算成 agent 的**；
- 非 git 目录走查文件，排除 `.venv` / `node_modules` / `build-*` / `dist*`；
- 系统自己的痕迹一律排除：任务结果目录、`learning.db` 及其 `-wal/-shm/-journal`
  ——**默认工作目录就是数据目录**，不排除的话光开库就会被误判。

### 3. 四种检查

| 检查 | 判什么 |
|---|---|
| `no_workspace_change` | 只读任务期间工作区零改动、无新提交 |
| `within_scope` | 改动都在 `scope.roots` 内，且不超过 `max_files` |
| `file_nonempty` | 指定产物文件存在且非空 |
| `command_zero` | 命令退出码 0；只放行 `python` / `pytest` / `npm` / `node` 前缀，超时 120 秒 |

### 4. 验收自己出错，绝不判通过

快照截断、命令超时、契约写错、单条检查抛异常——全部 `error`。
没有契约的老任务才是 `skipped`。

### 5. 结果看得到

- 任务详情 `/api/agents/tasks/{id}` 返回 `verdict` 全文与 `contract`；
- 任务列表只带 `verdict_state` / `has_contract`，不拖正文；
- 结果文件 `学习档案/agents/{id}-*.md` 新增「验收」段，逐条列绿红；
- 新增 `tools/agent_verify_report.py`：看最近任务的验收分布与失败明细。

### 验证

- 新增 45 条测试（闸门逻辑 36 + 端到端 3 + API 6），全量 **1730 条通过**；
- 架构 / 分层门禁通过；
- 生产库副本迁移 schema 21 → 22，`agent_tasks` 行数不变；
- 端到端实测：只读任务零改动 → `passed`；写了一个文件 → `failed` 并点名该文件。
