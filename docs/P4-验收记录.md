## 四、已知缺口

1. 迁移只能从 **file://** 那个浏览器来源推送；HTTP 页面看不到 file:// 的 localStorage。用户若从没再打开旧 HTML，HTTP 侧会是空的。说明文档已写明。
2. file:// 下分析仍固定打 `127.0.0.1:8765`；若 8765 被占退到 8766，旧 HTML 的分析会失败（HTTP 页面已改同源）。
3. 六级源码与产物目录（`D:\cet6_tool`、`D:\Desktop\六级精听`）不在 Git 仓库里，本轮改动只在磁盘上；学习系统仓库只记录接口与文档。
4. 迁移备份自动下载依赖浏览器允许下载；被拦截时只会 console.warn，不影响推送。
