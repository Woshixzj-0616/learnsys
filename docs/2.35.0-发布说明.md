# 学习工作台 2.35.0 发布说明

> 2026-10-27 · P25.2 学习写入工具 + 资料导入

## 新增

### Agent 能按你的明确指令写学习数据

四个新工具，全部会弹确认框，拒绝后答案会明确说「没有执行」：

| 工具 | 你说什么 | 写什么 |
|---|---|---|
| `add_vocab` | 「记一下这个词」「加进生词本」 | 生词本 + 复习卡（明天到期） |
| `delete_vocab` | 「把 apple 从生词本删掉」 | 删词 + 复习卡，一次一个 |
| `rate_review` | 「这张卡我记住了 / 忘了」 | FSRS 评档 1–4，一次一张 |
| `save_training_error` | 「把这个错误收进复习」 | 写作/翻译错题 + 复习队列 |

入口按场景裁剪：

- 快捷栏只加 `add_vocab`（听课时记词，不打断）；
- 六级训练加 `add_vocab` / `save_training_error` / `rate_review`；
- 录像只加 `add_vocab`；
- 工作台问答四个全给；速答仍只有记忆工具。

### 资料库补到 5 份

导入 2024-06 与 2024-12 的 5 份六级写作解析 PDF。检索、挂资料提问、从资料出题均已实测。
