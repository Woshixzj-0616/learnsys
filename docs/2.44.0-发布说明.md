# 学习工作台 2.44.0 发布说明

> 2026-10-29 · 问一问：切页不中断、确认不挡流、代码调试先跑再答、长会话记得住

## 这次改什么

### 切页不再中断思考

以前切到今日页/资料页，问一问这一轮会被直接掐断：前端 `unmount` 主动 abort，
服务端生成器冻结，`finally` 不执行——回答不落库、DB 连接不关、运行记录也没有。

现在：

- 模型在**后台线程**里跑，SSE 只是订阅者；切页/刷新/断线只退订，不中止、不丢回答；
- `done` 事件**先落库再通知前端**，回来重读一定能看到完整回答；
- 回到问一问时，运行中的正文、思考、工具轨迹直接接回页面，继续增长；
- 停止按钮按 `run_id` 精确命中，同一会话多标签页不再互相覆盖；
- 中断或出错时，已经流出的正文保留，并标记 `interrupted`。

### 写操作确认不再阻塞页面

把 `window.confirm` 换成页面右下角的非阻塞卡片：

- 卡片不挡流式渲染，切页也还在；120 秒倒计时，超时按拒绝处理并明确提示；
- `run_code` 可以选「本页面内不再询问」（`sessionStorage`，刷新页面后恢复询问）；
- 确认请求没送到后台时，页面底部会提示，不再只写控制台。

### 代码调试：先跑再答，不再被确认打断

- 用户明确要求运行（「跑一下 / 跑几个用例 / 帮我测」）或处于代码调试场景时，
  `run_code` 直接在临时沙箱执行，不再弹确认；
- 调试判据新增「长代码 ≥15 行 + 题目/输入输出格式/样例 ≥2 个」，
  贴题目+代码也会先运行验证，而不是读完就断言某一行是 bug；
- 沙箱仍是临时目录 + 默认禁网 + 超时/内存/输出上限，不改学习数据；
- 模型漏传 `language` 时按代码特征推断 C++ / C / Python。

### 长会话记得住

- 会话摘要从「只看最近 12 条、覆盖式」改为**滚动合并**：
  每次把「已有摘要 + 最近 12 条对话」合成新摘要（上限 200 字），
  长会话不会在第 16 条消息之后丢掉早期结论；
- 摘要输入和历史上下文都会跳过中断/出错的半截回答，不把半截当事实；
- 会话标题取第一条非空行，不再把整段题面/代码开头塞进侧栏。

## 数据 / 接口

- 无 schema 变更；
- `POST /api/agent/stop` 新增可选 `run_id`（旧前端按 `conversation_id` 仍然可用）；
- `confirm` 事件 data 新增 `label`（确认卡标题）；
- `AgentRequest` 新增内部字段 `auto_run_code`（不新增接口参数）；
- 口径固定：`messages` 是会话真相，`asks` 是时间线/检索索引。
