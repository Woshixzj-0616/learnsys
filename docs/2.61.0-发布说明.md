# 学习工作台 2.61.0 发布说明

## 专项降级：从独立队列变成精听里的一句话动作

专项听写上线后一次都没被真实使用（`cet6_drill_attempts` 长期为 0）。
问题不在功能本身，而在它占了一个独立标签、还要先走一套队列；练一句话的代价太高。

本期把它降级：

- 六级页去掉「专项」标签，`?tab=drill` 自动回到精听；
- 精听工作台每句卡片新增「听写这句」：点开自动重播该句，输入听到的内容，提交后按内容词算分；
- 漏听词高亮，并自动收进英语复习（`cet6_dictation` 来源），继续走同一套 FSRS；
- 真题自评 / 意群长句的数据表保留，不再有独立入口。

练习路径从「六级页 → 专项 → 队列 → 第 N 句」变成「精听 → 这一句 → 听写」。

## Agent 中枢内化：不再占一级页面

- 侧栏移除「Agent 中枢」和「运行记录」；`#/agents`、`#/agentruns` 仍可直达。
- 入口放回做事的地方：问一问输入框旁「派活」、项目卡「派活」。
- 后续再把运行状态做成右下角任务条；本期先把导航收掉，不改变派活能力。
