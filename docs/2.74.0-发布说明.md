# 学习工作台 2.74.0 发布说明

日期：2026-11-19

## 一、生词本与每日积累去重

- 每日积累生成翻译词时，跳过已经在 active 生词本里的词，也跳过以前每日积累推过的英文（按明显变体归一：大小写/标点、the、单复数、斜杠同义项、括号缩写）。
- 同一英文不再同时以「每日积累卡 + 生词卡」出现在英语复习词 tab；`seed_review_states` 会清理历史重叠卡，并保证以后不再种回来。
- 生词本新增变体合并：`Caravans`/`caravan`、`the Silk Road`/`Silk Road`、`remote medicine / telemedicine`/`telemedicine`、`advocate / uphold`/`uphold` 等只保留一条；`glass`/`glasses` 这类同词形不同释义不自动合并。
- 迁移工具 `tools/vocab_variant_merge.py` 默认只读，`--apply` 写库前自动备份；归档行可恢复。

## 二、整篇翻译句子卡正面改中文

- 新批改的整篇翻译卡按题库 `segments` 建卡：正面是中文原文，背面是学生英文 + 必改点 + 参考译文。
- 历史 18 张整篇翻译卡已回填：`question` 改为对应中文段落，`my_answer` 补上学生英文；13 张一句一译卡不动。
- 工具 `tools/train_prompt_backfill.py` 默认只读，`--apply` 写库前自动备份。

## 三、精听做题模块

- 精听工作台「本段」工具组新增「做题」按钮；题目面板升级为 A-D 选择题。
- 选项、标准答案、解析来自 Apache-2.0 开源题库 `ShepiTT/CET_practice_questions`，覆盖 2019–2026 的 33 份本地卷（含 3 份强化卷）；不生成 AI 选项。
- 2016–2018、2026-06 卷二、讲座原声显示「暂无做题数据」并说明原因。
- 判分在本机；HTTP 模式下把错题号写入六级做题统计。统计页文案改为「听力做题 / 正确率」。
- 题库源 `learnsys/train/content/cet6_listening_quiz.json`；每卷 `quiz.js` 为派生产物，可用
  `python tools/cet6_quiz_build.py --apply --sidecars` 重建。
