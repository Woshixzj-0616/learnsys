# 学习工作台 2.54.0 发布说明

## 新增：排错题先取证、再下结论

起因是 2026-11-03 会话 85 的 nginx 80/8080 排错：工作台 5 轮没答到根因，其中一轮空等
92.9 秒，5 轮全部 0 工具调用。这次把「排错 / 配置」从识别到收尾整条链路补齐。

- **排错意图识别**（`agent/intent.py`）：配置片段、Traceback、命令报错、版本问题、
  端口追问都能识别；纯概念题（死锁、三次握手）不误判。
- **路由**（`agent/router.py`）：`ops_mode=on` 时排错题强制思考，可选用强模型；
  `shadow` 只记录建议，不改回答；手动速度档 / 手动 routes 仍然优先。
- **取证提示**（`agent/prompt_ops.py`）：事实分「已验证 / 未验证 / 待确认」三级，
  没有证据只给候选原因 + 验证方法，不许把候选说成根因。
- **断言审核**（`agent/claims.py`）：假链接、假命令输出、无证据的绝对断言、
  无标签的版本断言、没有 URL 的「官方文档说」会被打回重写一次；
  重写后仍不通过就把「未核实项」列在答案末尾。
- **强制取证**（`agent/evidence_gate.py`）：版本 / 默认行为类问题在
  `ops_gate=on` 时强制先调 `web_search` / `fetch_url`，最多补一轮；
  取证轮不开放写操作工具，避免确认卡住整轮。
- **流式自愈**（`agent/fallback.py` + `llm/provider_anthropic.py`）：
  90 秒硬编码超时改为 `stream_timeout`（默认 30 秒）；没出字走原降级，
  出过字最多续写一次，已写正文不会丢。

## 新增配置（`设置.json` → `agent`）

```json
{
  "ops_mode": "shadow",
  "ops_gate": "shadow",
  "claim_audit": true,
  "summary_guard": true,
  "stream_timeout": 30
}
```

- `ops_mode`：`off / shadow / on`，默认 `shadow`（只记录，不改回答）；
- `ops_gate`：`off / shadow / on`，默认 `shadow`；
- `claim_audit`：排错题收尾是否做断言审核；
- `summary_guard`：会话摘要是否禁止把未验证候选写成「根因是 / 已解决」；
- `stream_timeout`：流式读超时秒数（10–180）。

## 已知边界

- 排错题开启 thinking 后单题 4–20 秒，明显慢于普通题；这是「先想再答」的代价。
- `ops_mode=on` + 强模型 `deepseek-v4-pro` 单题可达 20–50 秒，交互场景建议
  `strong_model` 留空（flash + thinking）。
- 强制取证只覆盖「版本 / 默认行为」类问题；端口排查、读配置仍靠提示 + 审核。
- 本版未启用 `tool_choice`，中转兼容性待单独验证。
