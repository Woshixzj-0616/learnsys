## 新功能

六级训练新增第五个标签 **「复习」**：写作/翻译的错误卡直接在训练里复习，
不再跳去错题本。

- 一次一张卡：先自己想，再「显示答案」；答案、你当时的写法、错误说明一起展开。
- 四档反馈「忘了 / 模糊 / 记得 / 简单」，真正写 FSRS 排期，与错题本共用同一套状态。
- 进度条、完成页（复习 N 张 · 忘了或模糊 M 张）、「再查一遍到期」、空状态。
- 入口统一：
  - 今日页「六级训练 · N 张到期错误卡」；
  - 写作首页「去复习」；
  - 翻译首页「到期错误卡」；
  - 统计页「N 张到期错卡」；
  - 深链 `#/cet6?tab=review`。

没有新表、没有 schema 变更：复习数据仍来自 `wrong_items` + `review_state` + `review_log`。
