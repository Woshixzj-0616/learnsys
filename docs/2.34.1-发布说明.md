# 学习工作台 2.34.1 发布说明

> 2026-10-27 · P25.1 代码调试验证 + 延迟感知

## 修什么

会话 45/46 暴露：粘贴 150 行 C++ 问「一组没过」，8 轮全部 0 次工具调用，
模型连续猜错（甚至把没问题的常数项说成被吞）。工作台沙箱本来 0.65 秒就能复现。

### 代码调试闭环

- `agent/debug_intent.py`：唯一判定「长代码 + 调试意图」；
- 路由建议 `deep + thinking`；`balanced` 档下**强制思考**（`fast` / 手动 routes 仍尊重用户）；
- 提示词新增「代码排查铁律」：先 `run_code`、多组用例合并一次 stdin、最多 3 次、没跑不许断言某一行；
- `run_code` 防抖：同代码 + 同 stdin 不重复；一轮最多 3 次；代码调试轮超时 5 秒（默认 10 秒）；
- **未验证闸门**：命中代码调试但没成功运行，答案第一行强制标「未运行验证 / 运行未成功」。

### 延迟感知

- 调模型前 3ms 就发状态：「代码调试：先编译运行验证，再回答（通常 10–30 秒）」；
- 思考流式可见（首思考 <1s），网页/快捷栏都有计时；
- 工具状态改中文短名：「正在运行代码… / 正在联网搜索…」（`TOOL_LABELS` 唯一映射）；
- 工具结束：「结果回来了，继续分析…」；失败「这步没成功，正在换路」；
- 不伪造进度条，不为了快而关思考（对照实验：不思考更快但全猜错）。

## 实测

- 你的多项式代码，flash + 强制思考：首事件 3ms、首思考 0.6–0.9s、第一个运行 28–30s、
  总 48–88s；最终找到「减法时 B 独有项未取负」的根因，并给出实际输入/输出；
- 同一段代码、不强制运行的三组（flash 不思考 / flash 思考 / v4-pro 思考）：0 工具、全部猜错；
- 不思考 + 强制运行：8 次超时、答案空 —— 所以「思考 + 运行」必须成对。

- 不做代码调试的专用「测试用例生成器」——仍由模型按题面构造 stdin。
