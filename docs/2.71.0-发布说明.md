# 学习工作台 2.71.0 发布说明

> 2026-11-10 · 英语每日复习：句型示例、单词手输、本轮进度续接

## 这次改什么

### 每日积累的写作句型：先造句，再看示例

- 写作句型卡正面：中文用途 + 英文句型 + 输入框「用这个句型自己写一句英文」；
- 「看参考例句」展开后：参考例句、例句译文、我这次写的、语法提示、四档评分；
- 例句之前被塞在 `note` 里只显示成脚注，现在拆成独立字段（`pattern` / `example` /
  `example_zh`），界面单独成块。

### 单词复习：看中文，打英文

- 每日积累的翻译短语：中文短语 → 打英文表达；
- 生词卡：取释义中「｜」前的中文词义 → 打英文单词；`context` 只在背面显示，避免泄题；
- 没有中文可提示的历史英文-英文条目回退为「英文正面 → 写中文释义」；
- 展开后给「一致 / 基本一致 / 和参考不同」的软提示，不替用户评分；
- 生词本页「开始复习」统一跳到 `#/english-review?tab=word`，删掉页内重复的复习面板。

### 复习进度不再重置为 10

- 本轮进度按「kind + 当天」存 `sessionStorage`，只存 `done` 和当前卡草稿，不缓存队列；
- 切页/刷新回来只补拉 `10 - 已做` 张；已评分的卡由 FSRS 移出到期队列，不会重复；
- 进度显示「第 X / Y 张 · 今日已复习 N 张」，切页后不会回到第 1 张；
- 修正新卡配额口径：
  - 只有 `state=new` 且属于本 tab `quota_types` 的卡才递减；
  - 后端 `_introduced_today` 按 tab 来源过滤，别页复习的手动/测验错题不再吃句子 tab 配额；
  - `stats.reviewed_today` 改为按 tab 统计「今天动过的不同卡片」（不再串 accum 类型）；
- 聚合页 `mountReview` 加 ticket，防止快速切 tab 时同一面板二次挂载、一次点击发两次评分。

## 数据 / 接口

- 无 schema 变更；
- `/api/review/queue?kind=` 新增 `quota_types`（`["wrong"]` / `["vocab"]`）；
- `/api/review/stats?kind=` 的 `reviewed_today` 改为 tab 口径（`review_state.last_review`）；
- 每日积累 writing 卡新增 `pattern` / `example` / `example_zh` 字段，`note` 只放语法提示；
  `answer` 仍保留 pattern，兼容旧调用。
