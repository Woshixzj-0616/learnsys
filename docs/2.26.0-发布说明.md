# 学习工作台 2.26.0 · 录像与录像分析

> 2026-10-25 · 本地部署版（未 push GitHub、未建 Release）

## 新增

### 录像（P23 M1）

- 快捷栏「录像」→ 3 秒倒计时 → 主屏 + 系统声音 → 标准 MP4（H.264 + AAC）。
- 产物固定放在 `D:\学习系统\录像\<日期-时间-会话>\`：
  `video.mp4`、`thumb.jpg`、`幻灯片\`。
- 快捷栏开始后自动藏起来；托盘「结束录像」或全局 `Ctrl+Alt+S` 停止。
- 新插件「录像」：列表、搜索、`<video>` 播放/拖动、转写时间轴点击跳转、
  幻灯片、存为资料、打开文件夹、删除。
- 只录系统输出，不录麦克风；视频不上传。

### 录像分析（P23 M2）

- 录像页「分析这段」：转写 + 幻灯片 OCR → Markdown
  - 这段课讲了什么
  - 时间线提纲（带时间）
  - 关键要点
  - 术语表
  - 没讲清 / 值得追问的地方
- 结果写到 `<录像目录>/analysis.md`，并存一份 `source=video` 的资料，可搜索、可出题。
- 「问这段」：问一问挂上「上下文 · 录像」，直接基于这段转写提问。
- 「出题」：优先用分析资料，没有就先把转写存资料，再跳测验页。
- 相同输入命中缓存；「重新分析」强制重跑；失败/取消可重试。
- 成本走模型调用账本；模型走「分析」路由（默认快模型、不思考）。

## 修复

- **SQLite 双锁**：`store/_base.py` 与 `core/db/fts.py` 曾各用一把锁共用一个连接，
  录像启停时偶发 `cannot commit - no transaction is active`；现在共用 `core.db._LOCK`。
- 旧「每 30 秒全屏快照」不再进入录像默认路径；幻灯片按画面变化抽取。

## 已知限制

- 分析只吃「转写 + 幻灯片 OCR」文字，不做视频逐帧视觉理解。
- 转写上限 6 万字、OCR 上限 2 万字、补 OCR 最多 120 张幻灯片。
- 分析单次超时 5 分钟；超长课会自动截断提示。
- 暂不支持点提纲里的时间跳转视频、导出 PDF、字幕烧录。
