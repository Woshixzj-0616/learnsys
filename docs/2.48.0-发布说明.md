## 六级训练新增「专项」听写

- 入口：六级训练 → 专项。
- 队列：每轮 8 句，约 3/4 来自精听工作台里标过笔记的句子，1/4 补 A/B 段未练句（优先练过的试卷）。
- 流程：播放原句（可 0.75x）→ 写整句 → 内容词级差异 → 漏听词自动建卡。
- 卡片：原句挖空 + 答案词，写 `wrong_items(source='cet6_dictation')`；复习仍走现有 FSRS，不新建第二套队列。
- 复习：六级训练 → 复习页会显示「听辨」卡，可播放原句音频。
- 统计：新增 `cet6_drill_attempts`（schema 17）；专项页显示近 30 天句数、平均分、建卡数。
- 今日目标：听写计入“训练 / 复习”格。
