## 4. 真实模型验证（临时数据根，不碰生产库）

四条链路都只调用预期工具，确认框均显示目标：

| 场景 | 工具链 | 落库/结果 |
|---|---|---|
| 「把 ubiquitous 记进生词本」 | `add_vocab` | 生词 #1，释义「无处不在的」，明天到期 |
| 「编号 1 的错题我记住了」 | `due_reviews` → `rate_review` | 评档 3，下次复习 2026-10-30，`review_log` 1 行 |
| 「把这个错误收进复习」 | `save_training_error` | 错题 #2，来源 `writing`，知识点「主谓一致（第三人称单数）」 |
| 「把 ubiquitous 删掉」 | `delete_vocab` | 生词与复习卡同时删除 |

真实模型回答示例：

- 「已加进生词本：#1 ubiquitous — 无处不在的，明天到期复习。」
- 「已给错题 #1「1 + 1 = ?」评成 3 档（记得），下次复习安排在 2026-10-30。」
- 「已收进错题本（错题 #1，写作），知识点记为主谓一致·第三人称单数，明天会进复习队列。」

**修掉的自检误报**：首次运行时，`save_training_error` 返回「训练错题（#2」，自检把它当成
「本轮没查过的错题编号」，在答案后追加问题。已让 `Evidence.add` 对
`save_wrongbook` / `save_training_error` 的返回编号计入 `wrong_ids`，复测不再出现。
