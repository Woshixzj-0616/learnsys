# 学习工作台 2.38.8 发布说明

> 2026-10-28 · 今日目标改为有效学习分钟 + 默认墨夜 + 横栏默认不置顶

## 改了什么

### 1. 今日目标 = 有效学习分钟

- 旧口径（100 学习点）是混合单位：问 10 个问题就能达标，和实际投入脱节；
- 新口径：**有效学习分钟 = 专注 ∪ 转写 ∪ 事件，按分钟并集去重**；
  - 专注：`sessions` 的起止区间；
  - 转写：`transcripts` 的起止区间（通常落在录像内，合并后不重复）；
  - 事件：问答 / 六级断点 / 训练 / 复盘按 2 分钟一段，相邻事件只算一次；
- 口径只在 `learnsys/services/study_time.py` 定义一处，`/api/overview` 和 `/api/today` 共用；
- 默认目标 **30 分钟**（`config.DAILY_GOAL_MINUTES`，设置文件 `daily_goal_minutes` 可改，5–240）；
- 学习点保留为成长值（等级 / 成就），不再当今日目标。

### 2. 今日页展示

- Hero：`42 / 30 分钟` + 构成（专注 / 转写 / 问答训练）；圆环按分钟；
- 副标题变成建议：`还差 18 分钟 · 精听 1 段约 8 分钟，或去训练场开一格`；
- 统计条第一格从「专注 + 切换次数」改为「投入 + 专注/问答构成」；
- 周柱状图改看有效学习分钟（`week.daily[].study_minutes`）。

### 3. 默认深色

- `config.DEFAULT_MOOD = "ink"`，Qt 的 `apply_theme` / `render_qss` 默认读墨夜；
- Web `modes.js` 默认 `mood: "ink"`；旧存储里没有 `_v` 标记且仍是 mist 的，按旧默认迁移到墨夜（用户主动选过纸感的不动）；
- 晨雾 / 纸感仍可在网页「模式」面板切换。

### 4. 横栏默认不置顶

- `config.ASK_BAR_ALWAYS_ON_TOP = False`；
- 用户点过「置顶」才记住（`always_on_top_set`），下次启动保持选择。
