| 8 | 前端纯函数 | `56-dualwrite.js`：服务端行映射（精确 → 字母 → 尾号 → 规范化，歧义不猜）、整卷快照、结构指纹；11 个 node 测试 |

## 2. 明确仍然没做

- **不切换**：`WB.FLAGS.retired=false`。11-04 依据报告决定；按当前证据最早 11-05。
- **多标签 rev/冲突检测**：后写覆盖前写；审计能记录差异，但不阻止覆盖。
- **gap 队列**：服务器不可达时当天没有审计记录，报告算「未知」并打断连续。
- **BKT 掌握度、深度分析 API 实测**：按顺序排在双写之后。
