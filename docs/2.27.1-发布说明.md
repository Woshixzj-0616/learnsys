# 学习工作台 2.27.1 · 录像体验调整

> 2026-10-25 · 本地部署版（未 push GitHub、未建 Release）
> 2.27.1 相对 2.27.0：先排除横栏再开录，避免第一帧把横栏带进画面。

## 改动（按用户反馈）

1. **工作台也能开始录像**
   录像页顶栏新增「开始/停止录像」，和快捷栏、托盘、`Ctrl+Alt+S` 共用同一个开关。
   倒计时、录像中、收尾中三种状态实时显示；开发后台没接 Qt 时显示「录像不可用」。

2. **录像时横栏不再收起来**
   横栏一直可见，方便随时点「停止」。
   同时用 `WDA_EXCLUDEFROMCAPTURE` 把横栏排除在屏幕捕获之外（本机 mss 实测有效）；
   老系统不支持时横栏会留在画面里，托盘/快捷键仍能停止。

3. **停止后先到录像页，转写放后台**
   视频一落盘、库一更新就立刻打开 `#/recordings?session=<id>`；
   页面显示「正在转写…」，每 2.5 秒自动刷新，转写写完直接出现。
   托盘/状态行只在全部收尾后更新汇总，不再抢页面。

4. **录像界面直接问 AI**
   详情页新增内联「问 AI」面板：问题带 `recording_id`，AI 直接基于这段转写回答，
   Markdown 流式渲染；「问这段」按钮改为聚焦这个面板。

## 验证

- 912 后端 / 23 网页测试全过；ruff、体量、分层门禁全过。
- 浏览器（8766 假 runtime + 假模型）实测：
  - 顶栏按钮：开始 → 取消倒计时 3→2 → 停止录像 · 00:00 → 收尾中… → 开始录像；
  - 内联 AI 请求体 `recording_id=1`、`surface=video`，答案正确渲染；
  - 转写空时显示「正在转写…」，后台补写后 7 秒内自动出现。
- 红色测试窗验证截图排除：WDA 前抓到红色，WDA 后抓不到，恢复后再次变红。
