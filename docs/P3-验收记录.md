## 二、自动化测试

```bat
cd /d D:\Desktop\learnsys
set QT_QPA_PLATFORM=offscreen
.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
```

连续跑 3 次，结果：

```
Ran 225 tests in 8.0–8.4s
OK
```

P1/P2 的 209 个全部保留；新增 16 个（Web 7 + 窗口外壳 4 + 启动链路 5）。

**顺带修了一个既有问题**：`OcrQueue` 的后台线程没有收尾，单独跑
`tests.test_assistant.TestOcrQueue` 会 15/20 次段错误（信号在线程里 emit，
和 PySide 退出清理相撞）。新增 `OcrQueue.shutdown()`，退出流程先停 OCR 线程；
修后单独跑 20 次 0 崩溃，全量跑 3 次全绿。

**另一个实测才暴露的问题**：`port_free()` 原来用 `bind()` 探测端口，Windows 的
`SO_REUSEADDR` 允许两个进程同时绑同一端口，会把“已被占用”误判成空闲；改成
`connect()` 探活后，再用假 HTTP 服务真实占用 8765 复测，确认能正确退到 8766。

## 四、安全与隐私

- 所有写接口（对话、设置、备份、上传）都要 `X-Learnsys-Token`；跨源按 Origin 白名单拦截。
- `GET /api/settings` 不返回密钥明文，只返回「配没配 + 尾号四位 + 来源」。
- 密钥留空 = 不改；保存用临时文件 + `os.replace`，不会写坏正在用的设置。
- 上传白名单后缀、单文件 20MB 上限；图片落当天「问答截图」，文档抽完文字即删临时文件。
- 前端依赖全部本地打包，不请求 CDN。

## 五、已知缺口 / 下一轮

1. **T3.5 快捷栏状态机**：固定几何、单一 `set_state()`、去掉 `_force_repaint()` 透明度抖动、框选遮罩不 `hide()`。需要录屏验收；本轮只在快捷栏底部加了「工作台」按钮，没动原有布局与状态机。
2. **窗口外壳是 Edge/Chrome 应用模式**，不是 WebView2：任务栏可能仍归在浏览器进程下；全屏游戏等前台锁定会阻止 `SetForegroundWindow`，窗口会留在后面（Windows 的正常保护，不是崩溃）。如果之后要彻底摆脱浏览器进程，换 `workbench.py` 里的 `open_app_window()` 即可，页面和接口不用动。
3. **模块页**：六级精听、复盘、测验、错题本、资料目前显示「待建」，按计划在 P4 落地。
4. **会话标题**只取第一问前 30 字，后续不自动改名；附件在刷新后只保留文字记录，不显示缩略图。
5. 上传的图片会留在当天「问答截图」目录，暂未做定期清理（备份会一起打包）。
6. 设置页的热键、备份目录保存后需重启问一问；页面已如实提示。
7. `workbench_on_start` 目前只能改 `设置.json`，设置页还没有这个开关。
