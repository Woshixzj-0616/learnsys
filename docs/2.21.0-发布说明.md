# 学习工作台 2.21.0 发布说明

> 2026-10-24。**Qt 桌面试点落地**：设置页与今日页两页从网页搬到 Qt，Web 工作台保持原样。
> 起点 2.20.2（708 测试 + 16 网页 + 25 六级）→ 2.21.0（819 后端 + 111 Qt + 16 网页 + 25 六级）。

## 1. 为什么

- Web 工作台受浏览器外壳限制：首屏偏慢、窗口多了难管、系统级托盘/快捷入口体验不一致。
- 全量 Qt 重写成本高、风险大；先做**混合架构 + 单页试点**，用两页真实页面验证可维护性、耗时、内存，再决定是否扩大。
- 方向决策见 `docs/重构-方向-20261024.md`，施工单见 `docs/施工单/R3-Qt试点.md`、`R3.10-视觉对齐.md`、`R4-今日页Qt.md`。

## 2. 这次做了什么

| 改动 | 落地 |
|---|---|
| Qt 客户端骨架 | 新增 `learnsys/ask/qt/`（`api.py` / `widgets.py` / `style.py` / `page.py` / `settings.py` / `memory.py` / `today.py` / `today_widgets.py`）与 `desktop/qt_pilot.py` |
| 设置页（R3） | 三接口只读渲染 → 7 分组表单 → 密钥只回掩码、留空不改 → 测试连接 / 立即备份 → 模块开关 → Agent 记忆 CRUD（行内编辑） |
| 设置页入口 | 托盘「设置（Qt 试点）」；`--qt-settings`；已有后台时只 attach 开窗，不抢单实例、不起第二套后台 |
| 深色视觉（R3.10） | 新增 `tokens.py` 运行时解析 `web/css/tokens.css`（**颜色唯一来源，Qt 不自抄**）；深色 QSS + `QPalette`；下拉弹层/列表/滚动条/复选框/tooltip 全深色；版心 780 居中 |
| 今日页（R4） | Hero / 插件舞台 / 四格统计 / 行动卡，顺序与 Web 一致；数据来自 `/api/overview` 等 5 个接口，每次打开重拉 |
| 今日页入口 | 托盘「今日（Qt 试点）」；`--qt-today`；`style.fit_size()` 按工作区收缩窗口，150% DPI 不越界 |
| 代码体量 | QSS 拆 `qss_common.py` / `qss_today.py`，`style.py` 410→159 行；全部低于 500 行门禁 |
| 入口修复 | `app.py` 补 `__main__` 守卫（此前 `python -m learnsys.ask.app` 空跑） |

## 4. 明确没做

- **不做全量 Qt 重写**，后端也不 Qt 化；Web 工作台仍是主界面，Qt 是试点入口。
- 今日页未做：时间线、本周、专注明细、六级断点、成就面板、自动刷新。
- **深链只打开 Web 工作台**：已有 Web 窗口时只聚焦，不保证跳到目标 hash；Qt 内导航 / Web↔Qt 事件桥留待下一阶段。
- 系统标题栏仍是浅色（Qt 无法改）。
- 打包版真人托盘交互、125% DPI、Web 今日页首屏基线未测（本轮只测 150% DPI 与进程侧指标）。
