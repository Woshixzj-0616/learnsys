## 五、本次修掉的连带问题

1. **统一库会把历史算进「今天」**：复盘/测验/报告/专注统计/今日概览全部加了日期过滤。
2. **旧按天库与新库重复计数**：`storage_dbs()` 有统一库时只读它；历史菜单不再列「更早的日子」。
3. **老库缺列**：迁移按实际列名读 `asks`，缺的字段走默认值（v1.4 之前的库也能迁）。
4. **FTS 连接缓存踩 id 复用**：改为查 `sqlite_master`，不按 `id(conn)` 缓存。
