# 学习工作台 2.15.0 发布说明

> 2026-10-23。P18.2：BKT 掌握度。FSRS 管「何时复习」，BKT 管「懂没懂」。
> 起点：2.14.0（565 测试）→ 2.15.0（582 测试全过）。

## 1. 这次做了什么

| # | 内容 | 落地 |
|---|---|---|
| 1 | BKT 纯函数 | `services/bkt.py`：标准 4 参数（L0=0.1 / T=0.15 / S=0.1 / G=0.25），对/错贝叶斯后验 + 学习转移 |
| 2 | 取数口径 | 只用 `store.ready_attempts()`；回填、fallback、未判定、格式异常、其他都不进 BKT |
| 3 | 服务层 | `/api/knowledge` 每类目追加 `mastery / mastery_attempts / mastery_ready / mastery_level` |
| 4 | 汇总 | totals 增加 `mastery_ready_points / average_mastery / weakest`；顶层 `bkt` 暴露参数与门槛 |
| 5 | 样本门槛 | 每类目至少 5 条可建模答题才给数值；不足显示「样本不足 N/5」 |
| 6 | 页面 | 知识点页 hero 增加平均掌握度/已建模类目；行与详情显示掌握度、等级、样本数 |
| 7 | 等级 | 薄弱 <40%、在学 40–70%、掌握 ≥70%；显示向下取整并 cap 99% |
| 8 | 「其他」 | 兜底类目不建模、不参与平均/最弱 |

## 2. 明确仍然没做

- **按知识点自动出题/排程**：BKT 只展示，不影响测验选题与 FSRS。
- **参数学习/置信区间**：参数写死；5 条是产品门槛，不是统计置信度。
- **遗忘建模**：长期不练掌握度不会自动下降；复习时机仍由 FSRS 管。
- **今天页薄弱点改造**：仍是「最近一条未掌握错题」，下一轮再接 BKT。
- **刷题门槛**：同一道题重复 5 次也能解锁；以后可按不同题目数加第二道门槛。
