# 学习工作台 2.40.0 发布说明

> 2026-10-28 · P26.3：Agent 中枢队列 + 路由影子建议

## 这次新增什么

### 1. 任务排队，不再「忙就拒」

- 同一个 agent 已有任务、或全局并发已满时，新任务不再被拒绝，
  而是落成「排队中」，显示第几位；前一个结束后自动开跑。
- 排队中的任务可以直接取消；取消后不会拉起进程。
- 队列上限默认 10 个（`设置.json` 的 `agents.queue_max`，1–100 可调），满了才提示稍后再派。
- 每 agent 仍串行；全局同时运行数沿用 `agents.max_concurrent`（默认 2）。
- 超时从任务**真正开始运行**算起，排队时间不计入。

### 2. 重启后不再卡死

- 工作台重启后首次打开 Agent 中枢：上次残留的「运行中」任务标为失败
  （原因写明「工作台重启，任务已中断」），排队中的任务继续接续。
- 任务的自定义超时会随任务保存，排队跨重启不会悄悄换成默认值。

### 3. 路由影子建议（只记录，不改行为）

- 派活时按纯规则算一条「建议用哪个 agent」并随任务保存：
  - 可写任务建议 Claude Code（逐条审批留审计）；
  - 只读任务按最近同模式的**完成率**（`done` 只代表正常结束，不代表正确）→ 中位耗时 → 费用比较；
  - 样本不足 3 条时沿用你的选择。
- 任务日志顶部显示「路由建议（影子）：建议 X · 理由…；本次按你的选择执行」；
  历史卡片在建议与选择不同时显示「建议 X」徽标。
- 新增只读工具 `tools/agent_route_report.py`：建议一致率、分歧样本、各 agent 完成率与中位耗时。
- **实际执行的 agent 永远是你选的那个**；本版不开自动路由。
