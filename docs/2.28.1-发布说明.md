## 新增

- **录像页内置问一问**：同一个 Agent / 同一套系统提示词与工具，不是第二个 AI。
  对话流直接显示在录像详情里，支持继续追问、切换这段录像的历史会话、「新对话」。
- **统一历史、可区分来源**：
  - 对话仍进 `conversations` 表，`module=ask`，所以问一问侧栏能看到；
  - 额外记 `origin=video` + `recording_id`，侧栏显示「录像」徽标和录像标题；
  - 打开视频对话会自动挂回录像上下文，后续追问继续带这段转写。
- **在问一问里打开**：录像面板一键跳到完整问一问会话 `#/ask/<id>`。
- **快捷栏历史**：这些提问带 `[录]` 标签，悬停提示带录像标题。
