# 学习工作台 2.62.0 发布说明

## 经验库：记「下次还想记得的事」，不是技术知识库

工程专业真正会重复遇到的，不是题目和答案，而是和 AI、工具打交道时踩过的坑。
之前这些经验散在对话和记忆里，下次要重新翻。

本期加一个独立经验库 `#/practice`，只强制三格：

| 格 | 写什么 |
|---|---|
| 场景 | 我在干什么（例如「让 codex 改完后端」） |
| 坑 / 有效点 | 实际发生了什么（例如「它回复完成，接口还是 500」） |
| 下次 | 下次先做什么（例如「先看 /api/health 和实际请求」） |

技术原因、证据、标签、项目都折叠在「更多」里，可以不填。

### 不按记忆曲线催

经验不接 FSRS，不进每日到期队列。页面默认按最近更新排序，顶部是搜索框；
用得到时点「这次用到了」，累计次数与最近使用日期。

### 从问一问直接起草

每条 AI 回答下面新增「记一条经验」：点击后把问题填进「场景」、回答摘要填进「坑」，
跳到经验库表单，改一句话就能保存。人只做判断，不要求从零写技术原因。

### 数据

- schema 22 → 23，新增 `practice_notes`；只做加法迁移，老库自动建表；
- 接口 `/api/practice*`：列表 / 新建 / 修改 / 用到 / 归档 / 删除；
- 校验与 SQL 分别在 `services/practice.py` / `store/practice.py`。
