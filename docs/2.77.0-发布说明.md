# 2.77.0 · 问答内核与信息源（P35）

> 2026-11-24。P35.1–P35.4：助手从「工作台内嵌助手」改为「专属学习助手」；英语/CET6 不再有第二套 AI。

## 用户可见

- **英语页**：外层 AI 抽屉退役，改为右下角「问助手」；自动带当前 tab、当前题和选中文本。
- **CET6 精听**：iframe 内置 AI 隐藏（宿主侧 CSS + Ctrl+J 拦截），不再出现两套助手。
- **快捷栏**：问答写入 `conversations/messages`，每 4 条生成摘要；历史菜单可「继续会话」回灌上下文。
- **助手**：回答下方新增「答对 / 答偏 / 资料不对」反馈；用户说「我说的是 / 不对 / 听不懂」时本轮自动升强模型。
- **学习状态**：只带学习域；无关英语卡点不再进入 rsync/C++ 等普通知识题。
- **资料题**：只读工具同名同参去重、预算提示；达到工具步数上限后无工具收口，不再整轮报「工具调用次数太多」。

## 内核

- `agent/qa/profile.py`：assistant 9 核心 + 2 记忆 + 按意图追加；quickbar 8。
- `agent/prompts/` 文件化；assistant system ≈988 token（旧 3,805）。
- `agent/tool_budget.py`：只读工具去重 / 3、6 次预算提示 / 无工具收口。
- `agent/correction.py`：纠错轮识别。
- `selfcheck.Evidence`：资料 id/页码、错题 #、时间、网页 URL 统一核对。
- `qa_feedback` 表（SCHEMA_VERSION 25）+ `POST /api/agent/qa_feedback`。
- `surface=cet6` 不再有专属 prompt/tool/model；旧 iframe 调用仍兼容，按 assistant 白名单 + 主模型。
