# 学习工作台 2.46.0 发布说明

> 2026-10-29 · 工作交接：项目卡片、HANDOFF 交接页、派活自动带交接包

## 这次改什么

### 项目卡片：`#/projects`

- 侧栏「工具」组新增「项目」页；每个项目一张卡：名称、状态（进行中 / 暂停 / 已归档）、
  仓库路径（路径不存在时标红「路径失效」）、下一步、风险、更新时间；
- 新建、编辑、归档都在页面完成；默认只列进行中，可切换看全部；
- 今日页「工作」域卡改为进入项目页。

### HANDOFF：换个会话接手，读一页就能开工

- 一键生成 `HANDOFF.md`，内容**只含指针和状态**：
  - 状态：项目状态、下一步、风险、更新时间；
  - 仓库指针：README / AGENTS / 最新两份施工单（按修改时间）/ 架构索引位置 / 最近 3 条提交；
  - 外部记忆（只读）：Codex 记忆库项目档的首段与完整路径；
  - 交接约定：先读什么、改代码前查哪张表、冲突时以仓库为准。
- **纯本地拼装**，不调用模型、不复制正文；
- 只写到 `数据目录\projects\<项目名>\HANDOFF.md`，**绝不写回仓库**；
- 记忆档按项目名匹配；名字对不上时列出记忆库里已有项目档，不猜别名；
- 外部记忆库根目录可在 `设置.json` 的 `handoff_memory_root` 修改。

### 派活自动带交接包

- Agent 中枢建任务时可以「挂项目」；
- 认领任务时读取该项目最新的 HANDOFF，作为背景拼进运行提示词
  （顺序：上一步结果 → 项目交接包 → 本轮任务），交接包上限 4000 字；
- 任务列表显示所属项目；数据库里 `prompt` 仍保存用户原文，交接包只是运行时注入。

## 数据 / 接口

- schema 13 → **14**：`agent_tasks` 新增 `project_id`（只加列，旧任务默认 0）；
- 新增 `PATCH /api/projects/{id}`、`POST /api/projects/{id}/archive`、
  `POST /api/projects/{id}/handoff`、`GET /api/projects/{id}/handoff`；
- `POST /api/agents/tasks` 新增可选 `project_id`；
- `GET /api/projects` 默认只返回进行中，`status=all` 返回全部。
