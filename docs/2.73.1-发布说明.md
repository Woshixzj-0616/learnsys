# 学习工作台 2.73.1 发布说明

> 2026-11-17 · 复习队列按遗忘风险排期 + 每日积累不再挤掉错题/生词

## 这次改什么

### 复习队列不再「固定的那几张」

- 取卡规则原来写死「每日积累永远排最前 + 到期日/类型/id 排序」，导致：
  - 11-14 起 90 次复习全部是每日积累，错题/生词 0 次；
  - 单词 tab 前 40 张候选全是翻译短语，124 个新词永远轮不到；
  - 今天生成的每日积累前面排着 20+ 张旧积累。
- 新规则（`services/review.py::_compose_queue`）：
  1. **当天**生成的每日积累保底在前（写作 2 / 翻译 8）；
  2. 其余卡按 **FSRS 遗忘风险**从高到低混排：`1 - R`，R 由稳定度和距上次复习天数算出；
  3. 旧每日积累降级为普通复习卡，最多占复习位一半，不再绝对置顶；
  4. 新词/新错题每轮最多 20%（10 张一轮 = 2 张），并受每天 10 张新卡配额限制；
  5. 新卡均匀插入复习卡中间，不再永远堆在末尾。

### FSRS 间隔抖动

- 同一天、同样评分的卡，原会算出完全相同的间隔，永远同一天一起回来；
- `services/fsrs.py::fuzz_interval` 按「卡类型 + 卡 id + 已复习次数」做**确定性抖动**：
  同一张卡同一步结果不变，不同卡错开到相邻 1~2 天；
- 1 天以内的间隔不抖动（新卡「忘了」仍然明天复习）。

### 界面提示

- 复习卡右上角新增「预计遗忘 N%」（按 FSRS 稳定度估算，新卡不显示）；
- 新卡提示改为「今天还剩 N 张（每轮最多 2 张，每日积累另计）」。

## 数据 / 接口

- 无 schema 变更，不需要迁移；
- `/api/review/queue` 返回字段新增 `accum_day` 与 `forget_risk`（新卡无 `forget_risk`）；
- 队列候选池改为一次取 500 张再排序；`due_review_items` 不再承担新卡限流；
- SW 缓存版本 `v77 → v78`。
