# 学习工作台 2.47.1 发布说明

> 2026-10-30 · 股票订阅接入 Tushare 免费档；手机价格改用目标价提醒

## 这次改什么

### 股票订阅（Tushare 免费档，0 元）

- 订阅类型「股票」从「暂不支持」改为可用；
- 在「生活订阅」页填一次 **Tushare token**（tushare.pro 免费注册，120 积分档）；
- 每条股票订阅填股票/指数代码（最多 5 个）：
  - 股票：`600519.SH`、`000001.SZ`；
  - 指数：`000001.SH` 上证指数、`399001.SZ` 深证成指等自动走 `index_daily`；
- 每天按订阅时间生成一张卡片：代码、收盘价、涨跌幅、交易日；
- 只走 **日线**（免费档没有实时）；卡片注明数据源，仅供本机查看，不构成投资建议；
- token 只存本机 `设置.json`，接口只回尾号；也可用环境变量 `TUSHARE_TOKEN`。

### 手机价格

- 不接自动抓价；用事务箱建「目标价」待办（机型写标题、目标价写备注/一行记录），
  到期提醒去官方商城核对。原因：手机价格没有权威且可持续的 SKU 接口。

## 数据 / 接口

- schema 不变（16），没有新表；
- 新增 `GET/POST /api/life/stock/config`（只回 token 尾号）；
- `stock` 订阅的 `sources_json` 复用为股票代码列表。

## 测试

- **1437 个 Python 测试通过**；前端 15 项通过；两个结构门禁通过；
- 单元测试覆盖：代码归一、指数路由、token 保存/掩码、Tushare 响应解析、
  缺 token/缺代码中文提示、同日不重复；
- 8766 真机：填假 token 调用真实 Tushare 接口返回「token 不对」，
  说明网络与错误链路通；页面 0 控制台报错。

## 已知限制

- 免费档只有日线，非实时；
- 个别指数/股票权限受 Tushare 积分档位限制，返回错误会显示中文原因；
- 未配置 token 时不会生成股票卡，只提示先配置。
