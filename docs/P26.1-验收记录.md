## 1. 交付

新增「Agent 中枢」插件 `#/agents`：写一个任务 → 选 Claude Code / Codex → 在允许目录只读执行 →
流式看过程 → 结果存学习档案。

| 层 | 文件 |
|---|---|
| 服务 | `services/agents/`：`base.py`（argv/解析）、`claude.py`、`codex.py`、`workspace.py`、`registry.py`、`runner.py` |
| 存储 | `store/agent_tasks.py`（任务 + 增量事件）；schema 5→6；agent 表拆到 `core/db/schema_agents.py` |
| 接口 | `server/routes_agents.py`：`GET /api/agents`、`POST/GET /api/agents/tasks*`、事件轮询、停止 |
| 前端 | `#/agents`：`web/pages/agents.html` + `js/pages/agents/*`（compose / log / history / format）+ `agents.css`；SW v32 |

## 2. 只读边界

| Agent | 参数 |
|---|---|
| Claude Code | `-p --output-format stream-json --verbose --restricted --permission-mode plan --strict-mcp-config --mcp-config '{"mcpServers":{}}' --add-dir <workspace>` |
| Codex CLI | `exec --json --sandbox read-only --skip-git-repo-check --ephemeral -C <workspace>` |

- 不使用任何 `--dangerously-bypass-*`；
- 目录白名单来自 `设置.json` 的 `agents.allowed_roots`，生产为 `D:\Desktop` / `D:\学习系统`；
- 拒绝 UNC、系统目录、不存在的目录；
- 不读写 `~/.claude` / `~/.codex` 的凭据，不接管登录。
