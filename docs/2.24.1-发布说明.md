# 学习工作台 2.24.1 发布说明

> 2026-10-24。**Qt 收尾补验**：今日页自动刷新；补齐 125%/150% 缩放验证。功能范围不变，只补 R4/R5 的未验项。
> 起点 2.24.0（875 后端 + 23 网页 + 25 六级）→ 2.24.1（878 后端 + 23 网页 + 25 六级）。

## 1. 这次做了什么

| 改动 | 落地 |
|---|---|
| 今日页自动刷新 | `learnsys/ask/qt/today.py`：`AUTO_REFRESH_MS = 60_000`；窗口显示才启动、隐藏/最小化暂停、有请求在飞时跳过 |
| 静默刷新 | 不闪屏、不清空已有内容、不改变滚动位置；失败只提示「自动刷新没连上（显示上次数据）」，不弹重试 |
| 测试 | 今日页新增 3 例：定时器随显隐启停、只在可见空闲时触发、失败保留旧数据（合计 40 例） |
