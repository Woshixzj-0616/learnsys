## 3. 本轮发现并修掉的问题

1. **闭环断开**：今天页给出薄弱卡，但测验页只认「今天有窗口/转写/问答/训练/断点」，
   没当天记录时按钮禁用。修法：`weak_points` 非空也允许出题；prompt 改为
   「没有新的学习记录 + 围绕重点类目出通识自测题 + 别编造今天学过什么」。
2. **「薄弱」口径过宽**：最初把 99% 的词汇也列进「优先覆盖」。修法：`weak_points`
   只收掌握度低于 70% 的类目；`totals.weakest` 保留「最低展示」语义。
